# Edge Case User Research: InvestScan 경쟁우위 관점

> Phase 1 Branch: User-EdgeCase (Round 2)
> 핵심 질문: "누가 InvestScan을 AlphaSquare보다 '압도적으로 우월'하다고 느끼는가?"

---

## 3 페르소나 요약

### Persona 1: 전업투자자 김재현 (47세)
- 운용자산 15억 원, 월 고정비용 ~50만원 (AlphaSquare Pro + 연합인포맥스 + WSJ/FT)
- **핵심 Pain**: AlphaSquare는 "뭘 사야 하나" 알려주지만, "왜 이 방향인가"의 매크로 맥락 제공 불가
- **InvestScan 우위**: 매크로→섹터→종목 연쇄 분석, 다중 시나리오 시뮬레이션, 신호 진화 타임라인
- **포기 가능**: 실시간 자동매매, 예쁜 UI, 백테스팅 → 판단의 질 > 실행 속도
- **성공 지표**: "InvestScan STEEPs 분석이 2주 전에 잡은 미중 규제 신호로 포지션 줄여 3천만원 손실 회피"

### Persona 2: 투자 콘텐츠 크리에이터 박서연 (32세)
- 유튜브 8만 구독, 유료 멤버십 2,000명 (월 9,900원)
- **핵심 Pain**: 모든 크리에이터가 같은 AlphaSquare 신호 사용 → 콘텐츠 동질화
- **InvestScan 우위**: 116개 글로벌 소스 기반 독자적 분석, 과정 자체가 콘텐츠, 14개 언어 커버리지 = 브랜딩 자산
- **포기 가능**: 트레이딩, 백테스팅, 게이미피케이션, 모바일 → 분석 깊이 > 편의성
- **성공 지표**: "영상 기획 6시간→2시간, '어디서 이런 정보를?' 댓글 매 영상 10+개, 멤버십 75% 증가"

### Persona 3: 체계적 투자자 이동현 (38세, 네이버 개발자)
- 투자자산 5억, AlphaSquare API(39,800원/월) + QuantConnect 사용
- **핵심 Pain**: AlphaSquare AI Score 87 → "왜 87인지" 알 수 없는 블랙박스
- **InvestScan 우위**: 전 파이프라인 오픈(코드 감사), 증거 체인 JSON, 재현 가능, Git 통합
- **포기 가능**: UI 편의성, 커뮤니티, 모바일 → 구조화된 데이터 > 예쁜 차트
- **성공 지표**: "증거 체인 신뢰도 0.8+ 결정 승률 72% vs 감 기반 51% — 이 데이터가 핵심 자산"

## 통합: Core 7 Features (3 페르소나 공통)

| # | Feature | 전업투자자 | 크리에이터 | 체계적 투자자 |
|---|---------|-----------|-----------|-------------|
| F1 | 매크로→투자 시사점 연쇄 분석 (STEEPs→Sector) | 포트폴리오 방향 | 내러티브 소재 | 체계적 입력 |
| F2 | 글로벌 다국어 뉴스 파이프라인 (116 sites, 14 langs) | 정보 우위 | 차별화 브랜딩 | 비정형 데이터 체계화 |
| F3 | 신호 진화 타임라인 (약→중→강 추적) | 조기 포지셔닝 | "남들보다 먼저" | 임계점 기반 알림 |
| F4 | 증거 체인 + 투명한 추론 (소스→추출→분류→결론) | 확신 수준 판단 | 팩트체크 근거 | 감사·재현 가능 |
| F5 | 반론 자동 생성 (Devil's Advocate) | 리스크 관리 | 균형 콘텐츠 | 확증 편향 제거 |
| F6 | 의사결정 이력 + 사후 복기 | 투자 실력 향상 | "복기 시리즈" 소재 | 모델 개선 피드백 |
| F7 | 100% 로컬 + 오픈 워크플로우 + $0 | 비용 절감+주권 | 저작권 자유 | 코드 감사+확장 |

## 패러다임 전환

> **"AlphaSquare는 물고기를 준다. InvestScan은 바다의 조류, 수온, 계절을 읽는 법을 준다."**

| | AlphaSquare 패러다임 | InvestScan 패러다임 |
|---|---|---|
| 핵심 질문 | What to buy? | Why does this matter? |
| 분석 방향 | 종목→신호 (Bottom-up) | 환경→시사점→포지션 (Top-down) |
| 사용자 역할 | 신호 수신자 (Consumer) | 분석 과정 참여자 (Collaborator) |
| AI 역할 | 답을 주는 오라클 | 사고를 구조화하는 파트너 |
| 가치 축적 | 없음 (매일 리셋) | 의사결정 이력이 자산으로 축적 |
| 차별화 원천 | 더 정확한 예측 (본질적 불확실) | 더 나은 사고 과정 (축적 가능) |

**결론**: 세 페르소나 모두 "결과가 아니라 과정을 소유할 수 있기 때문에" InvestScan이 압도적.
