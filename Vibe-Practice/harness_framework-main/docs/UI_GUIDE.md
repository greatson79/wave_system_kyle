# UI 디자인 가이드

## 디자인 원칙
1. 관리 도구답게 — 데이터 테이블 중심, 불필요한 장식 배제
2. 한눈에 현황 파악 — 대시보드에서 카테고리별 이수율 즉시 확인
3. 모바일 대응 — 관리자가 이동 중에도 체크 가능

## 컴포넌트
### 테이블
- 헤더: 굵은 글씨, 배경 #f1f3f4
- 행: hover 시 배경 #e8f0fe
- 체크박스: 구글 머티리얼 체크박스

### 버튼
- Primary: 배경 #1a73e8, 텍스트 white, rounded 4px
- Secondary: 테두리 #dadce0, 텍스트 #1a73e8

### 카드 (클래스 요약)
- 배경 white, 테두리 #dadce0, rounded 8px, 그림자 0 1px 3px rgba(0,0,0,0.12)
- 이수율에 따라 상단 바 색상 변경 (green/yellow/red)
