## 만들 것

- 간단한 채팅 서비스
- 반드시 로그인해야 이용할 수 있음. 비로그인 상태에서는 로그인/회원가입 페이지만 접근 가능.

## 주의 사항

- 채팅방 참여 개념은 없고, 누구나 모든 채팅방에 메세지를 보낼 수 있고 확인할 수 있음.
- supabase auth를 사용
- 반드시 client side와 server side가 같은 인증 방식을 사용하도록 꼼꼼히 체크

## 페이지 목록

- 로그인
- 회원가입 (닉네임, 이메일, 비밀번호, 비밀번호 확인 입력)
- 홈 ('/', 채팅방 목록, 헤더 존재, '채팅방 추가' 버튼 존재)
- 채팅방 추가 ('/chat-rooms/new', 채팅방 이름 입력 후 제출. 완료 시 홈으로 이동)
- 채팅방 상세 ('/chat-rooms/:id', 카카오톡 같은 레이아웃으로 표시)
  다음과 같은 세부 기능을 가진다.
  - 메세지는 텍스트/이모티콘 2가지 유형을 가진다.
    - 텍스트 메세지는 하단 입력창에서 메세지 입력 후 전송할 수 있다.
    - 이모티콘 메세지는 하단 입력창의 이모티콘 아이콘을 클릭한 뒤, 팝업에서 이모티콘을 선택하면 전송된다. 텍스트 내용은 가지지 않고 이모티콘만 전송된다.
  - 과거 메세지의 우측에 메뉴 버튼이 표시된다. 클릭 시 다음과 같은 버튼들이 나타난다.
    - 내 메세지인 경우: '삭제'
    - 남의 메세지인 경우: '답장', '좋아요'
  - 삭제 버튼을 클릭하면 '삭제 모드'가 되며, 해당 메세지가 삭제 대상 메세지가 된다.
    - 삭제 모드에서는 내가 보낸 메세지들 옆에 체크아이콘이 표시된다. 삭제 대상 메세지는 파란색, 그 외는 회색이다. 체크아이콘을 클릭해 삭제 대상 여부를 토글할 수 있다.
    - 삭제 모드에서는 하단에 입력창 대신 취소, 일괄삭제(N개) 버튼이 표시된다. 삭제 대상 메세지가 없으면 일괄 삭제 버튼이 비활성화된다. 일괄 삭제 버튼을 클릭하면 삭제 대상 메세지들이 삭제되고, 메세지 목록이 새로고침된다.
  - 답장 버튼을 클릭하면 해당 메세지가 답장 대상 메시지가 된다.
    - 답장 대상 메시지가 존재하는 경우, 하단 입력창 상단에 추가 UI로 해당 메시지의 발신자이름+내용이 표시되며 우측 X 아이콘을 클릭해 답장 대상 상태를 초기화할 수 있다.
    - 답장 대상 메시지가 존재하는 경우, 텍스트/이모티콘 메세지를 전송하면 답장 대상 메세지 정보도 데이터베이스에 함께 저장된다. 저장이 성공하면 답장 대상 상태가 초기화된다.
    - 메세지 목록에서, 각 메세지를 표시할 때 답장 대상 메세지가 있다면 해당 메세지의 발신자이름+내용을 함께 표시한다. 카카오톡의 디자인을 참고한다.
  - 좋아요 버튼을 클릭하면 해당 메세지에 좋아요가 추가된다.
    - 메세지 목록에서, 각 메세지를 표시할 때 좋아요가 있다면 하트아이콘과 개수를 표시한다. 이를 클릭해 좋아요 상태를 토글할 수 있다. 내가 좋아요한 메세지라면 하트 아이콘이 핑크색, 그 외에는 회색이다.
- 마이페이지 ('/my-page', 헤더 존재, '로그아웃' 버튼 존재, 닉네임 수정 가능)
