## 점검 방법론

### 점검 항목
1. **기능 구현 여부**: 각 spec.md에 명시된 기능이 구현되어 있는가?
2. **접근성**: 사용자가 해당 기능에 쉽게 도달할 수 있는가?
3. **네비게이션**: 페이지 간 이동이 자연스럽고 직관적인가?
4. **일관성**: 역할별 경험이 일관된 패턴을 따르는가?
5. **오류 처리**: 잘못된 접근이나 권한 오류가 적절히 처리되는가?

### 평가 기준
- 🔴 **긴급도 높음**: 사용자가 핵심 기능을 사용할 수 없거나 심각한 혼란 야기
- 🟡 **긴급도 중간**: 사용 가능하지만 불편하거나 비직관적
- 🟢 **긴급도 낮음**: 개선하면 좋지만 필수는 아님

## 발견된 문제점 및 개선방안

### 🔴 긴급도 높음

#### 1. 공통 헤더 네비게이션 메뉴 부재

**문제**:
- 현재 헤더에는 로고와 사용자 정보, 로그아웃 버튼만 있음
- 역할별 주요 메뉴로 이동할 수 있는 네비게이션이 없음
- 사용자가 URL을 직접 입력하거나 브라우저 뒤로가기만 사용 가능

**영향**:
- 사용자가 기본적인 네비게이션을 할 수 없음
- 페이지 간 이동이 매우 불편함
- 핵심 기능 사용에 지장

**개선방안**:
```tsx
// src/components/layout/header.tsx 수정

// Learner용 메뉴
const learnerMenuItems = [
  { label: '코스 카탈로그', href: '/courses' },
  { label: '내 대시보드', href: '/dashboard' },
  { label: '내 코스', href: '/courses/my' }, // 별도 목록 페이지 필요
];

// Instructor용 메뉴
const instructorMenuItems = [
  { label: '대시보드', href: '/instructor/dashboard' },
  { label: '코스 관리', href: '/instructor/courses' },
  { label: '과제 관리', href: '/instructor/assignments' },
];

// Operator용 메뉴
const operatorMenuItems = [
  { label: '신고 관리', href: '/operator/reports' },
  { label: '메타데이터 관리', href: '/operator/metadata' },
];
```

**구현공수**: 2-3시간
- 헤더 컴포넌트 수정
- 역할별 메뉴 아이템 정의
- 현재 경로 강조 표시
- 반응형 모바일 메뉴

---

#### 2. Learner 대시보드 접근 경로 혼란

**문제**:
- Learner 로그인 시 `/courses`로 리다이렉트
- 대시보드는 `/dashboard`에 존재
- 두 페이지의 관계와 접근 방법이 불명확

**영향**:
- 사용자가 자신의 학습 현황을 확인하기 어려움
- "내 코스"와 "대시보드"의 차이를 이해하기 어려움

**개선방안 (Option A - 권장)**:
- Learner 로그인 시 `/dashboard`로 리다이렉트 변경
- `/dashboard`를 메인 랜딩으로 사용
- 대시보드에서 "모든 코스 보기" 버튼으로 `/courses`로 이동

**개선방안 (Option B)**:
- `/courses` 페이지 상단에 대시보드 카드 섹션 추가
- "내 학습 현황" 섹션을 `/courses` 페이지에 통합

**구현공수**: 1-2시간
- 리다이렉트 로직 수정 (`src/app/page.tsx`)
- 대시보드 레이아웃 개선
- 네비게이션 메뉴 추가

---

#### 3. 내 코스 목록 페이지 부재

**문제**:
- 수강 중인 코스 목록만 보는 페이지가 없음
- `/dashboard`에서 과제 위주로 표시됨
- 내 코스를 한눈에 보기 어려움

**영향**:
- 수강 중인 코스를 관리하기 어려움
- 코스별 진행률을 비교하기 어려움

**개선방안**:
- `/courses/my` 페이지 추가
- 수강 중인 코스 목록 + 진행률 표시
- 각 코스 카드에서 "과제 보기", "성적 보기" 직접 링크

**구현공수**: 3-4시간
- 새 페이지 생성
- API 엔드포인트 확인 (이미 있을 가능성)
- 코스 카드 컴포넌트 제작

---

#### 4. Instructor 코스 관리에서 과제 접근 어려움

**문제**:
- `/instructor/courses`에서 특정 코스의 과제 목록으로 바로 이동하기 어려움
- `/instructor/assignments`는 모든 과제를 보여주는 것으로 추정
- 코스별 과제 필터링이 필요함

**영향**:
- 코스 관리와 과제 관리가 분리되어 불편함
- 특정 코스의 과제들을 한눈에 보기 어려움

**개선방안**:
- `/instructor/courses/[courseId]/edit` 페이지에 "과제 관리" 탭 추가
- 또는 같은 페이지에 "이 코스의 과제" 섹션 추가
- `/instructor/assignments?courseId={id}` 필터 지원

**구현공수**: 2-3시간
- 코스 상세 페이지에 과제 목록 섹션 추가
- 과제 목록 페이지에 코스 필터 추가

---

#### 5. 코스 상세에서 수강신청 후 이동 경로 불명확

**문제**:
- 코스 상세에서 수강신청 후 어디로 이동하는지 불명확
- 수강신청 후 바로 과제를 시작할 수 있어야 하는데 경로가 명확하지 않음

**영향**:
- 수강신청 후 다음 액션이 불명확함
- 사용자가 다음에 무엇을 해야 할지 모름

**개선방안**:
- 수강신청 성공 시 toast 메시지에 "내 코스로 이동" 링크 추가
- 또는 수강신청 성공 시 자동으로 `/courses/my/[courseId]`로 리다이렉트
- 과제가 있는 경우 "첫 과제 보기" 버튼 표시

**구현공수**: 1-2시간
- 수강신청 성공 핸들러 수정
- toast 메시지 개선 또는 리다이렉트 추가

### 🟡 긴급도 중간

#### 6. Breadcrumb 네비게이션 부재

**문제**:
- 깊은 페이지 구조 (예: `/courses/my/[courseId]/assignments/[assignmentId]/submit`)에서 현재 위치 파악 어려움
- 상위 페이지로 돌아가기 어려움

**영향**:
- 사용자가 현재 위치를 파악하기 어려움
- 상위 페이지로 이동하려면 브라우저 뒤로가기만 사용
