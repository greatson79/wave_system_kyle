### 표적 하이브리드 전략

**반드시 테스트 (비타협)**:
1. **Schema 파싱 (양 소스)** — ~10개 contract test (fixture 데이터)
2. **섹터 매핑 규칙** — ~15개 parameterized test
3. **그 외 아무것도 테스트하지 않음**

**나머지는 수동 검증**:
- 주간 파이프라인 실행 = E2E 테스트
- 리포트를 직접 읽기 = 품질 검증
- 월 1회 샘플 3개 spot-check

### 시간 배분 (80시간 예산)

| 활동 | 시간 | 비율 |
|------|------|------|
| 기능 개발 | 55hr | 69% |
| 표적 테스트 (작성+유지) | 8hr | 10% |
| 수동 테스트 (주간 실행) | 12hr | 15% |
| 타입 힌트 + 포맷팅 | 3hr | 4% |
| Git 위생 | 2hr | 2% |

### 한 줄 요약

> **통합 경계와 섹터 매퍼만 테스트하라. 함수 시그니처에 타입 힌트를 넣어라. 주간 파이프라인을 수동 실행하라. 나머지는 건너뛰어라.**
