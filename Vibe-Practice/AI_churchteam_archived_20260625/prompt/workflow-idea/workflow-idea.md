## §0. ABSOLUTE ANCHOR (회의 기준)

### §0.1 제1 핵심 목적 (PRD §0.1 인용 — 단정 아님, *고정 좌표*)

> **C-레벨 리더(담임목사)가 *목회적 통찰을 얻고 사역을 기획하며, 그 기획을 다매체로 실행할 수 있도록 돕는* 가상 AI 교역자팀(churchTeam)을 구축한다 — AI를 활용하여 목회자의 사고·전략·실행 3축을 보조한다.**

본 문서의 모든 아이디어는 위 한 문장과의 1줄 연결을 명시한다.

### §0.2 회의 절대 기준

1. **품질 절대우선** — 선택지·근거·트레이드오프 손실 금지. 단순화로 정보를 *없애지* 않는다.
2. **로컬 실행 불변** — 각 아이디어는 *로컬 macOS 자동 실행 적합성* 태그를 보유한다(✅/⚠/❌ + 사유).
3. **확정 결론 금지** — 본 문서는 회의 결과 보존본이며, 이후 성찰·수정·결정이 계속된다.
4. **(v0.4 신설) 보존 범위 = 트레이드오프 + 후보안 슬롯** — ⚠/🚧/🛡 표기 항목은 *후보안 0개 보존*을 금지한다. 보류는 *발산 방지*이지 *공백 허용*이 아니다. 보류 항목엔 후보 형태(≥1) + 트레이드오프 1줄을 함께 보존하여 후속 라운드 시작 시점의 발산을 차단한다.

### §0.3 본 문서가 단정하지 않는 것

- 정확한 슬래시 커맨드명·플래그
- 부교역자 에이전트 셋(Q7) 및 직무 매핑(Q2)·3축 매핑(Q3)
- didim 위임 인터페이스의 최종 형식(C-A-인터페이스, P0)
- 신학 필터 규칙·자동화 한도 정확값(Q5)
- Bootstrap 자동화 범위(Q4)·신학 필터 자동 설치 가능 여부(Q6)
- SPOF 4선 정책 정확값(Q8)
- 자기 진화 자율 권한 경계 정확값(Q9)
- 디렉터리 구조·DAG 노드 스키마·코드·Hook 본문(§16 ND 가드)

## §2. 아이디어 — A축 (메타빌드·부모 DNA·Bootstrap)

> 출처: 회의 1회차 / Teammate-A. 모든 항목은 *후보*이며 채택 결정은 사용자 세션 영역.

### A-1. 0회차 셸 1줄 = "PRD를 읽는 부트로더" (Genome Loader)
- **핵심**: 슬래시 커맨드가 *아직 없는 상태*에서 시작하므로 0회차 진입은 셸 1줄로 ① 부모 게놈 위치 해석 → ② 본 PRD 파싱 → ③ DNA 7요소(헌법·구조·검증·안전·기억·비판·투명) 자식 인스턴스로 복사·검증 → ④ 1회차 슬래시 커맨드 등록까지만. 그 외엔 만들지 않는다(YAGNI).
- **제1 목적 연결**: 비개발자 담임목사가 "팀"을 *맨손으로* 처음 만나는 지점 — 목적 ② 직격.
- **트레이드오프**: 1줄 안에 너무 많이 욱여넣으면 실패 진단 불가 → 명령 자체는 1줄, 내부는 단일 부트로더 스크립트 1개로 위임.
- **로컬 적합성**: ✅ — 네트워크는 §11.1.b가 0회차에 한해 명시 허용.
- **⚠ 보류 사항(v0.3 반영, C1)**: **0회차 셸 1줄 입력의 *행위자*가 약속 1(무코드)와 정합한지 미명문화.** 셸 입력 자체가 코드 작성은 아니나 비개발자 담임목사 적용 여부·대안(GUI 트리거·기존 Claude Code 세션 내 슬래시 등)이 정의되어 있지 않음. **본 행위자 결정 전 A-1 채택 보류 — BL-5(A-5 행위자 결정 라운드)에 *0회차 진입 행위자*도 합류하여 동시 처리.**
- **출처**: Teammate-A (회의 1회차) + 직전 성찰 §C1.

### A-2. PRD-as-Input은 "스키마 검증 게이트"부터 (메타빌드의 RED-line)
- **핵심**: 메타빌드(약속 2)의 첫 동작은 *생성*이 아니라 *거부*. PRD가 §11.1.a 필수 메타데이터 6항목(절대 목표/사용자 컨텍스트/3축 분해/직무·권한/P0 블로커/갱신일 인용)을 모두 갖췄는지 검증, 누락 시 *한국어 자연어*로 거부 사유만 출력하고 종료. 빌드 진입 자체를 차단.
- **제1 목적 연결**: AI 환각·기억 의존을 0회차에서 차단 → 통찰·기획 보조의 신뢰 기반.
- **트레이드오프**: 엄격할수록 PRD 진화 시마다 빌드 실패 ↑ → 거부 메시지에 *수정 위치(§·항목)*까지 동봉.
- **로컬 적합성**: ✅ — 순수 파일 파싱.
- **출처**: Teammate-A.

### A-3. DNA 상속을 "복사" 아닌 "참조-증명"으로 (Provenance Manifest)
- **핵심**: 부모 `AgenticWorkflow-Template`의 헌법·hook·검증 스크립트를 *물리 복사*하면 동기화 부채 발생. 대신 자식은 부모 경로를 *단일 출처*(env/설정 1곳)로 해석하고, 0회차에 inheritance manifest(부모 파일 SHA + 7요소 매핑)를 자식 SOT에 기록. FR-22 자가 검증 화면이 이 매니페스트를 한국어로 렌더링.
- **제1 목적 연결**: G-6/FR-09(DNA 상속) + FR-22(자가 검증)를 동일 산출로 묶어 *체험적 가시화*.
- **트레이드오프**: 부모 이동 시 자식 작동 중단 → didim 주소 안정성 약속과 동일한 1동작 복구 안내 적용.
- **로컬 적합성**: ✅ — 해시·심볼릭 참조뿐.
- **출처**: Teammate-A.

### A-4. 메타빌드는 "슬래시 1개만 등록"으로 종료 (Bootstrap 끝점 정의 + 지연 빌드)
- **핵심**: 0회차의 *끝*은 12 부교역자·DAG·hook 전체 설치가 아니라 단일 진입 슬래시 1개의 등록. 그 후 12 직무·산출진 hook은 첫 호출 시 *지연 빌드*(M1 모드 진입과 동시에 필요한 부교역자만 활성). Phase 1 핵심 3~5명만 즉시 실체화, 나머지는 placeholder + 사용자 승인 시 활성.
- **제1 목적 연결**: 약속 4(팀 본질) — 단일 진입점 뒤에 직무가 *체험적으로* 가시화.
- **트레이드오프**: 첫 호출 시 지연 ↑ → 첫 호출 진척을 한국어 자연어로 노출(FR-11/22 결합).
- **로컬 적합성**: ✅.
- **출처**: Teammate-A.

### A-5. 자기 진화 = "PRD 재입력"으로 일원화 (Re-build = Evolve)
- **핵심**: skill·prompt·DAG의 점진 갱신(§9.4)을 *별도 진화 엔진*으로 두지 말고, "PRD 수정 → 0회차 부트로더 재실행 → diff 기반 갱신"의 단일 경로로 통합. 자율 진화 경계 위반은 PRD diff 단계에서 §9.4 표를 검사해 차단·승인 요청.
- **제1 목적 연결**: 약속 3의 ④(자기 진화)를 약속 2(메타빌드)와 동일 메커니즘으로 묶어 1인 운영자의 인지 부하 최소화.
- **트레이드오프**: PRD가 사실상 단일 운영 콘솔이 됨 → PRD 자체의 가독·버전 관리 부담 ↑.
- **⚠ 보류 사항(v0.2 반영, R-4)**: **"PRD 수정자가 누구인가"**가 미결. 비개발자 담임목사가 `.md`를 직접 편집한다는 가정인지, Claude Code가 대화로 받아 *대신* 쓴다는 가정인지 모호. 전자는 약속 1(무코드) 위반, 후자는 SOT 단일쓰기자 + 사용자 승인 게이트 결합 설계 필요. **본 행위자 결정 전 A-5 채택 보류** — §7 권고 묶음의 "메타빌드"에서 분리.
- **로컬 적합성**: ✅.
- **출처**: Teammate-A + 직전 성찰 §B-3/R-4.
