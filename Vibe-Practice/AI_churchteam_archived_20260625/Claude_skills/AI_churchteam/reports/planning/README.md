# 사역기획팀 기획안 폴더

사역기획팀이 작성한 주간 기획안이 저장됩니다.
전략팀이 이 폴더에서 기획안을 읽어 방향 정렬 검증을 수행합니다.

## 파일명 규칙
```
YYYY-MM-DD-weekly-plan.md         ← 최종 기획안
YYYY-MM-DD-schedule-draft.md      ← 주간사역설계관 중간 산출물
YYYY-MM-DD-message-flow.md        ← 메시지정렬관 중간 산출물
```

## 흐름
1. 주간사역설계관 → `schedule-draft.md` 저장
2. 메시지정렬관 → `message-flow.md` 저장
3. 기획팀장 → 두 파일 통합 → `weekly-plan.md` 저장
4. 전략팀이 `weekly-plan.md` 읽고 정렬 검증 수행
