# 정렬 검증 결과 폴더

전략팀이 기획팀 기획안을 목회 방향과 대조 검증한 결과가 저장됩니다.
기획팀장이 이 결과를 읽고 최종 기획안을 확정합니다.

## 파일명 규칙
```
YYYY-MM-DD-alignment-check.md
예: 2026-05-07-alignment-check.md
```

## 검증 결과 등급
- **A (정렬)**: 방향 일치, 기획안 확정 진행
- **B (보완)**: 대체로 맞으나 수정 권고 포함
- **C (재검토)**: 방향 이탈, 기획팀에 수정 요청
- **D (충돌)**: 목회 방향과 충돌, 재기획 필요

## 현재 상태
파일이 없으면 기획팀이 검증 없이 기획안을 확정하고
총괄팀장에게 "정렬 검증 미실시" 표시와 함께 보고합니다.
