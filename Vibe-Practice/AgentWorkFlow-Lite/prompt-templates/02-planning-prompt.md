# Planning 단계 프롬프트 템플릿

> 사용 시점: Research 완료 후, Implementation 시작 전
> 목적: 실행 계획 수립 + 사람의 검토·승인

---

## 기본 템플릿

```
Research 결과를 바탕으로 실행 계획을 수립해줘.

## Research 결과
{research/findings.md 참조 또는 요약}

## 계획에 포함할 항목
1. 단계별 실행 순서 (병렬/순차 구분)
2. 각 단계의 담당 에이전트
3. 예상 산출물과 저장 경로
4. 사람이 확인해야 할 결정 포인트

## 출력 형식
계획을 보여주고 승인을 요청한다.
승인 전까지 Implementation을 시작하지 않는다.
```

---

## workflow.md 생성 버전

```
다음 정보를 바탕으로 workflow.md를 작성해줘.

## 프로젝트 정보
- 이름: {프로젝트명}
- 목적: {자동화할 업무}
- 대상: {사용자}

## 현재 프로세스
1. {현재 하고 있는 단계 1}
2. {현재 하고 있는 단계 2}
3. {현재 하고 있는 단계 3}

## 자동화 목표
- 자동으로 처리하고 싶은 것: {항목}
- 사람이 직접 해야 하는 것: {항목}

workflow-template.md를 기반으로 작성하고,
완성 후 내가 검토할 수 있도록 보여줘.
```

---

## 팀 시스템 설계 버전

```
우리 팀을 위한 AI 시스템을 설계해줘.

## 팀 정보
- 팀 규모: {인원}
- 주요 업무: {반복 업무 목록}
- 공유 도구: {구글 드라이브 / 노션 / 슬랙 등}

## 설계 요청
1. 팀 공통 SOT 구조 제안
2. 역할별 에이전트 구성 (누가 무엇을)
3. 팀 CLAUDE.md 초안
4. 공유 workflow.md 구조

결과를 workflow.md에 작성하고 검토 요청.
```
