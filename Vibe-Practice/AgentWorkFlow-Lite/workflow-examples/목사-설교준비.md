# 설교 준비 자동화 Workflow

> 직군: 목사·설교자
> 자동화 수준: Phase 1 자동 + Phase 2 대화형

---

## 1. 목적

**해결하려는 문제:** 매주 설교 준비에 소요되는 반복 작업 (자료 수집, 묵상 자료, 핸드아웃 제작)
**자동화 업무:** 본문 선정 → 원어 연구 → 묵상 생성 → 설교 개요 → 핸드아웃
**성공 기준:** 준비 시간 50% 단축, 신학적 정확성 유지

---

## 2. SOT

| 데이터 | 파일 위치 | 쓰기 권한 |
|--------|---------|---------|
| 52주 설교 계획 | `data/sermon-plan.json` | 사용자만 |
| 설교 맥락 | `output/{월}/{주차}/sermon-context.md` | sermon 에이전트만 |
| 진행 상태 | `output/{월}/{주차}/status.md` | team-leader만 |

---

## 3. 에이전트 구성

| 에이전트 | 역할 | 타입 |
|---------|------|------|
| team-leader | DAG 조율, status 관리 | interactive |
| sermon | 설교 5단계 준비 | interactive |
| devotion | 주중 묵상 자료 5일치 생성 | auto |
| handout | 핸드아웃·주보 초안 생성 | auto |

---

## 4. 실행 흐름

```
[시작: /설교준비 {주차}]

Phase 1 (병렬):
  A. devotion 에이전트: 묵상 5일치 HTML 생성
  ∥
  B. sermon 에이전트: 본문 연구 (1~3단계)

       ↓ [검토: 설교 방향 목사님 확인·승인]

Phase 2 (순차):
  sermon 에이전트: 설교 개요 완성 (4~5단계)
       ↓
  handout 에이전트: 핸드아웃·주보 초안 생성

[산출물: 묵상 HTML 5개 + 설교 개요 + 핸드아웃 docx]
```

---

## 5. 산출물

| 산출물 | 형식 | 저장 경로 |
|--------|------|---------|
| 묵상 자료 | HTML | `output/{월}/{주차}/묵상/` |
| 설교 개요 | Markdown | `output/{월}/{주차}/설교/` |
| 핸드아웃 | DOCX | `output/{월}/{주차}/핸드아웃/` |

---

## 6. 프로젝트 규칙

```markdown
- 응답 언어: 한국어
- 성경 본문: 개역개정판 기준
- AI 추측으로 날짜·본문 생성 금지 (반드시 sermon-plan.json에서 읽기)
- 신학적 판단이 필요한 결정은 반드시 목사님 확인 후 진행
```
