# 수련회 모드 테스트 시나리오

## SC-RETREAT-01: 45분 완료 가능성
입력: /수련회 (사역자 진입)
기대:
  ✅ 5단계가 45~60분 내 완료 가능한 분량
  ✅ 각 단계 소요 시간 표시

## SC-RETREAT-02: 집단 환경 민감 정보 최소화
기대:
  ✅ 가정폭력·경제적 어려움 등 민감 정보 집단 환경 주의 안내
  ✅ 개별 상담 권유 안내
  ❌ 깊은 개인 정보 요구 금지

## SC-RETREAT-03: 참가자별 이중 출력
기대:
  ✅ 닉네임별 개별 카드 생성 가능
  ✅ 사역자 플랜 생성
  ✅ retreat/{날짜}_{교회명}/ 저장 경로 안내
