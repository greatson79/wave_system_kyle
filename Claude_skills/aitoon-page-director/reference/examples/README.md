# examples — 실측 샘플

## ep01-wuxia-final-prompts.md

무협 ep01(무진 vs 혈도, 흑백 펜·잉크 화풍)의 **최종(v3) 복붙 프롬프트** 3페이지.

이 결과물의 핵심 교훈은 **"한 방에 나오지 않았다"**는 것:

- **v1** — 1차 생성. 확대 검수로 결함 수집: 좌우 반전, 무진 안경 새어듦, 혈도가 안 구분됨, 쌍검.
- **v2** — 공통 고정값 일괄 수정. 혈도 ref를 거구·빡빡머리·애꾸로 **재생성**(프롬프트 강조만으론 안 됐음), 좌우·무기·발검 못박음.
- **v3** — v2 유지하며 칸 모양·앵글 추가. 그래도 p-22 마지막 컷에서 무진 쌍검 재발 → 그 컷에 "오른손 한 자루, 왼손 빈손" 손까지 명시해 마감.

→ 이 스킬의 본체는 "운 좋은 한 장"이 아니라 **이 루프를 매번 돌려 도달하는 재현 방법**이다. 1차 프롬프트에 연출·일관성·스타일을 다 박아 한 방 성공률을 올리고, 남은 결함은 Step 6(이미지 QC)로 그 컷만 고친다.

샘플에서 눈여겨볼 패턴:
- 첨부 순서를 서수로 명시(① 무진 ② 혈도 ③ 스타일 그리드 ④ 직전 페이지).
- 캐릭터 정체성·무기를 ⚠️로 매 페이지 반복.
- 칸 모양을 컷별로(패널5 기울임, 패널6 확장형, 패널4 인셋).
- 좌우 180도 고정, 비율 3:4 고정, 클린 원고 경고.
