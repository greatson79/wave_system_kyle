# Gotchas — 알려진 실패 패턴 (0625 무협 ep01 실측)

> GPT(나노바나나) 배치로 페이지 만화를 뽑을 때 반복적으로 터진 문제와 대응.
> 핵심 통찰: GPT는 배치·한글 말풍선·스타일은 기대 이상으로 잘한다. **한계는 정밀 통제** — 무기 수·좌우·칸 모양.

---

## 1. 쌍검 재추가 (가장 끈질김)

**증상**: 검 한 자루 인물이 광역 격돌·벤 직후 컷에서 칼을 2자루 들고 나온다.
**원인**: "쌍검 금지"라고 적어도, 액션 광역 컷에서 GPT가 손에 칼을 또 그린다(ep01 v1·v3 재발).
**대응**: ① 그런 컷엔 **손까지 명시** — "오른손에 검 한 자루, 왼손은 비어 있음". ② 생성 후 그 컷을 **확대 QC**. 규칙 명시만으론 부족.

## 2. 썸네일로 놓침 → 확대 QC 필수

**증상**: 페이지 전체 썸네일로 봤을 땐 멀쩡한데, 확대하니 쌍검·말풍선 클립이 있었다(0625 2회 오판).
**대응**: 광역/격돌 컷·무기 든 손은 **잘라서 확대** 확인. 비전 토큰 아끼려고 의심 컷만 crop.

## 3. 좌우 반전 (180도)

**증상**: 페이지마다 두 인물 좌우가 바뀐다.
**원인**: 좌우를 안 박으면 GPT가 반전(ep01 v1).
**대응**: "A=화면 왼쪽 / B=화면 오른쪽"을 모든 대치·격돌 컷에 명시. 첫 와이드 컷에서 확정.

## 4. 안경·소품이 새어 들어옴 / 색이 페이지마다 바뀜

**증상**: 안경 없는 인물에 안경이 생긴다. 또는 머리색·의상색이 페이지마다 달라진다.
**원인**: 고정 외형(색 포함)을 명시 안 하면 엉뚱한 요소가 새거나 색이 바뀐다.
**대응**: "안경 없음"처럼 **없는 것도 명시**. **머리색·의상색은 ref + 매 페이지 프롬프트에 반복 명시**("갈색 단발, 베이지 셔츠"). 소품 on/off 컷별로.

## 5. 터널비전 — 한 차원 고치다 다른 차원 놓침

**증상**: 무기를 고쳤더니 칸 모양이 다 직사각으로 평평해짐(ep01 v2).
**원인**: 한 번에 한 차원만 신경 쓰면 나머지가 기본값으로 회귀.
**대응**: 매 프롬프트 확정 전 direction-rules §10 체크리스트 7줄 전부 통과.

## 6. 앵글 ≠ 칸 모양 혼동

**증상**: "더치 앵글"이라 적었는데 그림만 기울고 칸은 사각.
**원인**: 카메라 기울기(앵글)와 패널 테두리(칸 모양)는 다른 레버인데 하나만 적음.
**대응**: 둘을 따로 명시 — "기울어진 칸 + 더치 앵글".

## 7. 1~2컷 페이지가 6칸으로 복귀

**증상**: 스플래시(1컷)를 원했는데 6칸 그리드로 나온다.
**원인**: "패널 N개"를 안 바꾸면 GPT가 기본 6칸으로 복귀.
**대응**: "한 컷으로 페이지 전체를 채우는 스플래시 컷"으로 컷 수를 명시적으로 바꾼다.

## 8. 만화 프레이밍 함정 (스타일 묻힘)

**증상**: sref 화풍을 줘도 GPT 기본 웹툰체로 평평하게 나온다.
**원인**: "comic/웹툰"이라는 단어가 학습 관성을 부른다(인포그래픽의 "infographic" 함정과 같은 메커니즘).
**대응**: 0625엔 직교(잘 묻음)였으나 약하면 — "NOT a clean flat digital webtoon" 프레이밍 역전 + "keep the brushy hand-painted texture" 금지문(style-tokens.md 참조). **잘 묻으면 넣지 않는다.**

## 9. 첨부 누락 / 모호 지시 / 서수 어긋남

**증상**: 스타일이 안 먹거나 엉뚱한 캐릭터. 또는 "첫 이미지들은 인물·고양이"로 뭉뚱그려 매핑 안 됨. 또는 인물이 늘었는데 "세 번째 이미지는 직전 페이지"처럼 고정 서수를 써서 실제 첨부(4장)와 어긋남.
**원인**: 모호 표현 / 캐릭터 뭉뚱그림 / 서수 하드코딩.
**대응**: 맨 앞 첨부 경고 배너 + 각 캐릭터 **개별 서수+이름 1:1**("첫 번째=인물A, 두 번째=인물B"). 직전 페이지 서수 = **인물 수 + 2**, 첨부 개수에 맞춰 매번 계산(prompt-templates C형).
