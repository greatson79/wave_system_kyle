## 스킬 개요

스토리 + 미드저니 sref 스타일 이미지를 입력받아, **연출된 페이지 만화를 GPT(나노바나나)로 뽑기 위한 페이지별 복붙 프롬프트**를 생성하는 스킬. 페이지형 컷만화(트랙 A) 전용.

핵심 철학: 좋은 페이지 만화는 "운 좋은 한 장"이 아니라 **연출·일관성·스타일을 1차 프롬프트에 모두 박아 매번 도달하는 것**. 게으른 유저(만화는 만들고 싶지만 과정은 귀찮은)를 위해, 씬·컷 구성과 연출 판단은 전부 내부에서 처리하고 유저 눈엔 **복붙할 프롬프트만** 떨어진다.

## 스킬 유형 및 선택 이유

**D — 생성형 (Creator).**

- 핵심 산출물이 "복붙용 프롬프트"라는 **콘텐츠 생성물** → D.
- 외부 시스템에 실제 액션(발송·수정·삭제) 없음. GPT 이미지 생성은 **유저가 외부에서** 수행 → Approval Gate 불필요.
- 분석(스타일 토큰 추출·이미지 QC)도 하지만, 단계 간 승인 체크포인트로 묶인 파이프라인(E)이 아니라 단일 산출물로 수렴 → E 아님, D가 맞음. (gotchas: "분석 후 파일 생성은 D")

## 적용 설계 패턴

- **P6 Scope Boundary** (D 필수) — 하지 않는 것을 명시(이미지 직접 생성·자동 루프·말풍선 편집·트랙 B·SVG 노출).
- **P7 Setup Once** — 시리즈 연재 시 첫 회차에 스타일(sref)·캐릭터 ref를 셋업하고 이후 회차 재사용. 비율·톤 시리즈 고정.
- **(스킬 특유) 컨텍스트 관리** — 맥스 6페이지를 안정적으로 받치는 두 장치: ① 확정 페이지 텍스트 체크포인트 요약(비전 원본 비누적) ② 의심 컷만 crop QC. 이미지 비전이 컨텍스트 주범이므로 "분석 횟수"를 관리.
- **(스킬 특유) 페이지 상한** — 권장 4 / 맥스 6페이지. 초과 시 1~6 / 7~12로 분할 + 페이지 체크포인트 세션 인계.

## Approval Gate 위치

**없음.** 외부 액션이 없어 돌이킬 수 없는 작업이 없다. (선택 Step 6의 프롬프트 수정도 산출물 재생성일 뿐.)

## Scope Boundary

- **한다:** 씬·컷 내부 구성 / 스타일 토큰 추출 / 캐릭터 ref 프롬프트 / 페이지별 복붙 프롬프트(클린 원고 또는 선택적 말풍선) / 사용 안내 / (선택)이미지 보고 프롬프트 수정.
- **안 한다:** 이미지 직접 생성 / 자동 v1→v2→v3 루프 / 말풍선 픽셀 합성·편집(선택적 말풍선은 GPT가 직접 그림) / 트랙 B 세로 웹툰 / SVG 레이아웃 시안 노출.

> v1.2(2026-06-28): 시작 분기(intro.html)로 **클린 원고 / 대사 포함(말풍선)** 선택 추가. 대사 포함 분기는 `reference/balloon-dictionary.md` 사용. 클린 원고 경로는 기존 동작 보존.

## skill-creator 핸드오프 노트

- **`reference/direction-rules.md` 는 새로 쓰지 말 것.** 작업폴더의 완성본 `페이지만화_연출규칙.md`(v2)를 그대로 가져와 이 이름으로 둔다. 이게 연출의 권위 명세다.
- **`style-tokens.md` 는** stylish-infographic-by-blue의 `style_extraction.md`를 만화 맥락으로 옮긴다(7분해 표·영어 앵커 블록·내용물 가드·첨부 경고). 단 인포그래픽 전용 "4블록 골격"은 가져오지 말 것 — 대신 direction-rules.md §6-5 "만화 프레이밍 함정"(스타일이 약하게 묻을 때만 투입하는 프레이밍 역전·금지문)을 반영.
- **`prompt-templates.md` 는** direction-rules.md §9 실전 템플릿을 복붙 골격으로 구체화 + 캐릭터 ref 생성 프롬프트 골격 추가.
- **`image-qc-fix.md` 는** direction-rules.md §4·§5·§10 + 인계서 "확대 QC 필수"를 진단 체크리스트로. 자동 루프 금지, 유저 호출 시에만.
- **`gotchas.md` 는** 0625 실측을 옮긴다: 쌍검 재추가(광역 격돌 컷, 손까지 명시)·썸네일로 놓침(확대 QC)·좌우 반전(180도)·안경 새어듦·터널비전(무기 고치다 칸 모양)·1컷 스플래시 지시 안 하면 6칸 복귀·만화 프레이밍 함정.
- **`examples/` 는** 작업폴더 `ep-01/`의 v1→v2→v3 산출물을 샘플로 정리(복붙 프롬프트 + 문제 로그 + 개선 결과). "한 방에 안 되고 루프로 도달"을 보여주는 게 목적.
- **유저 노출 원칙 강조:** 씬·컷 설계표, 페이지 배분, 토큰 추출 과정은 **내부 작업물**. SKILL.md에 "유저에게 보여주지 않는다"를 명문화할 것. 산출은 복붙 프롬프트 + 안내뿐.
- **트리거 주의:** aitoon-insta(4컷)·세로 웹툰과 혼동되지 않게 description에 "페이지형 트랙 A 전용" 경계를 남겼다. 유지할 것.
