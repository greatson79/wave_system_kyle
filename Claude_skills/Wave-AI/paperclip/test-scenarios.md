# Wave AI Networks — 시나리오 테스트

> 목적: 에이전트 등록 후 실제 흐름이 설계대로 작동하는지 검증
> 순서: 단순 → 복합 순으로 진행

---

## 테스트 판정 기준

| 항목 | 합격 기준 |
|------|-----------|
| 라우팅 정확도 | 요청에 맞는 에이전트가 호출됨 |
| 출력 품질 | 산출물이 실제 사용 가능한 수준 |
| 제약 준수 | 금지 행동(재정 집행 등)을 하지 않음 |
| 에스컬레이션 | 판단 불가 시 Chief Wave Architect에게 올림 |
| 완료 보고 | 결과를 통합하여 명확히 보고함 |

---

## 테스트 1 — 단일 팀 (가장 단순)

**요청:**
```
"인스타그램에 올릴 부활절 메시지 3개 만들어줘"
```

**예상 흐름:**
```
Chief Wave Architect
    → Flow Operations Orchestrator (분석)
        → Content Wave Lead (GPT-4o)
            → 훅 3개 + 카피 3개 + 해시태그
        → 보고
```

**합격 기준:**
- [ ] Content Wave Lead 단독 호출 (다른 팀 불필요)
- [ ] Instagram 포맷 (짧고 감성적, 해시태그 포함)
- [ ] 신학적 메시지가 왜곡되지 않음
- [ ] 3개 완성 출력

---

## 테스트 2 — 운영 단일 (행정)

**요청:**
```
"이번 주 수요예배 공지문 만들어줘. 일시: 4월 9일 오후 7시, 장소: 본당, 주제: 부활의 증인"
```

**예상 흐름:**
```
Chief Wave Architect
    → Flow Operations Orchestrator
        → Flow Operations Lead (Gemini Flash)
            → 공지문 생성
        → 보고
```

**합격 기준:**
- [ ] Flow Operations Lead 단독 호출
- [ ] 공지 형식 준수 (제목/일시/장소/내용/문의처)
- [ ] 입력된 사실 정보 정확히 반영
- [ ] 재정 관련 내용 없음

---

## 테스트 3 — 복합 병렬 (2개 팀 동시)

**요청:**
```
"다음 주 청소년부 AI 교육 세미나 준비해줘.
강의안이 필요하고, 참여자 모집 SNS 글도 만들어줘."
```

**예상 흐름:**
```
Chief Wave Architect
    → Flow Operations Orchestrator (분해)
        ├── [병렬] Learning Wave Lead (Claude)
        │       → 청소년 대상 AI 교육 강의안
        ├── [병렬] Content Wave Lead (GPT-4o)
        │       → 모집 SNS 게시물
        └── 통합 보고
```

**합격 기준:**
- [ ] Learning + Content 두 팀 병렬 호출
- [ ] 강의안: 청소년 수준 언어 + 커리큘럼 구조
- [ ] SNS: 참여 유도 훅 포함
- [ ] 두 결과를 하나의 보고서로 통합 출력

---

## 테스트 4 — 복합 순차 (의존 관계)

**요청:**
```
"최근 설교 '부활의 증인, 섬김의 제자'를 기반으로
강의 자료를 만들고, 그걸 블로그 글로도 정리해줘."
```

**예상 흐름:**
```
Chief Wave Architect
    → Flow Operations Orchestrator (순서 설계)
        → [1순위] Learning Wave Lead
                → 설교 기반 강의 자료 생성
        → [2순위] Knowledge Wave Lead (Gemini Pro)
                → 강의 자료를 블로그 원고로 구조화
        → 통합 보고
```

**합격 기준:**
- [ ] Learning 먼저, Knowledge 나중 (순서 지킴)
- [ ] Knowledge Lead가 Learning 결과물을 입력으로 사용
- [ ] 블로그 원고: 목차 먼저 제시 후 본문
- [ ] 신학적 의미 보존 확인

---

## 테스트 5 — 에스컬레이션 (판단 불가 상황)

**요청:**
```
"Wave AI를 다른 교단과 협력하는 게 맞는지 판단해줘."
```

**예상 흐름:**
```
Chief Wave Architect
    → Flow Operations Orchestrator
        → 신학적/전략적 판단 필요 감지
        → Chief Wave Architect에게 에스컬레이션
            보고: "이 결정은 신학적 판단과 조직 방향이
                   포함되어 있어 Chief Wave Architect의
                   직접 결정이 필요합니다."
```

**합격 기준:**
- [ ] 어떤 에이전트도 직접 판단하지 않음
- [ ] 에스컬레이션 메시지가 명확함
- [ ] 판단을 위해 필요한 정보를 정리해서 올림

---

## 테스트 6 — AI 시스템 개발 트랙

**요청:**
```
"설교 원고를 입력하면 자동으로 소그룹 나눔 질문 5개를 생성하는 에이전트 만들어줘."
```

**예상 흐름:**
```
Chief Wave Architect
    → AI Systems Orchestrator (GPT-4o)
        → 아키텍처 설계
        → AI Systems Lead (GPT-4o)
            → 프롬프트 작성 + 워크플로우 설계
            → QA 검증
        → 완성된 에이전트 시스템 보고
```

**합격 기준:**
- [ ] Flow Ops Orchestrator가 아닌 AI Systems Orchestrator 호출
- [ ] 설계 문서 (구조 + 프롬프트) 산출
- [ ] 테스트 케이스 포함
- [ ] 즉시 사용 가능한 수준의 완성도
