# 예화 규칙 — SermonStory Companion 기반

모든 설교 모드(A/B/C)에서 예화를 다룰 때 적용한다.

---

## 예화의 본질

예화는 **다리**다. 본문과 청중을 연결하는 것이 예화의 존재 이유이며, 예화 자체가 메시지가 되어서는 안 된다.

---

## 위치별 깊이 조절

| 위치 | 깊이 | 설명 |
|---|---|---|
| **서론** | 짧고 직관적 | 인문학적 예화(문학, 영화, 일상 스토리 등)로 청중의 세계에서 본문으로 진입. 온세대가 공감할 수 있는 보편적 이야기. **서론 예화는 필수** |
| **본론 (M1-M4)** | 구조적 | 메시지 해석을 돕는 예화. 추상적 개념을 구체화하거나 청중 공감을 끌어올릴 때 삽입. **선택적 — 필요할 때만** |
| **결론/M5** | 이미지 중심 | 기억에 남는 짧은 이미지. 논리 통합 단계이므로 예화 추가 시 산만해질 수 있어 **대부분 불필요** |

---

## 삽입 판단 기준

| 상황 | 판단 |
|---|---|
| 추상적 개념을 구체화해야 할 때 | 삽입 |
| 청중의 공감을 끌어올려야 할 때 | 삽입 |
| 무브먼트 간 전환이 필요할 때 | 삽입 |
| 본문 자체가 충분히 구체적일 때 | 불필요 |
| 원어 설명이 이미 풍성할 때 | 불필요 |
| 예화를 넣으면 흐름이 산만해질 때 | 불필요 |

---

## 출력 구조

예화 삽입 시 이야기만 던지지 않는다. 다음 3요소를 포함한다:

1. **예화 제목** (한 줄)
2. **이야기 본문** (일상 언어, 전문용어 최소화)
3. **설교 연결 포인트** — "이 예화가 왜 이 본문/이 무브먼트에 필요한지" 명시

선택적으로 **청중 변형 제안**(청소년/청년/장년별 조정 포인트)을 추가할 수 있다.

---

## 신학적·내용적 경계

| 구분 | 내용 |
|---|---|
| **신학 기준** | 개혁주의·복음주의 신학과 명백히 충돌하는 내용 배제. 은혜·회개·소명·공동체 개념을 왜곡하지 않는다 |
| **제외: 성공 신화** | 인간 중심 성공 이야기, "열심히 하면 복 받는다"식 예화 배제 |
| **제외: 확인 불가** | 출처 불명의 인용구, 날조된 일화, 과장된 간증, 검증 불가능한 통계 배제 |
| **제외: 감정 조작** | 불필요하게 감정만 자극하고 본문을 소외시키는 예화 배제 |
| **제외: 사회 이슈** | 선정적·분열적 사회 이슈 배제 |
| **온세대 고려** | 어린이~어르신 모두가 공감할 수 있는 스토리를 우선한다. 특정 세대만 아는 레퍼런스는 피한다 |

---

## Self-Check (출력 전 점검)

모든 예화에 대해 출력 전 4가지를 확인한다:

```
□ 이 예화는 본문보다 앞서지 않는가?
□ 교리적으로 오해될 여지는 없는가?
□ 청중이 현실에서 공감 가능한가?
□ 불필요하게 감정만 자극하지 않는가?
□ (나선 구조 한정) 누적 대지(클라이맥스 이전)의 예화가 복음 해소(은혜로의 반전·구원의 위로)를 미리 누설하지 않는가?
```

4가지(나선 시 5가지) 중 하나라도 통과하지 못하면 해당 예화를 수정하거나 제거한다.
