# Cross Impact 연관성 규칙 (CrossLink 기반)

Mode C의 Bridge 단계, 그리고 Mode A/B에서 현대 적용을 구조화할 때 적용한다.

---

## 목적

Bridge 단계에서 CMT와 FCF를 현대 영역에 **교차 적용**하여, M4(현대 적용)로 넘어가기 전 **구조적 연결 고리**를 확보한다. "왜 이 고대 본문이 오늘 우리에게 유효한가"를 논리적으로 보여주는 단계다.

---

## Cross Impact 구조

```
Biblical Core Claim (CMT)
  ×
Human Condition (FCF)
  ×
Contemporary Domain:
  - 개인 (Individual)
  - 가정 (Family)
  - 교회 (Church)
  - 사회 (Society)
  =
Structured Connection Output → M4 적용의 근거
```

---

## 4영역 적용 규칙

| 규칙 | 설명 |
|---|---|
| **선별적 적용** | 4영역 모두를 다루지 않는다. 본문과 CMT/FCF에 자연스럽게 연결되는 영역만 선택한다 (보통 2-3개) |
| **본문 근거** | 모든 연관성은 본문 텍스트에서 도출되어야 한다. 본문에 없는 주제를 끌어오지 않는다 |
| **비인위적** | 연관성이 자연스럽지 않으면 해당 영역을 생략한다. 억지 연결은 설교의 신뢰를 떨어뜨린다 |
| **FCF 일관성** | 각 영역의 적용이 FCF의 동일한 핵심 구조를 반영해야 한다. 영역마다 FCF가 달라지지 않는다 |

---

## 4영역 교차 분석 템플릿

```
Bridge — Cross Impact 연관성

CMT: (한 문장)
FCF: (한 문장)

┌─────────┬──────────────────────────────────┐
│  영역    │  CMT × FCF 교차 연관성            │
├─────────┼──────────────────────────────────┤
│  개인    │  (본문의 진리가 개인 삶에서        │
│          │   어떤 형태로 나타나는가)          │
├─────────┼──────────────────────────────────┤
│  가정    │  (가정 관계에서 어떻게 작동하는가)  │
├─────────┼──────────────────────────────────┤
│  교회    │  (공동체에서 어떻게 나타나는가)     │
├─────────┼──────────────────────────────────┤
│  사회    │  (더 넓은 맥락에서 어떻게          │
│          │   반영되는가)                     │
└─────────┴──────────────────────────────────┘

→ 선택된 영역: (본문에 자연스럽게 연결되는 2-3개)
→ M4 적용 방향: (선택된 영역을 중심으로 구체화)
```

---

## 연관성 검증 기준

Bridge의 모든 연관성은 출력 전 3가지를 확인한다:

```
□ 논리적 일관성 — CMT·FCF와 논리적으로 연결되는가?
□ 본문 근거 — 본문 텍스트에서 도출 가능한가?
□ 비인위성 — 억지로 끌어온 연결이 아닌가?
```

3가지 중 하나라도 통과하지 못하면 해당 영역의 연관성을 제거한다.
