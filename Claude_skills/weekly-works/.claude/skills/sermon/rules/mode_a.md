# Mode A — 비서사 텍스트 설교 구조

서신서, 잠언, 교훈 시편, 예언서 등 비서사 텍스트에 적용한다.

---

## 13단계 흐름

> 1~4단계는 5단계 프로세스의 2단계(본문 분석)에서 수행된다.

1. 본문 선택 및 범위 확정
2. 원어 분석 — 파싱, 구조, 번역 비교 ← [2-1]
3. 역사·사회·문화 배경 분석 ← [2-2]
4. 문화 내러티브 · 우상 분석 ← [2-3]
5. CMT (Central Message of the Text) 도출 ← [2-4]
6. 도덕적 명제 (인간의 시도)
7. 인간의 노력과 실패
8. 무능력 (Inability)
9. FCF — 타락한 조건 직면 ← [2-4]
10. 그리스도 연결
11. 복음 선포
12. HP — 해석학적 적용 (복음 동기) ← [2-4]
13. 삶의 열매 · 공동체 회복

---

## 설교 아웃라인 (5부 구조)

```
서론 — 본문으로의 진입
1부 — Text: 본문이 말하는 것
2부 — Principle: 원칙과 명제
3부 — Inability: 인간의 무능력과 FCF
4부 — Christ: 그리스도 안에서의 해답
5부 — HP (Homiletical Point): 복음 동기 적용
결론 — 초청, 강압 없는 마무리
```

## 그리스도 연결 방법

| 본문 위치 | 연결 방법 |
|---|---|
| 구약 역사 | 예표론 (Typology) |
| 시편/지혜서 | 성취 (Fulfillment) |
| 예언서 | 약속-성취 (Promise-Fulfillment) |
| 서신서 | 직접 기독론 (Direct Christology, 예표 아님) |
| 묵시문학 | 완성 (Consummation) |
