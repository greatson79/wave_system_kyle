# Mode B — 서사 텍스트 설교 구조

창세기, 사사기, 사무엘, 열왕기, 복음서 사건, 사도행전 등 서사 텍스트에 적용한다.

---

## 기법 선택

### N기법 (귀납적 내러티브)

과거↔현재를 역동적으로 교차하며, M5-M6의 의도적 평행구조를 통해 **동일한 하나님이 오늘도 동일하게 구원하심**을 드러내는 귀납적 구조.

```
M1 — 본문의 사건을 전개하라 (본문 진입)
M2 — 본문의 위기를 보여주라 (긴장 고조)
M3 — 본문의 사건을 오늘날로 연관하라 (고대-현대 다리)
M4 — 본문의 위기가 오늘날의 위기임을 느끼게 하라 (FCF 체험)
M5 — 본문의 구원자 하나님과 나타난 믿음의 반응을 보여주라
M6 — 동일한 구원자 하나님과 오늘 필요한 믿음의 반응을 제시하라 (HP)
```

**M5-M6 평행구조 원칙:**
> M5(본문)와 M6(오늘)은 의도적 평행을 이룬다. M5에서 드러난 하나님의 구원 행위와 본문 인물의 믿음의 반응이, M6에서 오늘의 청중에게 동일한 하나님의 구원과 필요한 믿음의 반응으로 제시된다. 이 평행이 N기법의 설득력의 핵심이다.

**M4 체험 원칙:**
> M4는 정보 전달이 아니다. 청중이 본문의 위기를 자신의 위기로 **체험**하게 하는 단계다. "이것이 당시 문제였습니다"가 아니라, 청중이 "이것이 바로 나의 문제다"라고 느끼게 해야 한다.

### 2ST기법 (Story Telling → Spiritual Truth)

```
1st ST — Story Telling (본문의 이야기 전달):
  1-1. 본문 진입 (텍스트 내러티브)
  1-2. 구속사적 맥락
  1-3. 인물의 주변성 (marginality)
  1-4. 놀라움 극대화
  ⚠️ 핵심 원칙: 연관성이나 적용은 포함하지 않는다. 순수하게 이야기만 전달한다.

전환 다리:
  하나님의 성품을 통한 전환 (행동 명령 없음)
  전환 문장을 사용하여 1st ST와 2nd ST를 자연스럽게 연결한다.

2nd ST — Spiritual Truth (영적 진리와 적용):
  2-1. 하나님 중심 진술
  2-2. 핵심 진리를 대지 형태로 제시 (2-3개)
  2-3. 앞의 이야기를 요약하고 중요한 부분을 심화
  2-4. 질문형 적용 — 연관성을 제시하고 적용점을 제안

결론:
  초청, 강압 없이, 기도와 신뢰로 마무리
```

**1st ST / 2nd ST 분리 원칙:**
> 1st ST에서는 본문의 이야기에만 집중한다. 적용, 교훈, 현대적 연관을 섞지 않는다. 청중이 이야기에 먼저 충분히 빠져들게 한 후, 2nd ST에서 영적 진리와 삶의 적용으로 전환한다. 이 분리가 2ST기법의 힘이다.

## 서론 지침

서론은 청중의 세계에서 본문으로 진입하는 관문이다. 예화 일반 규칙(`rules/illustration.md`)에 추가하여 Mode B에서는 다음을 적용한다:

| 우선순위 | 유형 | 설명 |
|---------|------|------|
| **1순위** | 명언 | 잘 알려진 영향력 있는 인물의 명언을 우선 사용 |
| 2순위 | 인문학적 스토리 | 문학, 영화, 일상에서 온세대가 공감할 수 있는 이야기 |
| 3순위 | 인용구/일화 | 성경 역사 또는 기독교 역사에서 영감을 주는 사건 |

**명언 사용 시 제외 기준:**
- 반기독교적 정서를 가진 인물의 명언은 제외한다
- 출처를 확인할 수 없는 명언은 제외한다 (→ `illustration.md` 신학적·내용적 경계 참조)

## Mode B 체크리스트

**공통:**
- [ ] 인물 영웅화 없음
- [ ] "여러분도 해야 합니다" 언어 없음
- [ ] 주어는 항상 하나님
- [ ] 예화가 진리를 대체하지 않음
- [ ] 죄책감으로 끝나지 않음 — 기도와 신뢰로 마무리
- [ ] 서론에 명언 또는 인문학적 예화가 포함되었는가?

**N기법 추가 점검:**
- [ ] M4에서 청중이 본문의 위기를 자신의 위기로 체험하는가? (정보 전달이 아닌 체험)
- [ ] M5-M6 평행구조: 동일한 하나님, 동일한 구원 방식이 드러나는가?
- [ ] M5의 믿음의 반응 → M6의 오늘 필요한 믿음의 반응으로 자연스럽게 연결되는가?

**2ST기법 추가 점검:**
- [ ] 1st ST에서 적용이나 교훈을 섞지 않았는가? (순수 이야기만)
- [ ] 전환 문장이 자연스럽게 Story → Truth를 연결하는가?
- [ ] 2nd ST에서 영적 진리가 대지 형태로 명확히 제시되었는가?
