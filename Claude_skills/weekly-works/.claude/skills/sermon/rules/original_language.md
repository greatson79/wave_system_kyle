# 원어 활용 규칙

모든 설교 모드(A/B/C)에서 본문의 원어(히브리어/헬라어)를 다룰 때 적용한다.

---

## 목적

각 무브먼트(또는 설교 섹션)에서 핵심 원어 단어의 의미를 통해 본문 설명을 풍성하게 한다.

---

## 규칙

| 규칙 | 설명 |
|---|---|
| **한국어 읽기 병기 (필수)** | 원어 단어가 등장할 때마다 반드시 바로 옆에 한국어 발음을 괄호로 표기한다. 예: σκύβαλα(스퀴발라), ἐκ θεοῦ(에크 데우). 원어만 단독으로 표기하지 않는다 |
| **선별적 사용** | 무브먼트(또는 섹션)당 1-2개의 핵심 원어에 집중한다. 과도한 원어 나열은 피한다 |
| **의미 중심** | 어근·형태 나열이 아닌, 그 단어가 본문의 메시지를 어떻게 열어주는지에 초점 |
| **청중 접근성** | 원어를 소개할 때 청중이 이해할 수 있는 비유나 설명을 함께 제공한다 |
| **누적 효과** | 앞에서 소개한 원어가 뒤에서 다시 등장하며 의미가 깊어지는 구조를 지향한다 |
