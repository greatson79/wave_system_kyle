# Design Template Scout — 디자인 레퍼런스 서치 & 가이드 생성

콘텐츠의 주제·감성·타깃을 분석하여 웹에서 디자인 레퍼런스를 검색하고,
실제 제작에 바로 사용할 수 있는 **디자인 가이드**를 출력한다.

---

## When to Use

- 카드뉴스, PPT, 소셜미디어 포스트를 만들기 전 디자인 방향이 필요할 때
- "이 주제에 맞는 디자인 찾아줘" 류의 요청
- 기존 sns-cardnews 스킬 실행 전 디자인 가이드를 먼저 준비하고 싶을 때
- 새로운 콘텐츠의 비주얼 톤을 잡고 싶을 때

---

## Inputs

| 입력 | 필수 | 설명 |
|------|------|------|
| **콘텐츠 주제** | ✅ | 카드뉴스/PPT의 핵심 주제 (예: "섬김의 리더십", "AI 교육") |
| **콘텐츠 유형** | ✅ | `카드뉴스` / `PPT` / `인스타포스트` / `유튜브썸네일` |
| **타깃 오디언스** | 선택 | 20-40대, 청소년, 시니어 등 |
| **원하는 감성** | 선택 | 따뜻함, 모던, 역동적, 경건함 등 |
| **sermon-context.md** | 선택 | 설교 기반 콘텐츠인 경우 자동 분석 |

사용자가 최소한 **주제**만 제공해도 나머지는 AI가 추론한다.

---

## Outputs

| 산출물 | 파일명 | 설명 |
|--------|--------|------|
| 디자인 가이드 | `design-guide.md` | 컬러, 타이포, 레이아웃, 무드 가이드 |
| 레퍼런스 목록 | (design-guide.md 내 포함) | 검색된 디자인 레퍼런스 URL + 설명 |

---

## Protocol

### Phase 1: 콘텐츠 분석 (Content Analysis)

1. 사용자 입력에서 다음 요소를 추출한다:

   | 추출 항목 | 방법 |
   |-----------|------|
   | 핵심 주제 (Topic) | 사용자 입력 또는 sermon-context.md에서 추출 |
   | 감성 (Mood) | 주제에서 추론 또는 사용자 지정 |
   | 타깃 (Audience) | 사용자 지정 또는 기본값(20-40대) |
   | 플랫폼 (Platform) | 사용자 지정 (카드뉴스=인스타 1080×1080, PPT=16:9) |
   | 시즌/컨텍스트 | 현재 날짜 또는 교회력에서 추론 |

2. sermon-context.md가 제공된 경우:
   - CMT(Central Message of Text) → 핵심 주제
   - FCF(Fallen Condition Focus) → 감성 톤 (공감, 고통, 치유 등)
   - HP(Homiletical Purpose) → 메시지 방향

3. 추출 결과를 사용자에게 확인받는다:
   ```
   🔍 콘텐츠 분석 결과:
   - 주제: 섬김의 리더십
   - 감성: 따뜻함 + 겸손
   - 타깃: 20-40대 청년
   - 플랫폼: 인스타그램 카드뉴스 (1080×1080)
   - 시즌: 사순절

   이 방향으로 디자인 레퍼런스를 검색할까요?
   ```

### Phase 2: 디자인 레퍼런스 검색 (Design Reference Search)

→ 상세 전략은 `references/search-strategies.md` 참조
→ 플랫폼별 검색 가이드는 `references/platform-guide.md` 참조

1. **검색 키워드 생성** — 콘텐츠 분석 결과를 기반으로 다국어 검색 키워드를 조합한다:

   ```
   # 한국어 키워드 (국내 플랫폼용)
   KR_QUERIES:
     - "{주제} 카드뉴스 디자인 템플릿"
     - "{주제} {감성} 인스타그램 디자인"
     - "{시즌} 교회 카드뉴스"

   # 영어 키워드 (글로벌 플랫폼용)
   EN_QUERIES:
     - "{topic} social media card design {mood}"
     - "church {topic} instagram template"
     - "{topic} presentation design {mood} aesthetic"
   ```

2. **다중 소스 검색** — `search_web` 도구로 최소 3개 소스를 검색한다:

   | 우선순위 | 소스 | 쿼리 패턴 |
   |---------|------|----------|
   | 1 | Pinterest | `"pinterest {topic} {type} design"` |
   | 2 | Behance / Dribbble | `"behance {topic} social media design"` |
   | 3 | Canva | `"canva template {topic} {mood}"` |
   | 4 | 미리캔버스 | `"미리캔버스 {주제} 카드뉴스 템플릿"` |
   | 5 | Google (일반) | `"{topic} {type} design inspiration {mood}"` |

3. **검색 결과 수집** — 각 검색에서:
   - 상위 3-5개 결과의 URL과 설명 추출
   - 관련성이 높은 결과를 필터링
   - 디자인 스타일 키워드와 컬러 톤 메모

4. **상세 레퍼런스 분석** — 유망한 URL에 대해 `read_url_content`로 추가 정보 수집:
   - 색상 정보 (hex 코드 등)
   - 레이아웃 패턴 설명
   - 사용된 폰트 정보
   - 디자인 트렌드 키워드

### Phase 3: 디자인 방향 결정 (Design Direction Selection)

→ 디자인 분류 체계는 `references/design-taxonomy.md` 참조

1. 수집된 레퍼런스를 분석하여 **공통 디자인 패턴**을 추출한다:
   - 지배적인 컬러 톤
   - 반복되는 레이아웃 패턴
   - 타이포그래피 스타일
   - 그래픽 요소 (아이콘, 일러스트, 사진 등)

2. **2-3개의 디자인 방향**을 제안하고 사용자 선택을 받는다:
   ```
   🎨 디자인 방향 제안:

   [A] 미니멀 웜톤 — 베이지/크림 배경, 세리프 폰트, 여백 중심
       • Pinterest 레퍼런스 5건에서 발견된 패턴
       • 따뜻하고 고급스러운 느낌

   [B] 모던 다크 — 딥네이비 배경, 산세리프 폰트, 강조 컬러 포인트
       • Behance 디자인 3건에서 발견된 패턴
       • 세련되고 임팩트 있는 느낌

   [C] 그래디언트 감성 — 부드러운 그래디언트 배경, 둥근 모서리
       • Canva 인기 템플릿에서 발견된 트렌드
       • 젊고 친근한 느낌

   어떤 방향이 좋으시겠어요? (A/B/C 또는 조합)
   ```

3. 사용자가 선택하지 않으면 콘텐츠 분석 결과를 기반으로 **가장 적합한 방향을 자동 결정**한다.

### Phase 4: 디자인 가이드 출력 (Design Guide Generation)

선택된 방향을 기반으로 `design-guide.md`를 생성한다.

**디자인 가이드 필수 포함 항목:**

```markdown
# 🎨 Design Guide: [콘텐츠 제목]

> 생성일: [날짜] | 스킬: design-template-scout

## Quality Gates

### Q1: 검색 품질
- 최소 3개 소스에서 레퍼런스를 수집했는가?
- 검색 결과가 콘텐츠 주제와 관련이 있는가?
- 한국어 + 영어 검색을 모두 수행했는가?

### Q2: 가이드 완성도
- 컬러 팔레트에 hex 코드가 포함되어 있는가?
- 타이포그래피 추천이 구체적인가? (폰트명 + 사이즈)
- 레이아웃 패턴이 명확한가?
- CSS 변수가 바로 사용 가능한 형태인가?

### Q3: 실용성
- 생성된 가이드로 실제 디자인 작업이 가능한가?
- sns-cardnews 스킬이 이 가이드를 참조하여 HTML을 생성할 수 있는가?

## Error Handling

| 상황 | 대응 |
|------|------|
| 검색 결과 부족 | 키워드를 변형하여 재검색 (최대 3회) |
| 특정 소스 접근 불가 | 다른 소스로 대체, 사용자에게 알림 |
| 콘텐츠 주제 모호 | 사용자에게 명확화 요청 (최대 2개 질문) |
| sermon-context.md 없음 | 사용자 입력만으로 진행 |

---

## Language Rules

- **SKILL.md 내부 지시**: English (AI 성능 최적화)
- **사용자 대면 출력**: Korean (design-guide.md, 제안 메시지)
- **검색 키워드**: Bilingual (한국어 + 영어 병행)
