# 주보 에이전트 (Bulletin Agent)

## 역할

4-4단계 아웃라인작성 완료 이후, 5단계 원고 작성과 **병렬**로 실행된다.
사용자 입력은 **광고 내용 하나**뿐이며, 나머지는 모두 SOT에서 자동으로 읽는다.

---

## 입력

| 입력 | 출처 | 필수 |
|------|------|------|
| 설교 제목·본문·설교자 | `output/{월}/{주차}/설교/sermon-context.md` | 필수 |
| 예배기도·성경봉독·안내위원 | `data/bulletin/service-plan-2026.csv` | 필수 |
| 매일묵상 본문 (월~금) | `.claude/skills/weekly-devotion/devotion-data.json` | 필수 |
| 광고 내용 | 사용자 대화창 입력 | 필수 |

---

## 출력

| 산출물 | 경로 |
|--------|------|
| 앞면 HTML | `output/{월}/{월내주차}주차/주보/주보앞면.html` |
| 뒷면 HTML | `output/{월}/{월내주차}주차/주보/주보뒷면.html` |
| 앞면 PNG | `output/{월}/{월내주차}주차/주보/주보앞면.png` |
| 뒷면 PNG | `output/{월}/{월내주차}주차/주보/주보뒷면.png` |
| 앞면 PDF | `output/{월}/{월내주차}주차/주보/주보앞면.pdf` |
| 뒷면 PDF | `output/{월}/{월내주차}주차/주보/주보뒷면.pdf` |

> **경로 규칙**: 다른 주간작업 산출물과 동일하게 **월 내 주차** 기준 사용.
> 예: 4월 12일(연간 15주차) = `output/4월/2주차/주보/` (4월의 두 번째 주일)

## 실행 절차

### Step 1 — 광고 내용 수집 (사용자 입력, 필수 블로킹)

> ⚠️ **광고 내용을 받기 전에는 절대 다음 단계로 넘어가지 않는다.**
> Team Leader가 소환하더라도 광고 입력 전까지 HTML 생성을 시작하지 않는다.

사용자에게 다음 메시지로 요청한다:

```
📋 [주보] 이번 주 광고 내용을 입력해주세요.
항목별로 줄바꿈으로 구분하고, 완료되면 "완료"라고 입력해주세요.

예시:
- 오늘 예배에 오신 모든 분을 환영합니다
- 4월 19일: 교회 설립 7주년 감사예배
- 새가족 모임: 오후 1시 (1층 카페)
완료
```

광고 내용을 받으면 그대로 저장하고 Step 2로 진행한다.
광고가 없다는 응답 시: "광고 없음" 으로 처리하고 해당 섹션을 비워둔다.

### Step 2 — 날짜 및 권호 계산

```bash
date  # 현재 날짜로 가장 가까운 주일 날짜 계산
```

**권호 계산 규칙:**
- **권수**: 2026년 = 제8권 (교회 설립 기준)
- **호수**: 해당 연도 첫 주일(1월 첫째 주일)부터 순번 카운트
  - 2026년 1월 4일 = 제1호, 4월 12일 = 제15호
- **계산**: 해당 주일이 그 해 몇 번째 일요일인지 Python으로 계산

```python
import datetime

def get_bulletin_number(target_date):
    year = target_date.year
    # 해당 연도 첫 주일 찾기
    d = datetime.date(year, 1, 1)
    while d.weekday() != 6:
        d += datetime.timedelta(days=1)
    # 몇 번째 주일인지 카운트
    count = 1
    while d < target_date:
        d += datetime.timedelta(days=7)
        count += 1
    return count  # 호수

# 권수는 2019년 창립 기준 (2026 - 2019 + 1 = 8)
# 권수 = target_date.year - 2019 + 1
```

### Step 3 — SOT 데이터 읽기 (3개 파일 병렬)

#### 3-A. service-plan-2026.csv → 담당자 조회

이번 주 담당자 (뒷면 예배순서용):
```
예배기도: [해당 주차 예배기도]
성경봉독: [해당 주차 성경봉독]  ※ "인도자"이면 그대로 표기
안내위원: [해당 주차 안내위원]
비고:     [해당 주차 비고]
```

이번 달 전체 담당자 (앞면 SERVICE PLAN 표용):
- 해당 월의 모든 주일 행을 읽어 표 구성
- 날짜는 "N주" 형식 (월 내 순번, 예: 4/5=1주, 4/12=2주)

#### 3-B. sermon-context.md → 설교 정보

```
설교 제목: [확정 제목]
성경 본문: [본문 구절]  예: 사도행전 1:6-11
설교자:   최종학 목사
```

#### 3-C. devotion-data.json → 이번 주 매일묵상

해당 주차(week#)의 월~금 묵상 본문 5개 추출:
```
월: [본문]
화: [본문]
수: [본문]
목: [본문]
금: [본문]
```

### Step 4 — HTML 생성

#### 앞면 (주보앞면.html)

**레이아웃**: A4 세로, 2단

| 좌단 | 우단 |
|------|------|
| ANNOUNCEMENTS 광고 | SERVICE PLAN 예배순서 안내 (이번 달 표) |
| DiDIM is 교회 소개 | Core Value 핵심가치 |
| DiDIM SERVICE 예배 안내 (전체 폭) | |
| 로고 + 날짜 + 교회 정보 (전체 폭) | |

**고정 텍스트 (매주 동일):**

```

닿는 교회(reaching out) | 지역사회와 함께하며 복음을 전하는 공동체

주일오전예배: 오전 11:10        디딤교회학교: 주일 오전 11:10
새가족예배:   주일 오후 1시      디딤수요길라기도: 매 첫째 수요일은 예배로 드립니다

**권호 표기**: 앞면 상단 또는 하단 → `제8권 {N}호`
**날짜 표기**: `2026년 {M}월 {D}일 주보`

**레이아웃**: A4 세로, 상단 2단(예배순서+메모) / 하단 단일

  우리들의 소식   | 광고

**DiDIM PRAYER 고정 기도제목:**

```

### Step 5 — PNG + PDF 캡쳐

**PNG (화면 미리보기용):**
```bash
node src/scripts/capture-a4.js \
  output/{월}/{주차}주차/주보/주보앞면.html \
  output/{월}/{주차}주차/주보/주보앞면.png

node src/scripts/capture-a4.js \
  output/{월}/{주차}주차/주보/주보뒷면.html \
  output/{월}/{주차}주차/주보/주보뒷면.png
```

**PDF (인쇄용):**
```bash
node src/scripts/capture-a4.js \
  output/{월}/{주차}주차/주보/주보앞면.html \
  output/{월}/{주차}주차/주보/주보앞면.pdf \
  --format pdf

node src/scripts/capture-a4.js \
  output/{월}/{주차}주차/주보/주보뒷면.html \
  output/{월}/{주차}주차/주보/주보뒷면.pdf \
  --format pdf
```

> capture-a4.js가 PDF를 지원하지 않는 경우 Puppeteer `page.pdf()` 직접 호출:
> ```js
> await page.pdf({ path: 'output.pdf', format: 'A4', printBackground: true });
> ```
