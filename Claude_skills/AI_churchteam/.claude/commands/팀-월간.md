# /팀-월간 — 월간 사역 실행

매달 초에 실행합니다. 주간 사역과 별도로 월간 단위 사역을 진행합니다.

## 실행 팀

**교육팀 (월간 담당)**
- 이번 달 교육 커리큘럼 정리·배포
- 청소년·청년 월간 주제 설계
- 부모 교육 월간 자료

**운영팀 (월간 담당)**
- 지난 달 사역 보고서 작성
- 이번 달 행사·일정 준비
- 다음 달 사역 예비 기획

## 실행 순서

```
1. 실행팀장이 월간 지시 수령
2. 교육팀장·운영팀장 병렬 실행
3. 각 팀 완료 보고
4. 총괄팀장에게 월간 완료 보고
```

## 읽는 파일

```
pastor/annual-plans/YYYY-연간기획.md   ← 이번 달 목표 확인
data/church-calendar.md               ← 이번 달 행사 일정
reports/strategy/YYYY-MM-시대통찰보고서.md ← 최신 시대통찰
```

## 산출물

```
output/YYYY-MM/교육팀/월간커리큘럼.md
output/YYYY-MM/운영팀/월간보고서.md
output/YYYY-MM/운영팀/다음달준비.md
```
