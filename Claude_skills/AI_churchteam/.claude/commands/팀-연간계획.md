# /팀-연간계획 — 연간목회계획 작성

연간목회계획을 두 단계로 작성합니다.

## 1층 — 연간방향 (전략팀 + 담임목사님)

미래목회전략팀이 목회철학과 시대통찰을 바탕으로 올해 큰 방향의 초안을 작성하고
담임목사님이 검토·확정합니다.

```
산출물: pastor/annual-plans/YYYY-연간방향.md
예: pastor/annual-plans/2026-연간방향.md
```

**포함 내용:**
- 올해 핵심 주제·키워드 (1-2개)
- 핵심 가치 흐름 (예: 예배→공동체→섬김→제자)
- 절기별 강조점
- 시대적 도전과 목회적 응답 방향

## 2층 — 연간기획 (사역기획팀)

연간방향을 기반으로 사역기획팀이 구체적 실행 계획을 구성합니다.

```
산출물: pastor/annual-plans/YYYY-연간기획.md
예: pastor/annual-plans/2026-연간기획.md
```

**포함 내용:**
- 분기별 사역 계획
- 월간 주요 사역 일정
- 팀별 역할 배분
- 특별 행사·절기 기획

## 작성 순서

```
1단계: /팀-전략분석 실행 (시대통찰 보고서 발행)
2단계: 전략팀이 연간방향 초안 작성
3단계: 목사님 검토·수정·확정
4단계: 기획팀이 연간기획 구체화
5단계: 목사님 최종 승인
```

## 참고자료 업로드
