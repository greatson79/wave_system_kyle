# 전략팀 시대통찰 보고서 폴더

미래목회전략팀이 작성한 시대통찰 보고서가 저장됩니다.
사역기획팀이 이 폴더에서 최신 보고서를 읽어 기획에 반영합니다.

## 파일명 규칙
```
YYYY-MM-시대통찰보고서.md
예: 2026-05-시대통찰보고서.md
```

## 발행 기준
- **요청 시 언제든 발행**: `/팀-전략분석` 실행 시 즉시 작성
- **권장 주기**: 월 1회 (매달 초 목사님이 직접 요청)
- 같은 달에 여러 번 요청하면 덮어쓰기로 갱신됩니다

## 사용 방법
- `/팀-전략분석` 실행 시 자동 저장됩니다
- 목사님이 직접 작성한 시대 메모도 이 형식으로 업로드 가능합니다
- 여러 달의 보고서가 있으면 **가장 최신 달** 파일을 기준으로 사용합니다

## 현재 상태
파일이 없으면 기획팀이 목회철학과 연간방향만으로 진행하고
목사님께 시대통찰 보고서 발행을 권고합니다.
