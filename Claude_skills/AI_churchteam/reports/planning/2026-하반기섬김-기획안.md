# P-3: 하반기 섬김 실천 + 제자훈련 연계 기획안

**기준일**: 2026-06-10 | **담당**: 사역기획팀 메시지정렬관 | **신학 근거**: 막 10:45 / 행 1:8

---

## 전제 신학 선언

> 하반기 사역은 8/16 파송 예배의 **연장**이다. 프로그램이 아니라 파송된 삶의 궤적이다.
> 섬김은 칭의의 결과이며, 제자훈련은 파송된 자의 내면 형성이다. 두 축은 분리되지 않는다.

## 1. 섬김 1차: 장애인 시설 방문 봉사 (9–10월)

### 기본 틀

| 항목 | 내용 |
|------|------|
| **시기** | 9월 넷째 주 또는 10월 첫째 주 (토요일 오전 4시간) |
| **대상 기관** | 6월 후원금 전달 기관 (기존 관계 연속) |
| **참여 규모** | 15–25명 (청장년·중장년·청소년 세대 혼합팀) |
| **형태** | 방문 봉사 — 환경 정리·식사 보조·여가 활동 동행 |
| **담당자** | 운영팀장 + 청소년 지도자 1명 (세대 통합 접점 확보) |

### 준비 사항 (월별)

| 시기 | 준비 내용 |
|------|----------|
| **8월** | 기관 담당자 연락 — 방문 날짜·필요 인원·요청 사항 확인 |
| **9월 1–2주** | 참여자 모집 (자발적 초대, 의무 아님을 명시) |
| **9월 3주** | 준비 모임 — 기관 소개, 복음적 동기 나눔, 주의 사항 안내 |
| **방문 당일** | 팀 기도 (10분) → 봉사 (3시간) → 마무리 감사 기도 (10분) |

### 신학적 의미 부여 방법

- **복음 연결**: 방문 전 주 설교 또는 수요 기도회에서 막 10:45 재확인 — "우리가 이 기관을 찾는 이유는 그리스도께서 먼저 우리를 찾으셨기 때문입니다"
- **관계 연속성 강조**: 6월 후원금 전달 → 9월 방문 → 향후 정기 관계로 이어지는 흐름을 성도들에게 명시적으로 제시 ("우리는 이번 한 번으로 끝내지 않습니다")
- **금지선**: "봉사 점수", "우리가 도와주는 것" 언어 사용 금지. "함께 시간을 보내는 것"으로 프레이밍

### 피드백·나눔 장치

| 도구 | 시기 | 방법 |
|------|------|------|
| 현장 기록 | 방문 당일 | 참여자 2–3명이 사진·한 문장 감사 메모 수집 |
| 주일 나눔 | 방문 후 첫 주일 | 예배 광고 시간 3분 — 참여자 1인 간증 (결단 촉구 아닌 경험 나눔) |
| 소그룹 연결 | 방문 후 2주 이내 | 제자훈련 3단계 소그룹에서 "내가 본 것" 나눔 (요 21:24 연결) |
| 기관 이름 기억 | 상시 | 주보 기도 제목란에 기관명 주기적 게재 |

## 2. 섬김 2차: 추수감사 연계 지역사회 나눔 (11월)

### 기본 틀

| 항목 | 내용 |
|------|------|
| **시기** | 11월 셋째 주 주일 (추수감사절 주간) |
| **형태** | 교회 안 준비 → 지역사회 배분 (이중 구조) |
| **대상** | 화성시 관내 독거노인·저소득 가정 (지자체 연계 또는 기존 네트워크) |
| **규모** | 50–80 세대 물품 전달 목표 |
| **참여 방식** | 주일 예배 후 전 성도 참여 가능 (가족 단위 권장) |

### 추수감사절 연계 방식

| 단계 | 내용 | 신학 연결 |
|------|------|----------|
| **11/15 주일 예배** | 추수감사 설교 — 신 8:10–18 "주신 자가 누구인가" | 감사의 근거를 하나님께 귀속 |
| **예배 후 준비** | 성도들이 준비해 온 물품 포장 (가족·소그룹 단위) | 함께하는 행위 자체가 공동체 기억 |
| **오후 전달팀 출발** | 5–8개 팀으로 나눠 전달 | 행 1:8 지리 구조 — "예루살렘 → 유대" |
| **저녁 귀환 나눔** | 각 팀 대표 1인 보고 (3분) → 합동 감사 기도 | 우리가 본 것을 증언 |

### 지역사회 접근 방법

- **1안 (기존 채널 활용)**: 화성시 복지관·사회복지사와 협력 — 실제 필요 가정 목록 수령
- **2안 (관계 확장)**: 1차 섬김 기관 (장애인 시설) 네트워크 통해 연계 기관 소개 요청
- **준비 금지사항**: 교회 로고·선교 스티커 물품 부착 금지 (받는 자의 존엄 우선)

### 피드백·나눔 장치

| 도구 | 시기 | 방법 |
|------|------|------|
| 팀 사진 + 한 줄 | 당일 저녁 | 카카오 채널 또는 주보 다음 주 게재 |
| 감사 편지 | 11월 넷째 주 | 물품 전달받은 분 중 원하시는 분 감사 메모 — 교회 게시판 |
| 연간 회고 연결 | 12월 첫째 주 | 연말 예배에서 1년 섬김 흐름 (6월→9월→11월) 사진 슬라이드 3분 상영 |

## 3. 제자훈련 + 섬김 병행 설계 (월별 흐름)

### 설계 원칙

> 제자훈련은 섬김의 동기를 정화하는 내면 작업이다. 훈련과 실천이 분리되면 훈련은 지식 축적이 되고, 실천은 봉사 동원이 된다.

### 3단계: 말씀과 기도 (9–10월)

| 주차 | 훈련 내용 | 섬김 연결 포인트 |
|------|----------|----------------|
| 9/1주 | 말씀 읽기의 신학 — 왜 성경을 읽는가 | 수련회 복음 회고: "우리가 본 것" |
| 9/2주 | 기도의 구조 — 탄원·감사·중보 | 1차 섬김 기관을 위한 중보 기도 실습 |
| 9/3주 | 고난 본문 묵상 (막 10:32–45) | 방문 봉사 준비 — 동기 점검 나눔 |
| 9/4주 | **1차 방문 봉사** | 현장 경험 |
| 10/1주 | 방문 후 말씀 나눔 — "내가 본 것" | 경험을 말씀으로 해석 |
| 10/2주 | 기도 심화 — 특정 사람을 위해 이름 불러 기도 | 만난 분들 이름 기억하여 기도 |
| 10/3주 | 말씀 암송 + 삶 적용 발표 | 소그룹 내 상호 격려 |
| 10/4주 | 3단계 수료 — 4단계 소개 | 11월 2차 섬김 비전 나눔 |

### 4단계: 공동체 훈련 (11–12월)

| 주차 | 훈련 내용 | 섬김 연결 포인트 |
|------|----------|----------------|
| 11/1주 | 공동체란 무엇인가 — 행 2:42–47 | 교회가 왜 함께 나누는가 |
| 11/2주 | 은사 발견 — 공동체를 위한 나의 역할 | 2차 섬김 팀 구성 자원 |
| 11/3주 | **2차 섬김 (추수감사 나눔)** | 공동체 전체 참여 |
| 11/4주 | 섬김 경험 신학적 해석 | "우리가 행한 것이 복음과 어떻게 연결되는가" |
| 12/1주 | 선교적 공동체 — 행 1:8 재독 | 단기선교 비전 나눔 |
| 12/2주 | 4단계 수료 + 2027 단기선교 설명회 | 팀 구성 시작 |

### 월별 통합 일람표

| 월 | 제자훈련 | 섬김 실천 | 통합 연결점 |
|----|---------|---------|------------|
| 9월 | 3단계 — 말씀·기도 (전반) | 1차 방문 봉사 준비·실행 | 기도 실습 대상 = 방문 기관 |
| 10월 | 3단계 — 말씀·기도 (후반) | 1차 봉사 후 나눔 통합 | 경험 → 말씀 해석 |
| 11월 | 4단계 — 공동체 훈련 (전반) | 2차 추수감사 나눔 | 공동체 훈련의 현장 실습 |
| 12월 | 4단계 수료 + 단기선교 소개 | 단기선교 팀 구성 착수 | 훈련의 자연스러운 다음 단계 |

## 4. 2027 단기선교 준비 로드맵

### 신학 전제

> 단기선교는 행 1:8의 "땅 끝"이다. 출발은 결단이 아니라 보내심이다.
> 팀 구성은 "가고 싶은 자"를 모으는 것이 아니라 "보내심을 받은 자"를 분별하는 과정이다.

### 단계별 로드맵

| 시기 | 단계 | 주요 내용 | 담당 |
|------|------|---------|------|
| **2026년 12월** | 비전 선포 + 팀 소집 | 12/1주 제자훈련 연계 설명회 → 12/3주까지 관심자 명단 수집 | 기획팀장 |
| **2026년 12월** | 선교지 리서치 시작 | 협력 선교사·단체 접촉, 후보지 2–3곳 조사 | 전략팀 + 기획팀 |
| **2027년 1–2월** | 팀 확정 + 훈련 시작 | 최종 팀원 확정 (목사님 승인), 월 2회 준비 모임 시작 | 팀 리더 |
| **2027년 3–4월** | 선교지 확정 + 준비 심화 | 선교지 최종 선정, 현지 문화·언어 기초, 후원 모금 시작 | 운영팀 |
| **2027년 5월** | 파송 예배 준비 | 전교회 파송 예배 기획 (8/15–16 수련회 파송 예배와 구조 동일) | 말씀팀·기획팀 |
| **2027년 6–8월** | 단기선교 실행 | 현지 사역 (기간·지역 확정 후 상세 계획) | 팀 전체 |
| **2027년 귀환 후** | 보고·통합 | 전교회 보고 예배, 경험 나눔, 다음 사이클 비전 연결 | 콘텐츠팀 + 말씀팀 |

### 팀 구성 원칙

| 원칙 | 내용 |
|------|------|
| **분별 우선** | "가고 싶다"가 아닌 "보내심을 느낀다"는 기준으로 담임목사님과 면담 |
| **세대 혼합** | 청소년·청장년·중장년 최소 각 1인 포함 권장 |
| **제자훈련 연계** | 4단계 수료자 우선 (훈련 없는 파송은 프로그램 참가가 됨) |
| **규모** | 첫 단기선교는 8–12명 (관리 가능한 규모 우선) |
| **후원 구조** | 팀원 개인 모금 + 교회 공동 후원 (비율은 재정위원회 협의) |

## 5. 각 섬김 후 피드백·나눔 장치 통합 설계

### 설계 원칙

> 나눔 장치의 목적은 "잘했다"는 칭찬이 아니라 **공동체가 함께 본 것을 기억**하는 것이다.
> 피드백은 다음 섬김을 위한 개선이 아니라, 복음이 어떻게 살아 움직였는지의 **증언**이다.

### 통합 나눔 도구 일람

| 도구 | 1차 섬김 (9–10월) | 2차 섬김 (11월) | 단기선교 귀환 후 |
|------|----------------|----------------|---------------|
| **현장 기록** | 참여자 사진 + 한 문장 | 팀별 사진 + 한 줄 | 현지 사진 + 날짜별 일지 |
| **주일 나눔** | 방문 후 첫 주일 3분 간증 | 당일 저녁 팀 보고 | 귀환 후 첫 주일 보고 예배 |
| **소그룹 연결** | 제자훈련 나눔으로 통합 | 4단계 공동체 나눔 | 전교회 소그룹 동시 나눔 주간 |
| **공동체 기억 축적** | 주보 기도 제목 + 기관명 | 감사 메모 게시판 | 선교지 사진 연간 전시 |
| **연간 회고** | 12월 연말 슬라이드 포함 | 12월 연말 슬라이드 포함 | 2027 연말 예배 통합 |

### 공동체 기억으로 쌓는 구조: 연간 타임라인

```
6월    후원금 전달 → 기관 이름 주보 등재 시작
        ↓
9월    방문 봉사 → 주일 간증 + 제자훈련 나눔
        ↓
11월   추수감사 나눔 → 감사 메모 게시판 + 팀 보고
        ↓
12월   연말 예배 — 1년 섬김 사진 슬라이드 (6월~11월)
                  → 단기선교 비전 선포로 연결
        ↓
2027년 단기선교 귀환 후 — 2026 섬김과 연결된 "땅 끝" 증언
```

### 나눔 진행 시 금지선

| 금지 언어 | 이유 | 대체 표현 |
|---------|------|---------|
| "우리가 큰 일을 했습니다" | 공로 귀속 | "우리가 함께 있었습니다" |
| "더 많이 해야 합니다" | 의무감 강화 | "이미 시작되었습니다" |
| "감동받으셨나요?" | 감정 자극 | "어떤 분의 얼굴이 기억에 남으시나요?" |
| "다음엔 더 잘 해봅시다" | 성과 중심 | "다음에도 함께하겠습니다" |
