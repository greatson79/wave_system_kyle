### 1. 중동 전쟁 3주차 — 호르무즈 위기

| 팩트 | 상세 |
|------|------|
| 브렌트유 | **$114/배럴** 돌파 |
| 카타르 LNG 단지 | 이란 미사일 피격 → 수리 **3~5년**, 연간 **$200억 손실** |
| 호르무즈 해협 | 이라크 "불가항력" 선언 — 세계 석유 수출의 **1/5** 통과 |
| 헬륨 공급 | 카타르(세계 30%) 중단 → 한국 헬륨 수입 **65%** 차질 |
| 이란 확전 | 디에고 가르시아 미영 기지에 중거리 탄도미사일 2발 발사(실패) |
| 정부 대응 | 원유 자원안보 위기경보 **'관심'→'주의'** 격상, 석유제품 수출 제한 검토 |

**핵심**: 단순 유가 급등이 아닌 **에너지 공급망 구조적 훼손**. 카타르 LNG 복구에 3~5년이 소요되므로 에너지 비용 상승은 중기적 상수.

#### 3/21 추가 전개

- **러시아-미국 협상**: 푸틴이 "이란 정보공유 중단 대신 우크라이나 지원 중단" 제안 → 트럼프 거부
- **이란 미사일 사거리**: 디에고 가르시아 기지(인도양) 공격 시도로 공개된 것보다 훨씬 긴 사거리 확인
- **호르무즈 해협**: 이라크 "불가항력(포스메저)" 선언 → 세계 석유 수출 1/5 통과 해로 사실상 마비
- **카타르 라스라판 LNG 단지**: 이란 미사일 피격 → 수리 3~5년, 연간 $200억 손실
- **트럼프**: 중동 군사 작전 종료 고려 발표, NATO 동맹국 호르무즈 파병 부족에 "겁쟁이" 비난
- **우크라이나**: FPV 드론으로 러시아 Ka-52 공격 헬기($1,600만 상당) 격추

## III. GTC 2026 — 엔비디아 풀스택 AI 혁명 (3/16~19)

### 베라 루빈(Vera Rubin) 플랫폼 — 7종 신규 칩, 5개 랙 시스템, 1기 슈퍼컴퓨터

사전·사후 훈련, 테스트 시점 확장, 실시간 에이전틱 추론까지 AI 전 단계를 단일 시스템으로 지원하는 **풀스택 AI 인프라**.

| 구성요소 | 핵심 성능 |
|----------|-----------|
| **루빈 GPU** | 블랙웰 대비 **1/4 GPU 수**로 MoE 모델 훈련, 토큰당 비용 **1/10**, 와트당 추론 **10배** |
| **베라 CPU** | 기존 대비 효율 **2배**, 속도 **50%↑**, 256개 탑재 랙 — 세계 최고 단일 스레드 성능 |
| **그록 3 LPU** | 에이전틱 저지연·대규모 컨텍스트 특화, 256개 프로세서 LPX 랙 — 메가와트당 추론 **35배** |
| **우주 모듈** | 스페이스-1 베라 루빈 — H100 대비 우주 AI 추론 **25배↑** |

- 후속 아키텍처: **파인만(Feynman)** 로드맵 제시
- 매출 목표: 블랙웰+루빈 누적 **최소 $1조** (전년 $5,000억에서 12개월 만에 2배 상향)
- 2025 회계연도 매출: 약 **$1,300억** → 3년 내 7배 증대 목표

### GTC 2026 4대 핵심 테마

1. **베라 루빈**: 차세대 아키텍처 → 중장기 성장 전망 강화
2. **피지컬 AI**: 로봇, 공장 자동화, 자율 시스템 → 데이터센터 넘어 산업 전반 확장
3. **추론(Inference)**: 학습에서 실사용 추론 단계로 시장 전환
4. **에이전트형 AI**: 자율 계획·실행 → 소프트웨어+생태계 장악
