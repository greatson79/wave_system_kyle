# Google Forms Apps Script 자동생성 판정

## 결론

- **기술적으로 가능**: `FormApp.create`와 문항·섹션·분기 API로 폼을 자동 생성할 수 있다.
- **소유·응답 귀속**: 주인님 Google 계정으로 Apps Script를 실행하므로 생성 Form과 응답 Sheet는 처음부터 그 계정 소유다.
- **주인님 작업**: 스크립트 전체 복사 → 새 Apps Script 프로젝트에 붙여넣기 → `createRuthRetreatForm` 실행.
- **예상 소요**: 생성·권한 승인은 약 5분, 공개 전 3경로 확인은 추가 약 5분.

## 권한 승인

최초 실행 시 통상 `권한 검토` → 계정 선택 → `허용`의 3단계다. Google 계정 또는 Workspace 관리자 정책에 따라 경고 화면이 추가될 수 있어 실제 클릭 수는 고정할 수 없다.

## 자동 구현 범위

- 정본 §1의 제목·서두·1~12번 문안·선택지·필수 여부
- 미성년 여부와 만 14세 미만 여부에 따른 3경로 분기
- 일반 개인정보 동의, 건강정보 별도 동의, 법정대리인 확인의 경로별 필수 처리
- 이메일 수집·응답 수정·결과 요약·질문 섞기 끄기
- 응답용 Google Sheet 생성·연결
- 생성 후 편집 URL·응답 URL·Sheet URL 출력
- 재실행 시 중복 Form·Sheet 생성 차단

정본의 12개 논리 문항은 변경하지 않았다. 조건부 표시를 위해 번호 없는 기술용 라우팅 문항 2개를 추가했다.

## 검증

- 로컬 모의 Forms API 테스트: `PASS`
- 검증 범위: 문안·선택지, 개인정보 설정, 3경로 목적지, 종결 제출, 필수 동의, 응답 Sheet 연결, 중복 실행 방지
- 시크릿 패턴 검사: 매치 0건
- 실제 Google 계정 실행: 주인님 계정 권한이 필요하므로 **미실행**

## 생성 후 수동 확인이 남는 항목

Apps Script Forms Service에서 완전히 제어되지 않는 새 응답 이메일 알림, 응답 사본, 현재 Forms의 응답자 접근 범위는 편집 화면에서 확인한다. 배포 전 성인·미성년·만 14세 미만 경로와 뒤로 가기 경로 변경 시 민감정보 미저장을 시험한다.
