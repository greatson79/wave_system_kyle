## 법적 게이트의 구현

두 안 모두 목회사역 정본의 3단 구조를 그대로 적용한다.

1. **일반 개인정보 동의:** 목적·항목·보유기간·거부권/불이익을 표시하고 필수 체크.
2. **건강정보 별도 동의:** 건강 특이사항이 있는 경우에만 민감정보 목적·항목·“행사 종료 즉시 파기”를 별도로 표시하고 필수 체크. 일반 동의와 합치지 않는다.
3. **만 14세 미만:** 법정대리인 성명·관계·연락처와 별도 동의를 받고 확인 기록을 남긴다.
4. **응급처치·병원 이송 동의:** 개인정보 동의와 별도 유지.

Google Forms에서는 보호자가 직접 제출하게 하고, 교회가 보호자 연락처로 확인한 뒤 확인자·시각만 최소 기록한다. 단순 체크만으로 법정대리인 신원 확인이 끝났다고 간주하지 않는다.

HTML 정식판에서는 보호자 휴대전화 OTP 또는 확인 링크와 확인시각을 저장하되, 인증번호 원문은 저장하지 않는다. 서버는 동의 버전·동의시각·receipt ID를 기록하고 DB write가 성공한 뒤에만 제출 완료를 반환한다.

## 단계 전환 원칙

- 1주차 Google 원응답을 HTML DB로 자동 이관하지 않는다. 저장처 변경에 대한 별도 고지·동의 없이 민감정보를 복제하지 않는다.
- HTML 개통 후 신규 응답만 새 개인정보 고지 아래 받는다.
- 두 기간의 운영 집계는 이름·연락처·기도제목·건강정보를 제거한 숫자만 합친다.
- 행사 종료 즉시 Google Forms·Sheet·내보내기본과 HTML DB·백업·로그를 각 보관처의 파기 체크리스트로 확인한다.
