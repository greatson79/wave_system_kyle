> 2026년 4월 21일 기준 | 전자금융과 디지털화폐 (호서대학교, 이중만 교수)
> 이 요약은 전체 보고서(`국내외_금융시장_현황분석_심층_2026.docx`)에서 반드시 알아야 할 핵심만 파트별로 압축한 것이다.

## PART 1. 이론 — 수업 핵심 개념 5가지

### ① 부분지급준비제도와 신용창조
- 은행은 예금의 **10%만 보유**, 나머지 90%를 대출 → 본원통화가 **통화승수 배**로 증식
- 예금 1,000원 → 최종 통화량 10,000원 (지급준비율 10% 기준)
- **뱅크런**: 동시 인출 → 시스템 붕괴 위험 내포
- **2020년 Fed QE**: 국채 대량 매입으로 본원통화 직접 공급 → 인플레이션 원인

### ② 기준금리 전달 메커니즘 (반드시 외울 것)
| 방향 | 경로 | 결과 |
|------|------|------|
| 금리 인하 | 이자율↓ → 소비(C)·투자(I)↑ | GDP↑, 인플레이션↑ 위험 |
| 금리 인상 | 이자율↑ → 소비(C)·투자(I)↓ | GDP↓, 인플레이션↓ |

- 콜금리 → CD금리 → COFIX → 대출금리 순으로 전이

### ③ 양적완화(QE) vs 테이퍼링(Tapering)
- **QE**: 제로 하한(ZLB) 도달 시 국채·MBS 직접 매입으로 유동성 공급 (비전통적 통화정책)
- **테이퍼링**: 경기 회복 시 QE 규모 점진 축소 → **테이퍼 탠트럼** (시장 금리 급등 충격) 동반
- **피벗**: 금리인상 → 인하로 방향 전환 (Fed 2024년 9월 선언)

### ④ 인플레이션 3가지 유형 — 2026년과 연결
| 유형 | 원인 | 2026년 해당 여부 |
|------|------|----------------|
| 수요 견인(Demand-Pull) | 통화량 급증, 소비 폭발 | 2022년 원인 (지금은 아님) |
| 비용 인상(Cost-Push) | 에너지·원자재 가격 상승, 관세 | **현재 주범** |
| 스태그플레이션 | 경기침체 + 고인플레이션 동시 | **2026년 현실화 중** |

- **디플레이션** → 저축의 역설(소비 줄수록 침체 심화) → 일본 '잃어버린 30년' 참고

### ⑤ GDP 모델 공식

```
GDP = C + I + (T − G) + (X − M)
```

| 항목 | 의미 | 핵심 포인트 |
|------|------|------------|
| C | 민간소비 | GDP의 最大 구성요소 (미국 68%, 한국 48%) |
| I | 기업투자 | 금리에 가장 민감 |
| (T−G) | 재정수지 = 세입−지출 | 적자면 음수, 국채 발행 증가 → 구축 효과 |
| (X−M) | 순수출 | 양수면 흑자, 관세·에너지 충격에 직격 |

> **구축 효과(Crowding-out)**: 재정적자 → 국채 발행↑ → 시장금리↑ → 민간투자(I)↓
> **오쿤의 법칙(Okun's Law)**: 실업률↑ → GDP↓, 반드시 연결해서 설명할 것

## PART 2. 2026년 글로벌 충격 — 2가지 핵심 사건

### ① 트럼프 관세 충격 (2025년 4월~)
- 실효관세율 **7.7%** — 1947년 이후 최고
- 미국 가구당 연간 부담: **$1,500**
- 장기 GDP 영향: **−6%**, 임금 **−5%** (Penn Wharton)
- 세계 GDP: −0.5%(2025), −0.7%(2026) (IMF)
- **파급 경로**: 수입품 가격↑ → C(소비) 위축 + I(투자) 관망 + (X−M) 악화 + 비용 인상 인플레이션

### ② 미-이란 전쟁 (2026년 2월 28일~)
- "에픽 퓨리" 작전 → 이란 핵시설 공습
- 호르무즈 해협 위협 (세계 원유 20% 통과), 하르그 섬 원유시설 파괴
- PPI 에너지 부문: **+8.5% (단 1개월 만에)** ← 역대급
- IEA 전략비축유 **4억 배럴** 방출 (사상 최대)
- **파급 경로**: 유가↑ → PPI↑ → (2~3개월 후) CPI↑ → 스태그플레이션 강화

## PART 3. 미국 금융시장 — 반드시 알아야 할 수치

| 지표 | 수치 | 해석 |
|------|------|------|
| GDP 성장률 (Q1 2026) | **+0.5%** (연율) | 직전 분기 4.4%에서 급락 |
| CPI (2026년 3월) | **3.3% YoY / +0.9% MoM** | 피벗 이후 재상승 — 위험 신호 |
| Core CPI | **약 3.5%** | '끈적한 인플레이션' 지속 |
| PPI (2026년 3월) | **4.0% YoY** | CPI의 2~3개월 선행 지표 |
| PPI 에너지 | **+8.5% MoM** | 2023년 8월 이후 최대 단월 상승 |
| 실업률 (2026년 3월) | **4.3%** (720만 명) | 상승 추세, 완전고용 기준 초과 |
| 신규 고용 | +178,000명 | 고점(50만 명) 대비 급감 |
| 연방부채 | **$36~37조** (GDP 대비 130%) | 2026년 $10조 만기 도래 |
| 분기 국채 발행 | **$5,780억** | 국채 수익률 고착, 구축 효과 심화 |
| 10년물 국채 수익률 | **4.5~5.0%** | 민간 투자 억제 수준 |
| Fed 기준금리 | **3.50~3.75%** (동결) | 2026년 1회 인하만 점도표 반영 |

**Fed 딜레마 핵심**:
- 금리 내리면 → CPI 3.3% → 인플레이션 재가속
- 금리 올리면 → GDP 0.5% → 마이너스 성장 위험
- 결론: **동결·관망** (어떤 선택도 부작용)

## PART 4. 한국 금융시장 — 반드시 알아야 할 수치

| 지표 | 수치 | 해석 |
|------|------|------|
| GDP 성장률 (2025년) | **0.7~1.0%** | HRI 0.7% 하향, 코로나 이후 최저 |
| GDP 전망 (2026년) | **1.9~2.1%** | 반도체 수출 회복 기대 |
| CPI (2025년) | **2.0%** | 한국은행 목표 달성 |
| CPI 전망 (2026년) | **2.1~2.2%** | 에너지 충격 반영 시 추가 상향 위험 |
| 실업률 | **2.8%** | 공식 완전고용, 청년실업 6~7%는 별개 |
| 기준금리 | **2.50%** (동결) | 6회 연속 동결 (2026년 2월 포함) |
| 국고채 발행 | **168조 원+** (2026년) | 에너지 보조금·방위비 증가로 초과 예상 |
| 국가채무비율 | GDP 대비 **약 50%** | 수치는 낮으나 증가 속도가 문제 |

**한국의 핵심 취약점**:
- 에너지 자급률 낮음 → 유가 40% 급등 = (X−M) 흑자 잠식 + PPI 상승 + 원화 약세
- 원화 약세 → 에너지 수입비용 추가 증가 → 악순환

## PART 5. GDP 모델 한미 비교 — 핵심 대조표

```
GDP = C + I + (T − G) + (X − M)
```

| 항목 | 미국 | 한국 | 공통 위험 |
|------|------|------|----------|
| C (소비) | 에너지·관세로 위축 | 에너지·물가로 실질소득↓ | 양국 소비 모두 압박 |
| I (투자) | AI 인프라가 지지, 주택 −2.1% | 반도체 지속, 건설 부진 | 지정학 불확실성이 발목 |
| (T−G) | −$2조+ (GDP −7%) | −100조 원 (GDP −4.5%) | 양국 대규모 적자 → 국채↑ → 구축 효과 |
| (X−M) | 관세 보복에도 수입 강세 → 무역적자 | 흑자 유지, 에너지 수입으로 축소 | 교역량 감소 공통 |

**스태그플레이션 조건 점검**:
- 조건 1 (높은 인플레이션): 미국 CPI 3.3%, PPI 4.0% ✅
- 조건 2 (경기침체): 미국 GDP 0.5% ✅
- **→ 2026년 스태그플레이션 조건 충족. Fed 의장 파월 공식 인정.**

## PART 6. 반드시 알아야 할 결론 5가지

### 1. PPI는 CPI의 2~3개월 선행 지표
PPI 에너지 +8.5% (2026년 3월) → **2026년 2분기 CPI 추가 상승 예고**

### 2. 비용 인상 인플레이션은 금리 인상으로 못 잡는다
- 2022년 인플레이션: 수요 견인 → 금리 인상이 유효
- **2026년 인플레이션: 비용 인상 (관세+에너지)** → 금리 인상해도 공급 비용은 그대로
- **근본 처방**: 관세 협상, 에너지 안보 해결 (공급 측 정책)

### 3. 국채 발행 폭증 = 구축 효과 심화
- 미국 2026년 국채 만기 $10조 + 방위비 증가 → 분기 $5,780억 발행
- 금리 동결해도 국채 공급 급증 → 10년물 수익률 4.5~5.0% 고착
- → 기업 투자(I) 억제 → GDP 추가 하방 압력

### 4. 한국은 에너지 수입 구조가 최대 리스크
- 반도체 수출로 번 외화를 에너지 수입이 잠식
- 유가 충격 → 원화 약세 → 에너지 수입비용 재상승 → 악순환
- **2026년 한국 경제의 핵심 취약 고리**

### 5. 전통적 통화정책의 한계
| 정책 | 인플레이션 | GDP | 평가 |
|------|-----------|-----|------|
| 금리 인하 | 재가속 위험 | 지지 | 불가 |
| 금리 동결 | 부분 억제 | 회복 지연 | 현재 선택 |
| 금리 인상 | 억제 | 마이너스 위험 | 불가 |

> **결론**: 스태그플레이션 환경에서 통화정책은 어떤 선택도 부작용이 있다.
> 에너지 안보, 관세 협상, 재정 준칙이 병행되어야 한다.
