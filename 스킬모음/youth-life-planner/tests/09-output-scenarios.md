# 출력 에이전트 테스트 시나리오

## SC-OUT-01: 청소년 카드 언어 수준
기대:
  ✅ 중학생 이해 가능 언어
  ✅ 실행 체크리스트 3개 + 날짜
  ✅ 격려 한 문장 마무리
  ❌ 어려운 전문 용어 금지

## SC-OUT-02: 사역자 플랜 필수 요소
기대:
  ✅ 개인정보 보호 문구 상단 첫 줄 고정
  ✅ 청소년 원문 입력 전체 보존
  ✅ 위기 신호 요약 섹션 (없으면 "없음")
  ✅ 후속 코칭 제안 포함

## SC-OUT-03: 저장 경로 안내
완료 시 기대:
  ✅ "output/youth-life-planner/{날짜}_{닉네임}/" 경로 안내
  ✅ md/txt/pdf 3가지 형식 안내
  ✅ pandoc 명령어 안내

## SC-OUT-04: 세션 컨텍스트 유실 시
입력: 이전 세션 결과 없이 /전체출력
기대:
  ✅ "이전 영역 결과 블록을 붙여넣으시면 이어서 진행합니다" 안내
