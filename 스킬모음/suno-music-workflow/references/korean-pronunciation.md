# 한국어 발음 최적화 가이드 (Korean Pronunciation Guide)

Suno AI에서 한국어 가사의 발음 품질을 높이기 위한 실전 가이드.

---

## Style Prompt 설정

한국어 곡 생성 시 Style Prompt에 아래 태그를 추가하면 발음 품질이 향상된다.

```
clear Korean pronunciation, Korean vocals
```

---

## 받침별 발음 위험도

Suno는 받침(종성)이 복잡한 음절에서 발음을 뭉개거나 잘못 처리하는 경우가 있다. 아래 표를 기준으로 가사 작성 시 위험 음절을 우회한다.

### 위험도 높음 — 가능하면 대체어 사용

| 받침 유형 | 예시 | 문제 | 대체 전략 |
|----------|------|------|----------|
| 겹받침 (ㄳ, ㄵ, ㄶ, ㄺ, ㄻ, ㄼ, ㄽ, ㄾ, ㄿ, ㅀ, ㅄ) | 삶, 읽다, 넓은, 없다 | 두 자음 중 하나가 탈락하는 규칙을 Suno가 틀림 | "삶" → "살아감", "넓은" → "넓디넓은" 또는 "큰", "없다" → "없어" |
| 연음 필수 (받침+모음) | 음악을, 먹으면, 놓아줘 | 연음 처리가 어색해짐 | 연음이 자연스러운 구어체로 교체. "먹으면" → "먹으면" (유지 가능), 문제 시 "먹을 때" |
| ㄹ 받침 + 자음 | 걸고, 알겠어, 말도 | ㄹ 발음이 굴리거나 뭉개짐 | 짧은 어절로 분리. "알겠어" → "알아" |

### 위험도 중간 — 주의하며 사용

| 받침 유형 | 예시 | 주의사항 |
|----------|------|---------|
| ㄱ, ㄷ, ㅂ 받침 | 먹, 걷다, 잡다 | 대체로 잘 처리하나, 빠른 템포에서 뭉개질 수 있음 |
| ㅇ 받침 (비음) | 강, 봉, 성 | 비교적 안정적. 비음은 Suno가 잘 처리 |
| ㄴ, ㅁ 받침 | 문, 감, 손 | 안정적 |

### 위험도 낮음 — 자유롭게 사용

| 받침 유형 | 예시 | 비고 |
|----------|------|------|
| 받침 없음 (모음 끝) | 나, 하루, 너에게 | 가장 안정적. 코러스 훅에 적합 |
| 모음 연결 | 아이야, 우리야 | 멜로디에 자연스럽게 매핑 |

## 음절 수별 가이드

| 줄당 음절 수 | 판정 | 설명 |
|-------------|------|------|
| 5~8음절 | 최적 | 멜로디 매핑이 가장 자연스러움. 코러스에 특히 적합 |
| 9~12음절 | 양호 | Verse에 적합. 음절이 고르면 안정적 |
| 13~15음절 | 주의 | 빠른 템포가 아니면 보컬이 서두르거나 뭉개짐 |
| 16음절 이상 | 금지 | 거의 확실히 발음 문제 발생. 2줄로 분리 |

### 음절 균일성 규칙

같은 섹션 내에서 줄별 음절 수를 ±2 범위로 맞추면 리듬이 안정된다.

```
좋은 예 (7-8-7-8):
새벽 두 시 반 (7)
부엌 불빛 아래 (8)
냄비 하나 올려 (7)
보글보글 끓여 (8)

나쁜 예 (5-14-6-12):
새벽 두 시 (5)
부엌에 혼자 서서 불을 켜고 (14)
물을 올려 (6)
라면 봉지를 뜯어서 넣었어 (12)
```

## 호흡·구두점 활용

가사에 마침표(`.`)와 쉼표(`,`)를 넣으면 Suno가 호흡 타이밍을 인식한다.

| 구두점 | 효과 | 예시 |
|--------|------|------|
| 쉼표 `,` | 짧은 호흡 (0.3~0.5초) | "너와 함께라면, 두렵지 않아" |
| 마침표 `.` | 긴 호흡 (0.5~1초) | "괜찮아. 다 지나갈 거야" |
| 줄바꿈 | 프레이즈 분리 | 한 줄 = 한 프레이즈 원칙 |

**주의**: 느낌표(`!`), 물음표(`?`)는 보컬 톤에 영향을 줄 수 있지만 예측 불가능. 가사 자체로 감정을 전달하는 것이 안전하다.

## 한영 혼용 발음 전략

한국어와 영어를 섞을 때 발음 전환 지점에서 어색함이 생길 수 있다.

### 안전한 혼용 패턴

```
한국어 줄 → 영어 줄 (줄 단위 전환이 가장 안정적)

[Chorus]
라면에 계란 넣어 말어
Tonight is mine
이 완벽한 한 그릇 앞에
Everything's alright
```

### 위험한 혼용 패턴

```
한 줄 안에서 한영 전환 (발음 경계에서 뭉개짐 위험)

너와 함께 forever  ← 위험
오늘 밤 let's go    ← 위험
```

한 줄 안에서 혼용해야 한다면, 영어 단어를 줄 끝에 배치하는 것이 상대적으로 안전하다.

## 발음 문제 발생 시 대응 체크리스트

Suno에서 생성한 곡의 한국어 발음이 어색할 때 순서대로 시도한다.

1. **Style Prompt에 `clear Korean pronunciation` 추가** — 가장 먼저 시도
2. **문제 음절의 받침 확인** — 겹받침이면 대체어로 교체
3. **줄당 음절 수 확인** — 13음절 이상이면 2줄로 분리
4. **음절 균일성 확인** — 같은 섹션 내 줄별 음절 차이 ±2 이내로 조정
5. **쉼표로 호흡 삽입** — 긴 구절 중간에 `,` 추가
6. **해당 구간만 Replace Section** — Suno Studio에서 문제 구간만 재생성
7. **그래도 안 되면 영어로 교체** — 코러스 훅은 영어가 가장 안정적
