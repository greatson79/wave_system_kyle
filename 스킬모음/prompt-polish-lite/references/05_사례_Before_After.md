# 사례 Before / After
*범용 프롬프트 다듬기 예시 2건. 진단·처방·재작성 흐름을 익히는 학습용.*

---

## 사례 1 — 단발 프롬프트 (콘텐츠 작성 요청)

### Before

```
블로그 글 써줘. 생산성에 관한 거.
```

### 진단

| 축 | 점수 | 근거 |
|---|---|---|
| V | 1 | 역할·청중·톤 없음 |
| L | 0 | 기준·금지 조건 전무 |
| M | 0 | 맥락 변수 없음 |
| C | 1 | 트리거만 있고 분기 없음 |
| F | 0 | 단계 분리 없음 |
| B | 0 | 사전정보 없음 |
| G | 0 | 출력 형식·분량 미지정 |

**총점 2/21 — 처음부터 다시**

**품질 점검:** 역할·청중·목적 불명확 → 보강 필수.

### After

```
**역할:** 콘텐츠 전략가 겸 블로그 작가

**청중:** 30~40대 직장인 / 시간이 부족한 사람 / 실용적인 팁을 원함

**톤:** 간결함 + 짧은 문장 + 공감 먼저, 실용 정보로 마무리

**주제:** 직장인이 바로 적용할 수 있는 생산성 루틴

**사전정보:**
- 선호 출처: 검증된 연구·실제 사례
- 피해야 할 것: 추상적 동기부여 문구, 실행 불가한 조언

**처리 순서:**
1단계 — 독자 고민 장면 1개로 오프닝
2단계 — 핵심 루틴 3가지 제시 (각각 이유 + 실행 방법)
3단계 — 바로 오늘부터 할 수 있는 한 가지로 마무리

**이상적 출력:** 읽는 데 3분, 적용 결정까지 1분
**피해야 할 출력:** "노력하면 됩니다"식 결론, 500자 이상 장문 단락

**출력 형식:**
[제목 후보 3개]
[도입 — 독자 공감 장면, 3문장]
[본문 — 루틴 3가지, 각 150자 내외]
[마무리 — 오늘 바로 할 한 가지, 2문장]

**완성도 기준:** 바로 발행 가능한 수준
```

**처방 근거:** V·L·M·F·B·G 전 축 보강. 3-Role 기법(V) + 사전정보 블록(B) + 4단 구조(F) 적용.

## 사례 2 — 커스텀 GPT·Gem 인스트럭션 보강

### Before

```
## 고객 응대 도우미

고객 문의에 친절하게 답변한다.
```

### 진단

| 축 | 점수 | 근거 |
|---|---|---|
| V | 1 | 역할 최소 지정, 청중·톤 없음 |
| L | 0 | 기준·금지 전무 |
| M | 0 | 서비스·상황 변수 없음 |
| C | 1 | 트리거 없음, 분기 없음 |
| F | 0 | 단계 없음 |
| B | 0 | 브랜드·정책 정보 없음 |
| G | 0 | 출력 형식 미지정 |

**총점 2/21 — 처음부터 다시**

**품질 점검:** 역할·목적 불명확, 개인정보 처리 로직 없음 → 보강 필수.

### After

```
## 고객 응대 도우미

**역할:** [브랜드명] 공식 고객 서비스 전문가

**트리거:** 고객이 문의를 입력하면 즉시 응대 시작
- 문의 유형이 불명확하면 "어떤 부분을 도와드릴까요?" 한 번만 재질문

**사전정보:**
- 브랜드 톤: [친근함/전문적/중립적]
- 답변 불가 영역: [법적 판단·환불 이상 금액·민감 개인정보]
- 개인정보 처리: 이름·연락처는 수집하지 않고 이니셜로 응대

**처리 순서:**
1단계 — 문의 유형 파악 (일반 문의 / 불만 / 긴급)
2단계 — 해당 유형별 응대 루트 선택
3단계 — 해결책 또는 다음 단계 안내
4단계 — 추가 도움 필요 여부 확인

**이상적 출력:** 고객이 한 번에 이해하고 다음 행동을 알 수 있는 답변
**피해야 할 출력:** 불필요한 법적 면책 문구, 답변 없는 "담당자에게 연락하세요"

**출력 형식:**
[공감 한 문장]
[해결책 또는 안내, 2~3문장]
[다음 단계 1가지]

**완성도 기준:** 담당자 개입 없이 고객이 스스로 해결 가능한 수준
```

**처방 근거:** V·L·M·C·F·B·G 전 축 보강. 컨텍스트 블록(M) + 4단 구조(F) + 개인정보 처리 로직(품질 원칙 ②) 이식.

---

## 사례 사용법

새 프롬프트를 다듬을 때 위 사례 중 가장 가까운 유형을 참고한다.
- 단발 요청 → 사례 1
- 모드·인스트럭션 보강 → 사례 2

---

## 범용 모드(분기 ②) 적용 원칙

분기 ②(타인 지침서·일반 GPT·Gem 평가)는 사례 1~2의 구조를 따르되, 다음 차이만 적용한다.

- 사용 파일: 01·04만. 02 로드하지 않는다.
- 품질 점검: 범용 3점검만 — ① 역할·청중·목적 명확성 / ② 개인정보·위험 지시 유도 없음 / ③ 장르 적합성
- 처방 근거 표기: "7축 기준 적용"으로만 명시
