# CLAUDE.md 작성 프롬프트 템플릿

> 사용 시점: 새 프로젝트 시작 시 CLAUDE.md 초안 생성
> 목적: 프로젝트별 맞춤 CLAUDE.md 빠르게 작성

---

## CLAUDE.md 생성 요청 템플릿

```
내 프로젝트에 맞는 CLAUDE.md를 만들어줘.

## 나의 역할/직군
{목사 / 사역자 / 크리에이터 / 기획자 등}

## 주요 업무
{반복적으로 하는 업무 3가지}

## 사용 언어와 톤
- 응답 언어: 한국어
- 문서 톤: {격식체 / 비격식체}
- 특수 표기: {날짜 형식, 금액 형식 등}

## 자주 쓰는 도구
{구글 드라이브 / 노션 / 슬랙 / 카카오 등}

## 절대 하면 안 되는 것
{예: 성경 본문 임의 수정 금지, 개인정보 외부 전송 금지}

AgentWorkFlow-Lite의 절대 기준 3개를 유지하면서
내 업무에 맞는 추가 규칙을 포함해줘.
200줄 이내로 작성해줘.
```

---

## 직군별 예시

### 목사용 CLAUDE.md 핵심 규칙
```markdown
## 프로젝트 규칙
- 응답 언어: 한국어
- 성경 본문: 개역개정판 기준 (다른 번역 사용 시 명시)
- 설교 데이터: data/sermon-plan.json에서만 읽기 (AI 추측 금지)
- 신학적 판단: 반드시 목사님 확인 후 진행
- 교인 정보: 절대 외부 전송 금지
```

### 사역자용 CLAUDE.md 핵심 규칙
```markdown
## 프로젝트 규칙
- 응답 언어: 한국어, 격식체
- 날짜 형식: YYYY년 MM월 DD일 (요일)
- 예산 표기: 천 단위 쉼표 (1,200,000원)
- 공지문 발송: 반드시 담당자 최종 확인 후
- 행사 일정: data/church-calendar.md에서만 읽기
```

### 크리에이터용 CLAUDE.md 핵심 규칙
```markdown
## 프로젝트 규칙
- 응답 언어: 한국어, 브랜드 톤 (brand-guide.md 참조)
- 콘텐츠 계획: data/content-plan.csv에서 읽기
- 이미지 프롬프트: --ar 16:9 포함
- 발행 전: 사실 확인 필수
- 저작권 있는 콘텐츠 무단 사용 금지
```

## CLAUDE.md 개선 요청 템플릿

```
현재 CLAUDE.md를 개선해줘.

## 최근에 반복된 실수
{예: 날짜를 잘못된 형식으로 쓴다}
{예: 한국어로 응답하지 않는다}

## 추가하고 싶은 규칙
{새로 발견한 패턴이나 규칙}

## 제거하고 싶은 규칙
{더 이상 필요 없는 내용}

위 내용을 반영해서 CLAUDE.md를 업데이트해줘.
(Boris 방식: Claude가 실수할 때마다 추가)
```
