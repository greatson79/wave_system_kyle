# Research 단계 프롬프트 템플릿

> 사용 시점: 워크플로우 Research 단계 시작 시
> 목적: 필요한 정보를 체계적으로 수집·정제

---

## 기본 템플릿

```
다음 작업의 Research 단계를 수행해줘.

## 작업 목적
{워크플로우의 목적을 한 문장으로}

## 수집할 정보
1. {수집 항목 1}
2. {수집 항목 2}
3. {수집 항목 3}

## SOT 파일
{데이터를 읽어올 파일 경로}

## 출력 형식
- 수집한 정보를 `research/findings.md`에 저장
- 노이즈는 제거하고 핵심만 정제해서 저장
- AI 추측 금지: 파일에 없는 정보는 "확인 필요"로 표시
```

---

## 웹 리서치 포함 버전

```
다음 주제에 대해 Research를 수행해줘.

## 주제
{리서치 주제}

## 수집 방법
1. 내부 SOT 파일 확인: {파일 경로}
2. 웹 검색: {검색 키워드}
3. 참고 자료: {URL 또는 파일}

## 정제 기준
- 최신 정보 우선 (2024년 이후)
- 신뢰할 수 있는 출처만 포함
- 중복 제거

## 출력
`research/findings.md`에 저장:
- 핵심 발견 (불릿 5개 이내)
- 출처 목록
- 다음 단계를 위한 인사이트
```

---

## 사용 예시 (목사용)

```
설교 준비 Research를 수행해줘.

## 작업 목적
21주차 설교 "성령의 능력으로 섬기라" (행 2:1-4) 준비

## 수집할 정보
1. data/sermon-plan.json에서 21주차 본문·제목·절기 정보
2. 행 2:1-4 원어(헬라어) 주요 단어 분석
3. 오순절 사건의 신학적 배경

## SOT 파일
data/sermon-plan.json

## 출력 형식
research/21주차-설교리서치.md에 저장
```
