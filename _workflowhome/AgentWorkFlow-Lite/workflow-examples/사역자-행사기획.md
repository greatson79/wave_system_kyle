# 교회 행사 기획 자동화 Workflow

> 직군: 사역자·간사
> 자동화 수준: 기획 보조 + 문서 자동 생성

---

## 1. 목적

**해결하려는 문제:** 행사 기획서·안내문·일정표를 매번 처음부터 작성하는 반복 작업
**자동화 업무:** 행사 정보 입력 → 기획서 초안 → 안내 메일/문자 → 체크리스트 생성
**성공 기준:** 문서 작성 시간 70% 단축, 누락 항목 제로

---

## 2. SOT

| 데이터 | 파일 위치 | 쓰기 권한 |
|--------|---------|---------|
| 연간 행사 일정 | `data/church-calendar.md` | 사용자만 |
| 행사 기본 정보 | `data/event-info.json` | 사용자만 |
| 진행 상태 | `output/{행사명}/status.md` | orchestrator만 |

---

## 3. 에이전트 구성

| 에이전트 | 역할 | 타입 |
|---------|------|------|
| planner | 기획서 초안 생성 | auto |
| writer | 안내문·메일·문자 초안 | auto |
| checker | 체크리스트 생성·검증 | auto |

---

## 4. 실행 흐름

```
[시작: /행사기획 {행사명}]

Research:
  event-info.json + church-calendar.md 읽기
       ↓
Phase 1 (병렬):
  A. planner: 기획서 초안 (목적·일정·예산·역할분담)
  ∥
  B. writer: 안내문·초대 메일·문자 초안

       ↓ [검토: 담당 사역자 확인·수정]

Phase 2:
  checker: 준비 체크리스트 생성
       ↓
  최종 문서 패키지 저장

[산출물: 기획서 + 안내문 세트 + 체크리스트]
```

---

## 5. 산출물

| 산출물 | 형식 | 저장 경로 |
|--------|------|---------|
| 행사 기획서 | DOCX | `output/{행사명}/기획서.docx` |
| 안내문 | DOCX | `output/{행사명}/안내문.docx` |
| 메일·문자 초안 | MD | `output/{행사명}/공지문.md` |
| 준비 체크리스트 | MD | `output/{행사명}/체크리스트.md` |

---

## 6. 프로젝트 규칙

```markdown
- 응답 언어: 한국어, 격식체(합니다/습니다)
- 날짜 형식: YYYY년 MM월 DD일 (요일)
- 예산 표기: 천 단위 쉼표 (예: 1,200,000원)
- 안내문 발송 전 반드시 담당자 최종 확인 필수
```
