# 콘텐츠 제작 파이프라인 Workflow

> 직군: 크리에이터·SNS 담당
> 자동화 수준: 기획→초안→배포 준비 풀 자동화

---

## 1. 목적

**해결하려는 문제:** 콘텐츠 아이디어→완성까지 다단계 반복 작업
**자동화 업무:** 주제 선정 → 리서치 → 초안 → 플랫폼별 포맷 변환 → 배포 준비
**성공 기준:** 주 3회 발행, 제작 시간 60% 단축

---

## 2. SOT

| 데이터 | 파일 위치 | 쓰기 권한 |
|--------|---------|---------|
| 콘텐츠 기획표 | `data/content-plan.csv` | 사용자만 |
| 브랜드 가이드 | `data/brand-guide.md` | 사용자만 |
| 발행 현황 | `output/publish-log.md` | orchestrator만 |

---

## 3. 에이전트 구성

| 에이전트 | 역할 | 타입 |
|---------|------|------|
| researcher | 주제 리서치·트렌드 분석 | auto |
| writer | 콘텐츠 초안 작성 | auto |
| formatter | 플랫폼별 포맷 변환 | auto |

---

## 4. 실행 흐름

```
[시작: /콘텐츠 {주제} {플랫폼}]

Research:
  content-plan.csv + brand-guide.md 읽기
  researcher: 트렌드·참고자료 수집
       ↓
Planning:
  writer: 콘텐츠 구조 제안
       ↓ [검토: 크리에이터 방향 확인]

Implementation (병렬):
  A. writer: 본문 초안 완성
  ∥
  B. formatter: 플랫폼별 포맷 준비
       (인스타그램 / 유튜브 / 뉴스레터 / 카카오)

[산출물: 플랫폼별 완성 콘텐츠 패키지]
```

---

## 5. 산출물

| 산출물 | 형식 | 저장 경로 |
|--------|------|---------|
| 콘텐츠 본문 | MD | `output/{날짜}_{주제}/본문.md` |
| 인스타 캡션 | TXT | `output/{날짜}_{주제}/인스타.txt` |
| 유튜브 설명 | TXT | `output/{날짜}_{주제}/유튜브.txt` |
| 뉴스레터 | HTML | `output/{날짜}_{주제}/뉴스레터.html` |

---

## 6. 프로젝트 규칙

```markdown
- 응답 언어: 한국어, 브랜드 톤 준수 (brand-guide.md 참조)
- 이미지 프롬프트: --ar 16:9 --sref {브랜드 레퍼런스}
- 발행 전 반드시 사실 확인 필수
- 광고성 내용은 표시 의무 준수
```
