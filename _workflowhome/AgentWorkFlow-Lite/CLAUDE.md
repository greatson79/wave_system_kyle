# CLAUDE.md — AgentWorkFlow-Lite

이 파일은 Claude Code가 세션 시작 시 자동으로 읽는 지시서입니다.

---

## 절대 기준 (어떤 상황에서도 예외 없음)

### 1. 품질 최우선
속도·비용·작업량보다 **최종 결과물의 품질**이 유일한 기준입니다.
단계를 생략하거나 조용히 넘어가지 않습니다.

### 2. 단일 파일 SOT
모든 공유 상태는 **단일 파일**에 집중합니다.
- SOT 파일 쓰기 권한은 지정된 에이전트(Orchestrator)만 가집니다
- 나머지 에이전트는 읽기 전용 + 산출물 파일 생성만 합니다

### 3. 코드 변경 프로토콜 (CCP)
코드를 작성·수정하기 전에 반드시 3단계를 수행합니다:
1. **의도 파악** — 변경 목적을 1-2문장으로 정의
2. **영향 범위 분석** — 연쇄 변경 조사
3. **변경 설계** — 단계별 순서 확정

---

## 워크플로우 구조

모든 워크플로우는 3단계로 구성됩니다:

```
Research    → 정보 수집 및 분석
Planning    → 계획 수립 + 사람의 검토/승인
Implementation → 실제 실행 및 산출물 생성
```

---

## 세션 시작 시 확인 사항

1. `output/status.md` 존재 여부 확인 → 있으면 맥락 이어받기
2. `workflow.md` 존재 여부 확인 → 없으면 `/new-workflow` 먼저 실행
3. SOT 파일 위치 확인 (workflow.md의 SOT 섹션 참조)

---

## 금지 사항

- SOT 파일을 여러 에이전트가 동시에 쓰는 구조 금지
- workflow.md 없이 구현 시작 금지
- "부분 완료"를 완료로 보고하는 것 금지
- AI 기억으로 데이터 생성 금지 (반드시 SOT 파일에서 읽기)
