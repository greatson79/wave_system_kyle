# UI_GUIDE 문서 생성 프롬프트

## 지시
아래 양식에 맞게 `docs/UI_GUIDE.md`를 작성한다.
UI가 없는 프로젝트(CLI, API, 스크립트)는 이 파일 생성을 건너뛴다.
기획서의 "출력" 항목과 설계 철학을 기반으로 채운다.

## 양식

```markdown
# UI 디자인 가이드: [프로젝트명]

## 디자인 원칙
1. [원칙 1]
2. [원칙 2]
3. [원칙 3]

---

## 색상

### 배경
| 용도 | 헥스 |
|------|------|
| 페이지 배경 | #[hex] |
| 카드 배경 | #[hex] |
| 헤더 | #[hex] |

### 텍스트
| 용도 | 헥스 |
|------|------|
| 주 텍스트 | #[hex] |
| 본문 | #[hex] |
| 보조 | #[hex] |

### 시맨틱 색상
| 용도 | 헥스 |
|------|------|
| 성공 / 완료 | #[hex] |
| 오류 / 실패 | #[hex] |
| 경고 / 진행중 | #[hex] |
| 기본 액션 | #[hex] |

---

## 레이아웃

### [화면명 1]
\`\`\`
┌──────────────────────────────────────────┐
│  [헤더 영역]                    [버튼들] │
├──────────────────────────────────────────┤
│                                          │
│  [주요 콘텐츠 영역]                       │
│                                          │
└──────────────────────────────────────────┘
\`\`\`

### [화면명 2]
\`\`\`
┌──────────────────────────────────────────┐
│  [헤더]                                  │
├──────────────────────────────────────────┤
│  [콘텐츠]                                │
└──────────────────────────────────────────┘
\`\`\`

---

## 컴포넌트

### 테이블
- 헤더: [스타일]
- 행 hover: [스타일]
- 선택 행: [스타일]

### 버튼
- Primary: [배경색, 텍스트색, radius]
- Secondary: [테두리, 텍스트색]
- Danger: [배경색, 텍스트색]

### 카드
- 배경: [색상]
- 테두리: [스타일]
- 그림자: [스타일]
- radius: [값]
```

## 작성 기준
- 색상은 헥스코드로 명시 (예: #1a73e8)
- 레이아웃 와이어프레임은 ASCII로 실제 화면 구조를 표현
- 화면이 여러 개면 각각 ### 섹션으로 추가
- 컴포넌트는 실제 사용하는 것만 작성 (없는 것 삭제)
- UI가 없으면 파일 생성 생략하고 skill-design에서 건너뜀
