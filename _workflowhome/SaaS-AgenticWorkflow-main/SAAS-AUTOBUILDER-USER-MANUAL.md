# SaaS Auto-Builder 사용자 메뉴얼

## 가장 쉬운 사용법

```
claude 실행 → "시작" 입력 → 모드 선택 → 자동 실행
```

이것이 전부입니다. 나머지는 시스템이 알아서 합니다.

---

## 1. 시작하기

### 1.1 사전 준비

```bash
# Python 3.9+
python3 --version

# PyYAML 설치
pip install pyyaml

# Claude Code 실행
claude
```

### 1.2 "시작" — 워크플로우 진입

Claude Code 프롬프트에 다음 중 아무거나 입력하면 워크플로우가 시작됩니다:

| 입력 | 동작 |
|------|------|
| `시작` | 스마트 라우터 실행 |
| `시작하자` | 스마트 라우터 실행 |
| `start` | 스마트 라우터 실행 |
| `워크플로우 시작` | 스마트 라우터 실행 |
| `작업 시작하자` | 스마트 라우터 실행 |
| `/start` | 스마트 라우터 실행 (슬래시 커맨드 직접 호출) |

### 1.3 모드 선택 화면

"시작"을 입력하면 다음과 같은 선택 화면이 표시됩니다:

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  SaaS Auto-Builder — Workflow Launcher
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  프로젝트 상태: 새 프로젝트

── 실행 모드 선택 ──────────────────────────

  [1] Phase 1: PRD 생성 — 새로 시작
      12단계 워크플로우로 SaaS Auto-Builder PRD 문서를 생성합니다.

  [2] Phase 2: 풀스택 개발 — 새로 시작    (Phase 1 완료 후)
      16단계 워크플로우로 실제 코드를 자동 구현합니다.

── 실행 옵션 ────────────────────────────────

  [A] Autopilot 모드: OFF
  [U] ULW 모드: OFF

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  번호를 선택하세요 (예: 1, 1A, 1AU):
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

### 1.4 선택 방법

| 입력 | 의미 |
|------|------|
| `1` | Phase 1만 실행 |
| `1A` | Phase 1 + Autopilot 모드 |
| `1U` | Phase 1 + ULW 모드 |
| `1AU` | Phase 1 + Autopilot + ULW |

선택하면 워크플로우가 자동으로 시작됩니다.

## 2. 워크플로우 실행 중 사용자가 할 일

### 2.1 자동 실행 구간 (사용자 개입 불필요)

Phase 1의 12단계 중 **9단계는 완전 자동**입니다. AI 에이전트들이 연구, 분석, 작성, 검증을 알아서 수행합니다.

### 2.2 사람 검토 단계 (사용자 개입 필요)

3개 단계에서 사용자의 검토와 승인이 필요합니다:

| 단계 | 시점 | 검토 내용 | 선택지 |
|------|------|---------|--------|
| **Step 4** | 연구 완료 후 | 연구 결과물 품질 확인 | 승인 / 피드백 후 재작업 |
| **Step 8** | 계획 완료 후 | PRD 구조·설계 확인 | 승인 / 피드백 후 재작업 |
| **Step 12** | 최종 PRD 완성 후 | 최종 산출물 확인 | 승인 / 피드백 후 재작업 |

각 검토 단계에서 시스템이 자동으로 검토 화면을 표시합니다. 결과물을 읽고 `승인` 또는 피드백을 입력하면 됩니다.

> **Autopilot 모드**를 선택한 경우, 이 3개 단계도 자동 승인됩니다. 다만 품질 게이트(L0~L2)는 그대로 유지됩니다.

### 2.3 진행 상황 확인

워크플로우 실행 중 언제든 진행 상황을 확인할 수 있습니다:

```
/workflow-status
```

현재 단계, 완료된 단계, pACS 점수, 번역 상태 등이 표시됩니다.

## 3. 워크플로우 중단과 재개

### 3.1 중단

Claude Code 세션을 종료하거나 컨텍스트가 초과되면 워크플로우가 중단됩니다. **진행 상태는 자동으로 보존됩니다** (SOT + Context Preservation System).

### 3.2 재개

새 세션에서 다시 `시작`을 입력하면:

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  SaaS Auto-Builder — Workflow Launcher
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  프로젝트 상태: 워크플로우 진행 중 — Step 5/12
  현재 진행: Step 5/12 — "PRD Document Architecture Design"
  완료: 4개 단계 | 평균 pACS: 82

── 실행 모드 선택 ──────────────────────────

  [1] Phase 1: PRD 생성 — 이어서 진행
  [2] Phase 1: PRD 생성 — 처음부터 다시

```

`1`을 선택하면 중단된 지점부터 자동으로 이어서 진행합니다.

## 4. 실행 모드 상세

### 4.1 Phase 1: PRD 생성

**입력**: `coding-resource/PRD.md` (참조 PRD 문서, 2,667줄)

**과정**: 12단계 자동 워크플로우
1. **Research** (Step 1~3): PRD 분석, 다관점 연구, 종합
2. **Planning** (Step 5~7): 구조 설계, 인텐트 설계, 품질 프레임워크
3. **Implementation** (Step 9~11): PRD 작성, 교차 검증, 적대적 리뷰
4. **Human Checkpoints** (Step 4, 8, 12): 사용자 검토·승인

**출력**: `prompt/PRD-SaaS-AutoBuilder.md` (영어) + `prompt/PRD-SaaS-AutoBuilder.ko.md` (한국어)

### 4.2 Phase 2: 풀스택 개발

Phase 1이 완료된 후에만 선택할 수 있습니다.

**입력**: Phase 1에서 생성된 PRD

**과정**: 16단계 자동 워크플로우
- Phase A: 기술 분석 + 아키텍처 설계 (3단계)
- Phase B: 핵심 구현 — 스캐폴딩, 스키마, 엔진, API (7단계)
- Phase C: 테스팅, 문서화, 최종화 (6단계)

**출력**: 실제 동작하는 SaaS 코드

### 4.3 Autopilot 모드 (옵션 A)

모드 번호 뒤에 `A`를 붙이면 활성화됩니다 (예: `1A`).

| 항목 | 동작 |
|------|------|
| 사람 검토 단계 | 자동 승인 |
| 품질 게이트 (L0~L2) | **그대로 유지** |
| pACS RED (<50) | 자동 재작업 |
| 결정 로그 | `autopilot-logs/`에 자동 기록 |

> Autopilot은 **속도를 위한 것이 아닙니다**. 사람 개입 없이 품질 게이트만으로 품질을 보장할 수 있는 경우에 사용합니다.

### 4.4 ULW 모드 (옵션 U)

모드 번호 뒤에 `U`를 붙이면 활성화됩니다 (예: `1U`).

ULW(Ultrawork)는 **철저함 강화 오버레이**입니다:
- **I-1 Sisyphus Persistence**: 실패 시 최대 3회 재시도 (각각 다른 접근법)
- **I-2 Mandatory Task Decomposition**: 모든 작업을 Task로 분해·추적
- **I-3 Bounded Retry Escalation**: 무한 재시도 방지 (3회 초과 시 사용자 에스컬레이션)

## 6. 문제 해결

### "시작"이 작동하지 않아요

```bash
# 인프라 검증 실행
/install
```

`/install`이 문제를 진단하고 해결 방법을 안내합니다.

### 워크플로우가 중간에 멈췄어요

```bash
# 진행 상황 확인
/workflow-status

# 이어서 진행
시작
```

`시작`을 다시 입력하면 중단 지점부터 이어서 진행합니다.

### 처음부터 다시 하고 싶어요

`시작`을 입력하고 "처음부터 다시" 모드를 선택하세요. 기존 진행 상황이 백업(`.bak`)된 후 초기화됩니다.
