## 3. 컴포넌트 어휘

### 3-1. 필(pill) 버튼 — 유일한 버튼 형태
- radius 999px · weight 700 · 표준 `0.72rem 1.8rem` / 소형 `0.55rem 1.4rem`(2종만) · 보더 1.5px.
- Primary: 블루 채움 → hover 바이올렛 단색 스왑(160ms). Ghost: 잉크 라인 → hover 잉크 반전.
- 컬러/다크 블록 위: solid=페이퍼+잉크 / ghost=ink-inverse 라인. 블록 위 채움색 버튼 금지.
- 직각·중간 라운드(4~16px) 버튼 금지.

### 3-2. 카드 — "박스"가 아니라 "구획"
- 기본 = 헤어라인 카드(1px `--color-line`·radius 0·그림자 0). 리스트형 = 상단 헤어라인만.
- 강조 = `--color-wash` 면 + 블루 보더 1px. **hover = 보더 색 전이만(160ms)** — 리프트·
  스케일·그림자 금지(레퍼런스류 hover lift는 §9 큐레이션에서 명시 기각).

### 3-3. 뱃지 — 필 소형 라벨
- 채움(상태) = kicker·700·`0.14rem 0.7rem`·블루+ink-inverse / 라인(분류) = 동규격+헤어라인+muted.
- `.pending` 정직한 자리표시 = 헤어라인 직각 유지(임의 값 채우기 금지).

### 3-4. 스탯 타일 — 대형 컬러 숫자
- `clamp(2.6rem, 2rem + 3vw, 4.6rem)`·800·`-0.03em`·색 = 블루/바이올렛/**샌드딥** 순환.
- 수치는 SOT 집계만(기억 생성 금지). 대형 장식 숫자는 `--tint-*` 전용.

### 3-5. 섹션 헤드
- 중앙 정렬 미니멀: 킥커(블루) + 타이틀. 번호형 구 문법 신규 사용 금지.

### 3-6. ★상태(States) 규정 (v2.0 신설 — 큐레이션 흡수)
모든 인터랙티브/데이터 표면은 5상태를 정의하고 출고한다:
| 상태 | 규율 |
|---|---|
| hover | §3-1/3-2 색·보더 전이만(transform·그림자 금지) |
| focus | `:focus-visible` 2px 블루 outline + offset 3px(§6-2) — 제거 금지 |
| disabled | muted 텍스트 + line 보더 + `cursor: not-allowed`(채도 낮춤·투명도 남발 금지) |
| empty/pending | `.pending` 헤어라인 라벨("확인 중") — 임의 데이터 금지 |
| loading | 정적 wash 면(스켈레톤 애니메이션 불요 — reduce-motion과 일관) |

## 4. anti-AI 원칙 (웹 — 예외 없음 · 불변 척추)

2. 이모지 금지 3. 둥근 카드 금지(radius 0 — pill은 버튼/뱃지 전용) 4. AI일러스트 금지
(실사진만 — 무료 스톡 큐레이션 허용) 5. 기본서체 금지(Pretendard 단일) 6. 획일 반복 금지
(내용 따라 변주).
**AI툰 예외 경계** = `_캐릭터소스/design.md` §5 정본(웹 UI 표면에는 예외 불적용 — 콘텐츠

## 7. ★모션 정본 (v2.0 신설 — ditestudio 판단 정식 편입 + 무소실 사가 표준화)

스프링/바운스 이징 금지 — "잔잔한 물결" 톤(축하·팝 모먼트 불사용, 큐레이션에서 의식적 기각).

### 7-2. 무소실 등장 표준 — hold-키프레임 (정본)
- **원칙: 어느 시각에 얼어붙어도 완전한 화면.** 등장 모션의 from은 항상 **보임+오프셋**
  (콘텐츠 0.4em·h1 0.25em·장식 op 0.35~), 숨김 시작(op 0·마스크 105%) 전면 금지.
- 스태거는 `animation-delay`가 아니라 **키프레임 내 hold 구간**(0%~H%)으로 인코딩,
  `forwards` 고정(backwards/both 금지 — CEO fill-mode 원칙).
- 확정 수치 정본 = `라우팅티켓_히어로모션_hold키프레임_2026-07-13.md` §2 (커밋 84fe4af 반영·
  검증 ACCEPT). 시퀀스: 킥커 100ms → h1 200/260 → 리드 260 → 버튼 340/400 → 물결 400ms.
- 검증 표준 = deterministic-motion-capture 동결 캡처(완료정의 10항목 — 무소실 항목 포함).
- **증빙 정본(동결 캡처 실물)** = `output/WaveAI/크리에이티브본부/_웹디자인/히어로B안_목업/_증빙/`

  (JS 0 직접 로드) + 접합부 `junction_w320px/w1440px/full_w1440px.png` 3매. 어느 동결 시각에도

### 7-3. 비숨김 스크롤 리빌 (ditestudio 판단 §3-A 흡수 — codex 검수 반영분)
- 하위 섹션(섹션헤드·카드·스탯) 진입 시 `opacity 0.4 + translateY(0.5em) → 정위치`,
  700ms `--ease-out`. 타임라인 = CSS scroll-driven `animation-timeline: view()` — **JS 0 유지**.
- **★폴백 명세(필수)**: 리빌 선언 전체를 `@supports (animation-timeline: view()) { … }` 블록
  안에만 둔다 — 미지원 브라우저는 선언 자체가 없어 정위치 정적 표시 구조 보장(나이브 선언 시
  문서 타임라인 자동재생 함정 — codex 실검증).
- 스태거 리듬: 인접 요소 진입 간 80~120ms 체감(view() 진입 구간으로 자연 형성 — 대시보드식
  일제 팝인 금지).

### 7-4. 시그니처 모션 (전 사이트 2개만 — 남발 금지)
1. **물결 드리프트+부유**: 히어로 물결(라인·밴드) `translateX(-1주기)` 32~44s linear 무한 +
   `translateY ±5px` 7s alternate. 이음새 C1 무결이 검수 항목.
2. **로드 시퀀스**: §7-2 hold-키프레임 1회. 그 외 상주 모션 신설은 본부장 게이트.

### 7-5. 기각 목록 (레퍼런스 재론 금지 — ditestudio 판단 §3-C)

## 8. ★보이스 & 마이크로카피 (v2.0 신설 — 큐레이션 흡수·Wave 번역)

**목소리 = 잔잔하고 신뢰가는 안내자.** 교육 브랜드의 격려 + 사역 파트너의 진중함.
과장·조급·유행어 없이, 물결처럼 차분하게 다음 걸음을 권한다.

| 맥락 | 규율 | 예 |
|---|---|---|
| CTA | 행동 동사 명사형 | `클래스 보러 가기` · `문의하기` · `강연 요청하기` |
| 본문·안내 | `~합니다` 기본(신뢰 톤) | `연결의 도구로 이해합니다` |
| 상태·피드백 | `~요` 허용(부드러운 완료) | `요청을 보냈어요` |
| 미확정 데이터 | 정직한 자리표시 | `일자 확인 중` · `소개 준비 중` |
| 오류 | 원인+다음 행동 1개, 무책·구체 | `불러오지 못했습니다. 잠시 후 다시 시도해 주세요` |

**금지구**: `오류가 발생했습니다`(무정보) · 최상급 남발(`최고의`·`혁신적인`) · 조급 프레이밍
(`지금 아니면`·`놓치지 마세요`) · 한국어 표면의 영어 우선 문자열(영문은 킥커/라벨 장식 위계
전용 — 29cm 관행 채택) · UI 크롬 이모지(§4와 일관).
