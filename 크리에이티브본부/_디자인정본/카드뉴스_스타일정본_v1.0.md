## 0. 매체 선언 (웹과 다르다)
카드뉴스 = **모바일 피드에서 엄지로 넘기며 읽는 매체.** 웹사이트의 에디토리얼 여백이 아니라
**후킹·1메시지·고밀도 가독**이 지배한다. 배경색만 바꾸고 물결 얹는 것은 브랜드 일관성이지
전달력이 아니다(주인님 지적).

## 1. 규격
- **1080 × 1350 (4:5)** 고정. Pretendard(Black/ExtraBold/Bold/SemiBold/Regular).
- 제작 = **HTML/CSS + 헤드리스 Chrome 캡처**(`--window-size=1080,1350` · 투명배경 옵션).
  gpt-image-2 직접 카드 생성 금지(텍스트 렌더·정밀 레이아웃 불가).
- ★폴더명에 `#`가 있으면 `file://` URL에서 프래그먼트로 잘려 캡처가 **빈 에러 페이지**로 뜬다.
  경로를 `urllib.parse.quote`로 인코딩해 캡처할 것(PNG 용량이 전부 동일하면 이 실패 신호다).

## 1-b. ★폰트 자산 — fonts/ 동봉 의무 (v1.1 · COO 승인 2026-07-15)
- **각 카드뉴스 산출 폴더에 `fonts/` 를 동봉한다**(Pretendard woff2 5종: Regular·SemiBold·
  Bold·ExtraBold·Black). 원본 = `~/WAVE/wave-education/blog/node_modules/pretendard/dist/web/static/woff2`.
  CSS는 `@font-face{font-family:'P';src:url('fonts/...')}` + `font-family:'P',sans-serif`.
- **★시스템 폰트 참조 금지** — `'Pretendard Variable'`·`'Pretendard'` 직접 참조 금지.
  Variable/Static은 **메트릭이 달라 자간·베이스라인이 틀어진다**(실측: 시리즈 간 킥커 불일치).
- **근거(실사고 2026-07-15)**: #9 폴더에 `fonts/`가 없어 재캡처 시 fallback 폰트로 렌더 →
  승인본 대비 **유의차 5.3%·글자 메트릭 상이**. 무검증 재캡처였다면 승인된 타이포가 훼손될
  뻔했다. woff2 복원 후 **해시 100% 일치** 재현 확인.
- **★재캡처 재현성 규율**: 승인·게시된 카드를 다시 캡처할 때는 **먼저 무수정 재캡처 → 원본과
  해시/픽셀 대조**로 재현성을 검증한 뒤 수정한다. 수정 후에는 변경 bbox가 의도한 영역에만
  국한되는지 실측한다(그 외 0픽셀).

## 1-c. ★참조 자산 무결성 — 재캡처 전 전수 검증 (v1.1 · 2026-07-15 실사고 2건)
- **★PNG 정상 ≠ 재캡처 정상**: 캡처 후 자산이 유실돼도 **PNG는 멀쩡히 남아** 표면상 정상으로
  보인다. 재캡처하는 순간 그 요소가 증발한다. 폰트(§1-b)와 캐릭터 모두 이 패턴으로 사고났다.
- **★의무 — 검증기 실행**: 재캡처·재생성·검수 상신 전에 아래 도구를 돌린다(수작업 대체).
  ```bash
  bash output/WaveAI/크리에이티브본부/_assets/verify_cardnews.sh <카드뉴스_폴더_절대경로>
  # 종료코드 0=PASS / 1=위반(재캡처·발행 금지)
  ```
  검사 항목: ①참조 자산 전수 실존(img src·@font-face url) ②fonts/ woff2 5종 동봉·시스템 폰트
  참조 금지 ③anti-AI(그라디언트·이모지·본문 둥근 컨테이너) ④사명 표기·DiA 표기 ⑤PNG 4:5
  규격 + **동일 용량 다수 = 캡처 실패 탐지**(`#` 폴더명 프래그먼트 함정).
  검증 실적(2026-07-15): 오늘의 실사고 3유형(자산 유실·폰트 유실·둥근 카드)을 fixture로 재현해
  전부 탐지 확인, 정상 폴더(#9·#10)는 PASS 회귀 확인.
- **실사고 기록(2026-07-15)**: ①#9 `fonts/` 유실 → 재캡처 시 폰트 메트릭 변형(유의차 5.3%).
  ②#9 `char01_nobag_m.png` 유실 → 무수정 재캡처만으로 캐릭터 증발(유의차 7.79% ·
  bbox=캐릭터 영역). 둘 다 **재캡처 전 검증으로 사전 포착**했다.
- **자산 복원 절차**: 유실 자산은 추측 생성 금지 — **가설을 세우고 원본 재현으로 검증**한다.
  (`char01_nobag_m` = `char01_nobag`의 좌우반전 가설 → 복원 후 재캡처가 승인본과 **해시
  비트단위 일치**로 검증 성공.) 복원 불가 시 CEO 보고.
- **산출 폴더 자기완결 원칙**: 카드뉴스 폴더는 `card*.html` + `fonts/` + `char*.png` +
  `logo_wave*.png` + `gen.py`를 **모두 동봉**해 폴더만으로 재현 가능해야 한다.

## 5-b. ★캐릭터 변주 — 리듬 (v1.1 · 주인님 지시 2026-07-15)
- **동일 위치 반복 금지**: 10장 내내 캐릭터를 우측에 같은 크기로 두면 심심하다(주인님 지적).
  **위치(좌/우)·크기·포즈**를 카드마다 변주해 넘길 때 리듬이 생기게 한다.
  검증 배치(#10): 우-좌-우-우-우-좌-우-좌-우-좌.
- **★위치 변주의 전제 = 텍스트 반대편 이동**: 캐릭터를 좌측에 두면서 텍스트를 `left:72`에
  그대로 두면 **정면 충돌**한다. 텍스트 블록(`.h/.sub/.rows/.steps/.two/.note`)의 left·width를
  side에 연동시켜라(#10 `gen.py`의 `tl`/`tw` 파라미터가 구현 참조).
- **★캐릭터 실폭은 계산으로 확인**(눈대중 금지): `object-fit:contain`은 **캔버스 비율**로
  렌더되므로 알파 bbox와 캔버스가 다르면 예측이 어긋난다.
  `그림 우측 끝 = loff + height × (bbox_right / canvas_height)`.
  실측 가로세로비: `char01_nobag` 0.358 · `char10` 0.464 · **`char01_mirror` 0.556(가장 넓음 —
  책 든 팔)**. mirror를 좌측에 둘 때 height 880이면 그림 우측이 loff+562까지 뻗는다.
- **자산 우선순위**: 검증된 기존 컷아웃(`char01_nobag`·`char01_mirror`·`char10`) **재사용 우선**
  (일관성+비용). 신규 포즈는 불가피할 때만 gpt-image-2(주인님 구독 Codex 세션) + **얼굴 절대
  앵커**(메인캐릭터 소스 고정) + 1회 생성 + CEO 얼굴 대조 통과(§2 규율 준수).
- **side 변경 시 수직 리듬 재계산**: 텍스트 폭이 좁아지면 헤드라인 줄 수가 늘어 `subtop`·
  콘텐츠 `top`이 밀린다 — 변경 후 반드시 실물 캡처로 겹침을 확인한다.

### ★캐릭터 크기 기준 (v1.2 · 주인님 확정 2026-07-17)
- **기본 배율 = 현행 대비 80%**(20% 축소). "캐릭터가 너무 크다"는 주인님 지적 반영 —
  텍스트가 주(主), 캐릭터가 종(從)의 균형.
- **★소급 범위 (주인님 확정 2026-07-17)**: 이 배율은 **신규 제작분부터 자동 적용**한다.
  **기존 확정분에는 소급하지 않는다.** 교육11·12·AI트렌드 3세트는 주인님 직접 지시로 이미
  20% 축소 확정된 예외이며(현행 그대로 유지·재작업 없음), 그 외 기존 카드뉴스에 새 표준을
  소급 적용하지 않는다.
- **구현 = 파라미터 1곳**: `gen.py` 상단 `CHAR_SCALE = 0.8`. build()가 `ch=int(cfg.get("ch",..)*CHAR_SCALE)`로
  전 카드 일괄 적용 — 카드별 `ch` 하드코딩값은 상대 리듬(포즈별 키 차이)만 유지, 절대 크기는 이 변수로 조정.
  다음 조정은 이 변수 1줄 수정으로 끝난다(개별 카드 수정 금지).
- **정적 표지·마무리(card01/card10 — gen.py 미생성) 예외**: 이 두 장은 `.char{height}`를 직접
  0.8배로 조정한다(교육 시리즈 기준: 표지 912→730, 마무리 768→614). 신규 시리즈부터는 표지·
  마무리도 gen.py 생성으로 통일해 예외를 없애는 것을 권장.
- 축소 후 반드시 verify_cardnews.sh PASS + 텍스트 diff 0(height 라인 외 무변경) 실증.
