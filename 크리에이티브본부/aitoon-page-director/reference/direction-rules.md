## 0. 큰 원칙

1. **세 개의 줌 레벨로 본다.** ① **에피소드 전체**(여러 페이지의 리듬·클라이맥스 위치 → §11) ② **페이지 한 장**(감정 호흡 단위 → §1·§8) ③ **컷 하나**(크기·앵글·모양 → §2). 한 레벨만 보면 나머지가 무너진다.
2. **페이지는 정보 단위가 아니라 감정 호흡 단위다.** 한 페이지 안에 작게라도 도입→전개→(클라이맥스)→여운의 곡선이 흐르게 한다.
3. **연출 = 컷의 크기·앵글·모양·수·배치를 감정에 맞춰 통제하는 것.** 이걸 안 하면 덩어리, 하면 만화.
4. **한 차원에 집중하면 다른 차원을 떨어뜨린다.** (무기 고치다 칸 모양 놓침 등) → §10 체크리스트로 매번 전체 점검.
5. **반복 개선 루프:** 한 번에 완성 안 됨. v1→v2→v3로 **한 차원씩 쌓되 이전 성과는 유지** + 매 판 **확대 QC**.

## 1. 컷 수는 탄력적이다 (1~8) ★ 중요

> **6은 의무 할당량이 아니다.** "5~6 기본"을 잘못 쓰면 모든 페이지를 억지로 6칸으로 채운다(ep01 실측 문제). 컷 수는 **그 페이지의 감정 비트가 정한다.**

### 컷 수 결정표

| 컷 수 | 쓰는 상황 | 효과 |
|-------|-----------|------|
| **1컷 (스플래시)** | 충격·반전·표지급 임팩트, 큰 여운, 결정적 순간 | 한 컷이 페이지 전체 → 최대 임팩트·정적 |
| **2컷** | 강한 단일 비트 + 반응, 전·후 대비 | 묵직한 호흡 |
| **3~5컷** | 대화·전개·감정 흐름 | 표준 서사 |
| **6~8컷** | 빠른 합·몽타주·정보 밀집 | 속도감 (8 초과는 빽빽해서 금지) |

### 운용 규칙

- **페이지를 채우기 전에 컷 수부터 정한다** — "이 페이지의 비트는? → 거기 맞는 컷 수." 비트가 약/정적이면 **과감히 1~2컷**.
- 한 에피소드 안에서 컷 수를 **변주**한다. 6칸만 반복되면 리듬이 죽는다.
- **1컷 페이지 프롬프트**: "패널 6개" 대신 **"한 컷으로 페이지 전체를 채우는 스플래시 컷"**으로 지시. (수를 안 바꾸면 GPT가 6칸으로 복귀)
- 상한은 미니컷(인셋) 포함 **8컷**. 가독성 우선.

## 2. 연출 3대 레버 — 각각 따로 명시 ★

> **크기 / 앵글 / 칸 모양은 서로 다른 레버.** 셋 다 컷마다 지정한다. 특히 **앵글(카메라 기울기) ≠ 칸 모양(테두리 형태)** — "더치 앵글"만 적으면 그림은 기울어도 칸은 사각으로 남는다(ep01 v2 미스).

### 2-1. 컷 크기 (감정 강도)

| 감정 | 크기 |
|------|------|
| 강(클라이맥스·충격) | 대형(전폭/2-3 이상, 또는 스플래시) |
| 중(갈등·전환) | 중형 |
| 약(일상·이동) | 소형~중형 |
| 침묵·여운 | 의도에 따라 대형(여백) 또는 소형 |

→ 한 페이지에 **큰 컷↔작은 컷 대비** 필수. 다 같은 크기 = 덩어리. 클라이맥스 = 제일 큰 컷.

### 2-2. 앵글 / 거리 / 시점

- 거리: 풀샷 · 미디엄 · 미디엄 클로즈업 · 클로즈업 · 익스트림 클로즈업. 한 씬에 **2~3종 혼합**.
- 앵글: 수평 · 부감(하이) · 앙각(로우) · 더치(기울임). **앵글이 감정 강도·인물 권력 관계와 일치**(올려다보면 압도, 내려다보면 위축).
- 시점: **1인칭(POV·몰입)** / **3인칭(객관·거리)** / **관찰자(관계 전체)**.

### 2-3. 칸 모양 (패널 테두리 형태) — 매번 명시

| 모양 | 조건 |
|------|------|
| 직사각 | 기본 |
| **사선 분할** | 긴장·대립·빠른 리듬, 격돌 |
| 기울임 | 불안·동요 |
| **깨진(broken)** | 충격·임팩트 |
| 무경계 | 회상·꿈·여운 |
| 인셋 | 디테일·리액션(미니컷) |
| 확장형 | 개방·몰입 |

- **격돌·액션 페이지엔 사선·기울임·깨진 칸 적극** ("패널을 수평으로 가르지 말고 사선으로 비스듬히 분할").
- 단 무작정 전부 비틀면 산만 → **격돌·충격·여운 컷 위주**, 정적 페이지는 직사각 기본 + 포인트 1~2개.
- 읽는 순서(왼→오·위→아래) 명시.

### 2-4. 칸새 / 여백 리듬 (배치 생성 한계 내에서)

> 배치 생성이라 칸새를 픽셀 단위로 통제하긴 어렵다. **방향성만 프롬프트로 유도**한다. (정밀 통제는 외부 편집/뷰어 몫.)

- **감정 상승 구간**(빠른 합·추격)은 칸을 **촘촘히 붙여** 속도감, **여운·전환 구간**은 칸 사이를 **넓게 띄워** 호흡.
- **씬 전환 칸새**는 일반보다 넓게(시간·장소가 바뀐다는 시각 신호).
- 침묵 컷은 **여백을 크게** 줘서 정적을 만든다("이 컷은 주변에 넉넉한 여백, 정적인 호흡").

## 3. 캐릭터 일관성

- **고정 외형 못박기** — 머리(길이·**색**)·체형·의상(+**색**)·**안경 유무** 등. 안 적으면 엉뚱한 요소가 샌다(ep01: 안경 새어 들어옴). ★ **머리색·의상색은 매 페이지 명시**한다(안 적으면 페이지마다 색이 바뀐다 — ref + 페이지 프롬프트 양쪽에 반복).
- **비슷한 두 인물은 실루엣·체형을 극단적으로 차별** — ref + 프롬프트 양쪽. (프롬프트 강조만으론 부족 → 혈도를 거구·빡빡머리·애꾸로 **ref 자체를 새로 뽑아** 해결.)
- **다중 인물 컷은 역할 단서 필수** — 자세(걷기/꿇기/서기)·위치(전경/후경)·방향으로 "누가 누구이고 뭘 하는지" 못박기. (ep01 컷18 "누가 남고 누가 가나" 모호 사례)

## 4. 무기·소품 상태 연속성

- **정체성 고정** — 누구는 검(劍), 누구는 도(刀). 매 컷 명시.
- **개수 고정** — 각자 딱 한 자루. **쌍검·여분 칼 금지.**
  - ⚠️ 규칙 명시만으론 부족: **광역 격돌·아프터매스 컷에서 칼이 재추가**됨(ep01 v3 무진 2자루 재발). → ① 그런 컷엔 **손까지 명시**("오른손에 검 한 자루, 왼손은 비어 있음") ② **반드시 확대 QC**.
- **발검/납검 타임라인** — 컷별 "칼집에/뽑은 채" 명시(안 하면 뽑았다 사라짐).
- 기타 소품 **on/off**(우산·안경 등)도 컷별 명시.

## 5. 방향 (180도 연속성)

- **좌우 고정** — "A=화면 왼쪽 / B=화면 오른쪽"을 모든 대치·격돌 컷에 명시. 안 적으면 좌우 반전(ep01 v1 사례).
- **대화씬은 앵커 컷에서 좌우 확정** — 씬 첫 와이드 컷에서 두 인물 좌우 위치를 정하고, 단독 클로즈업에서도 시선은 상대방을 향하게.
- 진행·시선 방향 일관. 의도적 위반은 "의도적 연출 — [이유]"로 메모.

## 6. 스타일 (개성 입히기) ★ 보강

> **연출(구성)과 스타일(화풍)은 직교** — 서로 안 잡아먹고 한 파이프라인에서 같이 간다(검증됨). 스타일은 **sref 그리드 이미지를 GPT에 첨부**해 전달한다. (sref **코드**는 미드저니 전용 — GPT엔 안 먹힘.)

### 6-1. 스타일 토큰 7분해 (추출을 구조화)

첨부할 sref 그리드를 비전으로 읽어, 아래 7개 토큰으로 분해한다. **피사체는 무시하고 "공통된 그리는 방식"만 본다.** 색은 구체적으로, 기법·무드는 형용사로.

| 토큰 | 무엇을 본다 | 예시 |
|------|------------|------|
| 컬러 팔레트 | 주색·보조색·배경색(구체적으로) | "따뜻한 과슈 오렌지 지배 + 세이지 그린 보조 + 크림 배경" |
| 기법 | 페인팅/잉크/연필/벡터 | "거친 과슈 페인팅 + 약한 수채 워시" |
| 윤곽선 | 두께·질감 | "부드러운 손그림 윤곽, 진한 선 없음" |
| 색면 | 플랫/그라데이션 | "결이 보이는 플랫 색면" |
| 텍스처 | 그레인·해칭·붓결 | "종이 그레인 + 붓결" |
| 무드 | 전체 분위기 | "따뜻·아날로그·정감" |
| 폰트 무드 | 어울리는 글씨(말풍선 편집용 참고) | "손글씨 레터링" |

### 6-2. 영어 앵커 블록 + 내용물 가드 (복붙 템플릿)

추출 토큰을 **영어 지시문**으로 옮겨 프롬프트에 박는다. 내용물 가드는 **절대 생략 금지** — 안 넣으면 GPT가 그리드 속 얼굴·집·풍경까지 베껴 그린다.

```
=== STYLE (match the ATTACHED reference image; use ONLY its palette / texture /
technique, and IGNORE its subject matter — faces, houses, landscapes, animals.
Do NOT copy any of those objects) ===
- Palette: [컬러 팔레트]
- Technique: [기법]
- Linework: [윤곽선]
- Color fill: [색면]
- Texture: [텍스처]
- Mood: [무드]
```

### 6-3. 첨부 경고 배너 (산출물 맨 앞)

스타일 프롬프트는 그 이미지를 GPT에 **함께 첨부**해야 작동한다. 안 올리면 무용지물 → 산출물 맨 위에 경고를 띄운다.

```
⚠️ 이 프롬프트는 [스타일 이름/sref] 참조 이미지를 GPT에 함께 첨부해야 작동합니다.
   (캐릭터 ref → 스타일 그리드 → (연속 시) 직전 페이지 순서로 첨부)
```

### 6-4. 운용 원칙

- **캐릭터 ref도 같은 sref 스타일로** 생성 → 페이지 전체 톤 통일. **(sref 코드 보유 시 캐릭터는 미드저니 `--sref`로 생성하는 게 화풍 상위호환 — GPT 평면화 탈피. 페이지는 멀티패널이라 GPT 유지.)**
- 연속 페이지는 **직전 페이지를 함께 첨부** + 가능하면 같은 GPT 세션(세션 관성으로 연속성↑).
- **첨부는 서수로 지시**("첫 번째 이미지는 ○○ 캐릭터, 두 번째는 스타일 참조…"). "마지막/첨부한" 같은 모호 표현 금지.
- sref 코드는 출처 기록용으로만 MD에 남긴다.

### 6-5. "만화 프레이밍 함정" 점검 (검토 포인트)

> 인포그래픽 스킬의 최대 발견: "infographic"이라고만 하면 스타일 앵커를 줘도 **기업용 플랫 벡터로 회귀**한다. 만화도 "comic/웹툰"이라고만 하면 GPT 학습 관성(기본 웹툰체)으로 회귀해 **sref 화풍이 묻힐** 위험이 있다.

- 0625 실측에선 "연출+스타일 직교 OK"라 큰 문제 없었으나, **스타일이 약하게 묻으면** 다음을 추가한다:
  - **프레이밍 역전 문구**: "a hand-painted comic page in the attached painterly style, NOT a clean flat digital webtoon."
  - **금지문**: "Do NOT default to glossy flat webtoon shading; keep the brushy hand-painted texture of the reference."
- 스타일이 잘 묻으면 위 두 문구는 불필요 — **결과를 보고 약할 때만** 투입한다.

## 7. 말풍선 / 출력 ★ 보강

> **★ 원고 분기(시작 카드에서 정함):** 이 스킬은 두 경로를 지원한다.
> ① **클린 원고**(기본) — 아래 그대로. 말풍선 없이 그림만, 대사는 편집으로 얹는다.
> ② **대사 포함** — GPT가 말풍선을 직접 그린다. 이 경우 `balloon-dictionary.md`를 읽어 각 컷에 사전 스니펫을 박는다(검증된 말풍선 종류·꼬리·위치 거동). §7-1 타입 표는 클린 원고용 간이 분류이고, **대사 포함 분기의 권위 문서는 balloon-dictionary다.**

- **클린 원고:** 말풍선·텍스트·효과음 글자 절대 금지. 대사는 별도 메모 → 편집 도구/뷰어에서 얹는다.
  - (GPT가 한글 말풍선·꼬리·컷밖 넘침도 의외로 잘 그리는 게 확인돼 **대사 포함** 분기가 생겼다. 정밀 한글·위치 보정이 필요하면 클린 원고 + 외부 편집, 또는 말풍선 완성본 → 클린 역획득(balloon-dictionary §7).)
- **비율 고정** — "정확히 N:N로 고정, 벗어나지 마". 시리즈 내내 동일.

### 7-1. 대사 메모 = 말풍선 타입을 지정해서 넘긴다

클린 원고라 GPT엔 말풍선을 안 그리지만, **편집 도구로 넘기는 대사 스크립트에 타입을 지정**해두면 편집이 깔끔하고 일관된다. 컷별로 [화자 / 타입 / 대사]를 적는다.

| 타입 | 형태(편집 시) | 용도 |
|------|--------------|------|
| 일반 대사 | 둥근 말풍선(ellipse) + 꼬리 | 입 밖으로 하는 말 |
| 독백/내레이션 | 사각 박스(rect, 회색조) | 마음속 말·해설 |
| 전화 너머/기계음 | 구름형 또는 점선 테두리 | 통화·스피커 목소리 |
| 효과음(SFX) | 그래픽 텍스트 | 동작·충격음(클라이맥스는 강조색) |

- 한 컷당 말풍선 **3개 이하**, 핵심 표정·동작을 가리지 않게.
- 읽기 순서(왼→오·위→아래) 따라 배치.
- **대사 포함 분기**에선 이 4타입 대신 `balloon-dictionary.md`의 검증된 종류(대사/생각/외침/특수)를 GPT 스니펫으로 박는다.

## 8. 페이지 설계 절차 (프롬프트 쓰기 전)

1. **이 페이지의 감정 비트**를 한 줄로 정한다. (감정 키워드 + 강도 강/중/약)
2. **핵심 컷 식별** — 클라이맥스/대화/전환/침묵 컷이 어느 것인지 먼저 정한다.
3. 비트에 맞는 **컷 수(1~8)**를 §1 표로 고른다. (정적/충격이면 1~2컷 과감히)
4. 컷마다 [크기 / 앵글 / 칸 모양]을 부여(§2).
5. 등장인물·무기·방향·소품 상태를 컷별로 못박는다(§3~5).
6. 대사는 §7-1 타입 표로 메모(클린 원고엔 안 넣음).
7. §6 스타일 토큰·앵커·첨부 경고를 붙인다.
8. §10 체크리스트로 전체 점검 후 프롬프트 확정.

## 10. 프롬프트 확정 전 체크리스트 (터널비전 방지)

```
□ 이 페이지 컷 수를 비트로 정했나? (6 자동 아님 — 1~2컷도 후보)
□ 컷 크기 대비 · 앵글 혼합 · 칸 모양 명시(사선/깨진/무경계)   ← 자주 빠짐
□ 칸새 리듬(상승=촘촘/여운=넓게) · 침묵 컷 여백
□ 캐릭터 고정 외형(안경 등) · 비슷한 둘 실루엣 차별 · 다중인물 역할 단서
□ 무기 정체성·개수(쌍검 금지, 손까지)·발검/납검 상태   ← 자주 빠짐
□ 좌우 180도 고정 · 대화씬 앵커 컷
□ sref 그리드 첨부 + 스타일 토큰 앵커(영어) + 내용물 가드 + 첨부 경고 배너
□ (클린)대사 메모 타입 지정 또는 (대사 포함)컷별 💬 사전 스니펫 · 비율 고정 · 첨부 서수
```

## 11. 에피소드 전체 흐름 레이어 (여러 페이지 묶기) ★ 신규

> §1~§10이 "페이지 한 장"이라면, 이 층은 **페이지들을 묶은 한 회차 전체의 리듬**이다. 페이지마다 잘 연출해도, 회차 전체에서 클라이맥스가 너무 앞이거나 도입이 안 끌리면 무너진다. **모든 페이지 확정 후 한 번, 줌아웃해서 점검**한다.

### 11-1. 전체 흐름 지도 (먼저 그린다)

| 페이지 | 씬 범위 | 감정 톤 | 클라이맥스? |
|--------|---------|---------|-------------|
| p1 | | | |
| … | | | |

### 11-2. 전체 흐름 평가 항목

| 항목 | 평가 질문 |
|------|-----------|
| 전체 리듬 | 긴장과 이완이 균형 있게 배치됐나? (6칸만 반복 = 리듬 죽음) |
| **클라이맥스 위치** | 전체의 **2/3~3/4 지점**에 클라이맥스가 있나? |
| 감정 곡선 | 페이지 간 감정 흐름이 자연스럽게 이어지나? |
| 도입부 | 첫 1~2페이지가 독자를 충분히 끌어들이나? |
| 마무리 | 마지막 페이지가 여운 또는 다음 화 기대감으로 닫히나? |
| 원본 충실도 | 스토리의 핵심 감정·의도가 페이지에 제대로 실렸나? |
| 컷 수 변주 | 회차 안에서 컷 수가 변주돼 리듬을 만드나? |

### 11-3. 처리

- 이상 없으면 → 마감.
- 수정 필요하면 → **어느 페이지가, 원본 의도와 어떻게 다른지** 짚고, 그 페이지로 돌아가 §10 루프로 재작업.

## 12. 반복 개선 루프 (실전 워크플로)

1. **v1**: 스토리·컷 설계로 1차 생성 → 확대 검수로 결함 수집(덩어리·연속성·무기·방향…).
2. **v2**: 결함을 **공통 고정값**으로 일괄 수정(캐릭터 구분·무기·방향·발검). ref가 약하면 **캐릭터 ref 재생성**.
3. **v3**: v2 유지하며 **다음 차원 추가**(칸 모양·앵글). ← 발전이지 교체 아님.
4. 각 판마다 **확대 QC**로 잔여 결함(광역 컷 쌍검 등) 점검 → 해당 컷 손까지 명시해 재생성.

> 핵심 통찰: 좋은 페이지 만화는 "운 좋은 한 장"이 아니라 **이 루프를 돌려 매번 도달하는 것**. 이게 자동화할 스킬의 본체다.

## 13. 부록 — 수정 요청 처리 (지도교수 모드) ★ 신규

> 스킬로 만들 때의 **인터랙션 정책.** 유저가 연출 원칙을 깨는 수정을 요청해도 **무조건 수용하지 않는다.** (단, 최종 결정권은 유저.)

| 요청 유형 | 처리 방식 |
|-----------|-----------|
| 연출 원칙 무관(레이블·파일명·구분색 등) | 바로 수정 |
| 원칙과 경미하게 충돌 | 설명 후 수정 |
| 원칙을 크게 위반 | 이유 설명 + 확인 후 수정 |
| 의도적으로 설계한 연출 요소 변경 | 설계 의도 설명 + 확인 후 수정 |

> **관련 판단 기준** — 관련: 패널 크기·모양·위치, 칸새, 인물 좌우 배치, 앵글, 180도 / 무관: 작업용 레이블, 파일명, 컷 번호 표기.
> 충돌 시: "이 요소는 [의도]로 설계됐고, 바꾸면 [문제]가 생길 수 있어요. 그래도 진행할까요?" → 유저가 강행하면 "[원칙]이 깨짐을 인지하고 진행"으로 기록.
