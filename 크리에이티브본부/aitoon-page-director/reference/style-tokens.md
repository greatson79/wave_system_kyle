# 스타일 토큰 추출 — 미드저니 sref → GPT 프롬프트 앵커

> Step 2에서 읽는다. 유저가 첨부한 미드저니 sref 그리드 이미지를 분석해 스타일 토큰을 뽑고,
> 그것을 페이지 프롬프트에 박을 **영어 스타일 앵커 블록**으로 변환한다.
> (원리는 `stylish-infographic-by-blue`의 style_extraction을 만화 맥락으로 가져온 것.)

---

## 무엇을 뽑는가 — 7개 토큰

미드저니 sref 그리드가 주는 것은 "이미지의 룩앤필"이다. **피사체(그리드 속 인물·집·풍경)는 무시하고, 공통된 "그리는 방식"만** 본다.

| 토큰 | 무엇을 본다 | 만화 예시 |
|------|------------|-----------|
| 컬러 팔레트 | 주색·보조색·배경색 (구체적으로) | "흑백 모노크롬, 종이 크림 베이스" / "따뜻한 과슈 오렌지 + 세이지 보조" |
| 기법 | 펜·잉크/페인팅/연필/셀채색/벡터 | "펜&잉크 + 거친 크로스해칭" / "부드러운 셀 채색" |
| 윤곽선 | 두께·질감 | "굵고 거친 손그림 윤곽" / "가는 균일선" |
| 색면 | 플랫/그라데이션/해칭음영 | "해칭으로 음영, 그라데이션 없음" |
| 텍스처 | 그레인·해칭·붓결·스크린톤 | "종이 그레인 + 스크린톤" |
| 무드 | 전체 분위기 | "고대비·극화·비장" / "따뜻·아날로그·정감" |
| 폰트 무드 | 어울리는 레터링(말풍선 편집 참고용) | "각진 붓글씨 레터링" |

### 추출 원칙 — 색은 정확히, 무드는 비전으로

- **색**: 실제로 두드러지는 색을 구체적으로. "다채로운" 같은 모호한 말 금지. ("고대비 흑백" "따뜻한 비비드 오렌지가 지배, 틸이 보조".)
- **기법·무드**: 비전으로 읽은 인상을 형용사로. 그리드의 여러 피사체가 같은 방식으로 그려져 있으니, **그리는 방식의 공통점**만 본다.

## 영어 앵커 블록으로 변환

추출한 토큰을 페이지 프롬프트에 박을 영어 블록으로 옮긴다. **내용물 가드는 절대 생략 금지** — 안 넣으면 GPT가 그리드 속 얼굴·집·풍경까지 베껴 그린다.

```
=== STYLE (match the ATTACHED reference image; use ONLY its palette / texture /
technique, and IGNORE its subject matter — faces, houses, landscapes, animals.
Do NOT copy any of those objects) ===
- Palette: [컬러 팔레트]
- Technique: [기법]
- Linework: [윤곽선]
- Color fill: [색면]
- Texture: [텍스처]
- Mood: [무드]
```

> 한글 프롬프트 본문 안에서도 이 블록만 영어로 박으면 GPT가 스타일을 더 또렷이 잡는다.
> 한국어로 "흑백 펜·잉크 화풍, 거친 해칭…"을 같이 적어줘도 좋다(ep01 실제 사례). 둘 다 OK.

## 첨부 경고 배너 (산출물 맨 앞에)

스타일 앵커는 그 이미지를 GPT에 **함께 첨부**해야 작동한다. 안 올리면 무용지물 → 산출물 맨 위에 경고를 띄운다.

```
⚠️ 이 프롬프트는 [스타일 이름/sref코드] 참조 이미지를 GPT에 함께 첨부해야 작동합니다.
   첨부 순서: ① 캐릭터 ref → ② 스타일 그리드 → (연속 페이지면) ③ 직전 페이지 결과
```

## "만화 프레이밍 함정" — 스타일이 약하게 묻을 때만

> 인포그래픽에서 "infographic"이라고만 하면 스타일 앵커를 줘도 기업용 플랫 벡터로 회귀하듯,
> 만화도 "comic/웹툰"이라고만 하면 GPT 기본 웹툰체로 회귀해 sref 화풍이 묻힐 수 있다.

0625 실측에선 연출+스타일이 직교(잘 묻음)였으나, **결과를 보고 스타일이 약하면** 다음을 추가한다 (잘 묻으면 불필요):

- **프레이밍 역전**: "a hand-painted comic page in the ATTACHED painterly style, NOT a clean flat digital webtoon."
- **금지문**: "Do NOT default to glossy flat webtoon shading; keep the brushy hand-painted texture of the reference."

## sref 코드 메모

유저가 미드저니 sref 코드(예: `--sref 1623720629`)를 주면 산출물에 출처로 기록한다. sref 코드는
GPT/나노바나나엔 직접 못 쓰지만(GPT엔 **이미지 첨부**가 스타일 전달 수단), **캐릭터 ref를 미드저니로
직접 뽑을 때 `--sref [코드]`로 쓰는 게 상위호환**(화풍이 원본에 가장 가깝게 묻고 GPT 평면화에서 벗어남).

→ 즉 **sref 코드 보유 시 = 캐릭터는 미드저니 / 페이지는 GPT 하이브리드**가 최적(prompt-templates A-MJ).
페이지(멀티패널 연출)는 미드저니가 약하므로 GPT 유지. 코드 없이 그리드 이미지만이면 캐릭터도 GPT(A-GPT 폴백).
