# 프롬프트 템플릿 — 캐릭터 ref + 페이지 복붙 골격

> Step 3·4에서 읽는다. 캐릭터 ref 생성 프롬프트와 페이지별 복붙 프롬프트의 복붙용 골격.
> 연출 값은 `direction-rules.md`의 설계표에서 가져와 `[ ]`를 채운다.

---

## A. 캐릭터 ref 생성 (Step 3)

> **전략: 캐릭터는 미드저니로 원본을 잡는 게 정석.** 미드저니 `--sref [코드]`로 뽑은 캐릭터를 GPT 페이지에
> ref로 넣으면, GPT 특유의 평평한 화풍에서 벗어나 sref 원본 화풍이 또렷이 묻는다. sref 코드가 있으면
> **A-MJ형(권장)**, 그리드 이미지만 있으면 **A-GPT형(폴백)**. 어느 쪽이든 결과를 페이지 프롬프트에 ref로 첨부한다.

### 공통 원칙 (MJ·GPT 둘 다)

- ⚠️ **중립 기본형으로만 뽑는다.** 고정 외형·의상 + 중립 포즈 + 기본 표정 1~2개까지만. **특정 장면의 소품·
  상황 포즈(손에 든 물건·특정 동작·특정 감정 연기)는 ref에 넣지 않는다** — 그건 페이지 프롬프트에서 해당
  컷에 부여한다. ref에 소품을 박으면 그 인물을 쓰는 다른 컷에도 소품이 따라붙어 재사용성이 깨진다.
- **비슷한 두 인물은 실루엣·체형을 극단적으로 차별**해 따로 뽑는다. 프롬프트 강조만으론 부족하니
  외형 자체를 다르게(예: 한쪽을 거구·빡빡머리). (direction-rules §3)

### A-MJ형 — sref 코드 보유 시 (권장·정석)

```
character reference sheet of [인물 영어 묘사], multiple poses, full body plus face close-up,
front and side views, [고정 외형 영어 — 머리·의상·체형·소품·표정], [스타일 앵커 키워드],
cream background --ar 4:3 --niji 7 --sref [코드]
```

**예시 (오늘부터 다이어트):**
```
character reference sheet of a young woman, multiple poses, full body plus face close-up,
front and side views, messy short bob hair, round glasses, baggy pastel pajamas, average build,
big expressive cartoon face, warm hand-drawn pen-and-ink illustration with loose watercolor washes,
sage green and terracotta palette, cream background --ar 4:3 --niji 7 --sref 2567811006
```
```
character reference sheet of a young person, ... hair tied up in a messy bun, oversized hoodie and shorts,
slightly tall, calm deadpan expression, warm hand-drawn pen-and-ink illustration ...
--ar 4:3 --niji 7 --sref 2567811006 --no glasses
```

#### 미드저니 프롬프트 필수 규칙 (스킬 내장 — 반드시 지킴)

미드저니는 imagine 입력 자체가 이미지 생성이고, 파라미터가 레이어별로 작동한다. 아래를 어기면 깨진다:

- **생성 동사 금지** — "draw / create / generate / make an image of" 등을 프롬프트에 쓰지 않는다.
- **비율은 `--ar`로만** — 프롬프트 텍스트에 "4:3" 같은 비율 표현 금지. `--ar 4:3` 파라미터로.
- **스타일 앵커는 쌍방향** — 프롬프트의 화풍 키워드 ↔ `--sref [코드]`가 서로를 고정한다. 코드만 넣지 말고
  그 스타일을 묘사하는 키워드(예: `warm hand-drawn pen-and-ink, sage green palette`)를 **반드시 함께** 적는다.
- **요소 제외는 `--no`** — 특정 요소를 빼려면 프롬프트에 "no glasses"라 쓰지 말고 `--no glasses` 파라미터로.
- **파라미터를 텍스트로 지칭 금지** — "첨부 이미지의 스타일로", "이 인물을 참조해서" 같은 말은 안 쓴다.
  연결은 앵커 키워드가 한다.
- **모델 파라미터** — 만화는 `--niji 7` 기본. 화풍이 약하면 `--v 7`. **`--v`와 `--niji`는 동시 사용 불가**
  (둘 중 하나). sref 코드는 둘 다 호환.

### A-GPT형 — 그리드 이미지만 있을 때 (폴백)

미드저니 코드가 없으면 그리드 이미지를 GPT에 첨부해 스타일을 전달한다.

```
첨부: [스타일 그리드 이미지]

[인물 이름] 캐릭터 시트를 만들어줘. 전신 + 얼굴 클로즈업, 정면·측면.
[고정 외형을 구체적으로 — 머리(길이·색)·체형·키·의상·소품·안경 유무·흉터 등]. 중립 포즈·기본 표정.

첨부 이미지는 스타일 참조입니다 — 색·질감·화풍만 따르고, 그 속 인물·사물은 베끼지 마세요.

=== STYLE (match the ATTACHED reference; use ONLY its palette/texture/technique,
IGNORE its subject matter) ===
- [style-tokens.md에서 뽑은 7토큰]

배경은 단순하게. 말풍선·텍스트 금지(클린).
```

## B. 페이지 복붙 프롬프트 골격 (Step 4)

`[ ]`를 direction-rules.md §8 설계표 값으로 채운다. 컷 수는 페이지 감정 비트가 정한다(1~8, 6 자동 아님).
**페이지는 멀티패널 연출이라 GPT로 생성**(미드저니는 멀티패널 약함). 캐릭터 ref(A에서 뽑은 것)를 첨부한다.

```
첫 번째 이미지는 [인물A], 두 번째 이미지는 [인물B] 인물 참조입니다. 모든 패널에서 일관성 유지.
⚠️ [인물A] = [고정 외형·무기 한 줄] / [인물B] = [고정 외형·무기 한 줄]. 두 사람 실루엣 확실히 다르게.
[N]번째 이미지는 스타일 참조입니다 — 색·질감·화풍만 참조, 그 속 인물·사물·풍경은 베끼지 마세요.

[그림 스타일] [한국어 화풍 요약 — 흑백 펜·잉크 등].

한 장의 만화 페이지를 만들어줘. 패널 [N]개, 읽는 순서 왼→오·위→아래. 배경은 [장소].
좌우 방향 고정: [인물A] = 화면 왼쪽, [인물B] = 화면 오른쪽.
칸 모양: [기본 직사각 + 포인트 컷 지정 — 예: 패널5 기울임, 패널6 확장형, 패널4 인셋]. [클라이맥스 패널]을 가장 크게. 굵은 검은 테두리.

[패널 1 / 거리·크기·칸모양] (장면 / 무기·발검 상태 / 좌우 / 이 컷의 소품·포즈)
[패널 2 / …] (장면)
…
[패널 N / …] (여운/전환, 주변 여백 넉넉히)

=== STYLE (match the ATTACHED reference image; use ONLY its palette/texture/technique,
IGNORE its subject matter — faces, houses, landscapes, animals) ===
- Palette / Technique / Linework / Color fill / Texture / Mood: [토큰]

전체 이미지 비율은 정확히 [N:N]로 고정.
⚠️ 말풍선·대사창·텍스트·효과음 글자 등 어떤 텍스트 요소도 절대 그리지 마세요. (클린 원고)
```

> 장면 소품·상황 포즈는 **여기(페이지 프롬프트의 해당 컷)**에서 부여한다. 캐릭터 ref엔 넣지 않았으므로.

> **★ 대사 포함 분기면 (Step 0에서 선택):** 위 골격은 **클린 원고** 기준이다. 대사 포함이면 각 컷 묘사 아래에 `💬 [balloon-dictionary 영어 스니펫] + 위치 한 줄 + 한국어 대사`를 넣고, 맨 끝 ⚠️ 줄을 **"지정된 💬 말풍선만 그리고 그 외 텍스트는 넣지 마세요"**로 교체한다. 말풍선 종류·꼬리·위치 거동·사용 예시는 `balloon-dictionary.md`. 폰트는 깔끔한 산세리프(손글씨 금지).

### 채울 때 매번 통과시킬 것 (direction-rules §10)

```
□ 컷 수를 비트로 정함(6 자동 아님) · 크기 대비 · 앵글 혼합 · 칸 모양 명시
□ 캐릭터 고정 외형(안경 등) · 비슷한 둘 차별 · 다중인물 역할 단서
□ 무기 정체성·개수(쌍검 금지, 격돌 컷은 손까지) · 발검/납검
□ 좌우 180도 고정
□ 스타일 앵커(영어) + 내용물 가드 + 첨부 경고 배너
□ 클린 원고 · 비율 고정 · 첨부 서수
```

## C. 연속 페이지 처리

2페이지부터는 **직전 페이지 결과 이미지를 추가 첨부**하고(세션 관성), 첨부 순서를 서수로 다시 명시한다.

**★ 서수는 실제 첨부 개수에 맞춰 매번 계산한다(고정 금지).** 등장인물이 늘면 뒤 서수가 밀린다.
- 첨부 순서 = ① **캐릭터 ref들(각각 개별 서수 + 이름 1:1)** → ② 스타일 그리드 → ③ 직전 페이지 결과.
- **각 캐릭터를 뭉뚱그리지 마라**: "첫 이미지들은 인물·고양이" ❌ → "첫 번째 이미지는 인물A, 두 번째 이미지는 인물B" ✅.
- **직전 페이지의 서수 = (인물 수) + 1(스타일) + 1.** 인물 1명 → 세 번째 / 2명 → 네 번째.

예) 인물 2명:
```
첨부(순서대로): ① [인물A ref] ② [인물B ref] ③ [스타일 그리드] ④ [직전 페이지 결과]
첫 번째 이미지는 인물A, 두 번째 이미지는 인물B입니다. … 네 번째 이미지는 직전 페이지입니다. 같은 인물·화풍·톤 유지.
```

## D. 대사 메모 (별도 — 그림엔 안 넣음)

클린 원고라 프롬프트엔 말풍선을 안 넣지만, 편집 도구로 넘길 대사 스크립트는 타입을 지정한다(direction-rules §7-1).

```
[페이지N]
- 패널2 / [화자] / 일반대사 / "대사"
- 패널5 / [화자] / 독백 / "마음속 말"
- 패널6 / SFX / 효과음 / "쾅"
```
