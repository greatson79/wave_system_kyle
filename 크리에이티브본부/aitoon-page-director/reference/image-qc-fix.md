# 이미지 QC → 프롬프트 수정 (선택 부가)

> Step 6에서만 읽는다. 유저가 "여기 이상해"라며 결과 이미지를 올릴 때만 발동.
> **자동 v1→v2→v3 루프는 돌리지 않는다.** 유저가 부를 때만, 문제 난 페이지 프롬프트만 고친다.

---

## 발동 조건

- 유저가 생성 결과 이미지를 올리며 수정을 요청할 때.
- 올리지 않고 "다 좋아"면 → 스킬은 Step 5에서 이미 끝난 것. 아무것도 하지 않는다.

---

## 진단 — 확대(crop) QC가 핵심

> 썸네일로는 쌍검·말풍선 클립·무기 개수를 놓친다(0625 실측 2회 오판). **의심 컷만 잘라서 확대** 확인한다.
> 페이지 전체를 매번 통째로 비전 분석하면 컨텍스트가 훅 간다 — 의심 컷 crop으로 절약.

### 자주 나는 결함 체크리스트

| 결함 | 확인 위치 | 고치는 법 |
|------|-----------|-----------|
| **무기 개수**(쌍검·여분 칼) | 광역 격돌·아프터매스 컷 확대 | 그 컷에 "오른손에 [무기] 한 자루, 왼손은 비어 있음" 손까지 명시 |
| **좌우 반전**(180도 깨짐) | 대치·격돌 컷 | "A=화면 왼쪽 / B=화면 오른쪽" 다시 못박기 |
| **칸 모양**(다 직사각으로 평평) | 페이지 전체 비율 | 격돌 컷에 사선/기울임/깨진 칸 명시 |
| **캐릭터 혼동**(둘이 비슷) | 두 인물 같이 나온 컷 | ref 차별 부족 → 캐릭터 ref 재생성 권유(prompt-templates A) |
| **새어든 요소**(안경 등) | 얼굴 클로즈업 | 고정 외형에 "안경 없음" 등 부정형 명시 |
| **컷 수 회귀**(1컷인데 6칸) | 페이지 구조 | "한 컷으로 페이지 전체를 채우는 스플래시 컷"으로 지시 |
| **말풍선·글자**(클린 안 됨) | 컷 안 글자 | "어떤 텍스트도 절대 그리지 마" 강조 |

---

## 수정 출력

- **그 페이지 프롬프트만** 고쳐서 다시 복붙용으로 준다. 다른 페이지는 건드리지 않는다.
- 무엇을 왜 고쳤는지 한 줄로 알려준다. (예: "p-22 마지막 컷에서 칼 2자루가 보여서, 그 컷에 '오른손 한 자루·왼손 빈손'을 추가했어요.")
- 재생성 후에도 **그 의심 컷을 다시 확대 QC**한다. 규칙 명시만으론 재추가되는 결함이 있다(쌍검).

---

## 한 차원 고치다 다른 차원 놓치지 않기 (터널비전)

무기를 고치느라 칸 모양을 놓치는 식의 실수가 잦다(0625 실측). 수정 프롬프트를 내기 전 direction-rules §10 체크리스트를 한 번 더 통과시킨다 — **고친 것 + 원래 잘 됐던 것이 둘 다 유지**되는지.
