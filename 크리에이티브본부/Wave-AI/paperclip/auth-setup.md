# Wave AI Networks — 로그인 연결 가이드

> API 키 없이 기존 유료 계정으로 로그인만 하면 됩니다.

---

## 연결할 계정 3개

| 서비스 | 로그인 계정 | 사용 에이전트 |
|--------|------------|---------------|
| Anthropic (Claude) | claude.ai 유료 계정 | Flow Ops Orchestrator, Learning, Network |
| OpenAI (GPT) | ChatGPT Plus 계정 | AI Systems Orchestrator, Content, AI Systems Lead |
| Google (Gemini) | Google 유료 계정 | Knowledge Wave, Flow Operations |

---

## Paperclip에서 연결하는 방법

**Settings → Integrations** 에서 아래 순서대로 진행:

### 1. Anthropic 연결
```
"Connect Anthropic" 클릭
→ claude.ai 로그인 화면
→ Kyle Choi 계정으로 로그인
→ 권한 허용
→ 연결 완료 ✅
```

### 2. OpenAI 연결
```
"Connect OpenAI" 클릭
→ OpenAI 로그인 화면
→ Kyle Choi 계정으로 로그인
→ 권한 허용
→ 연결 완료 ✅
```

### 3. Google 연결
```
"Connect Google" 클릭
→ Google 로그인 화면
→ Kyle Choi Google 계정 선택
→ 권한 허용
→ 연결 완료 ✅
```

---

## 연결 완료 후 확인

```
□ Anthropic → claude-sonnet-4-6 사용 가능
□ OpenAI    → gpt-4o 사용 가능
□ Google    → gemini-2.5-pro, gemini-2.0-flash 사용 가능
```

이 3개가 초록불이면 모든 에이전트 작동 준비 완료입니다.
