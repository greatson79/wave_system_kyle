# Mainstream User Research: InvestScan vs AlphaSquare 솔직한 평가

> Phase 1 Branch: User-Mainstream (Round 2)
> 핵심 질문: "일반 투자자가 InvestScan을 '월등히 뛰어나다'고 느낄 것인가?"

---

## 페르소나: 김민수 (35세, IT 회사 대리)

- 투자 3년차, 삼성전자+ETF 중심 3,000만원, 일일 투자시간 30분
- 도구: 토스증권 + 네이버 증권 + 유튜브 + 알파스퀘어 무료
- Python 경험 없음, CLI 사용 경험 없음

### 전환 가능성: **99% NO**

| 채택 장벽 | 심각도 | 설명 |
|----------|--------|------|
| Python/CLI | 치명적 | `pip install`이 무엇인지 모름 |
| 모바일 앱 부재 | 치명적 | 투자 루틴이 100% 모바일 |
| 4시간 배치 | 심각 | 일일 투자 시간 30분 vs 4시간 대기 |
| 매매 기능 없음 | 높음 | "그래서 이걸로 뭘 하라는 건데?" |
| 실시간 알림 없음 | 높음 | 급등주 알림을 실제로 사용 중 |

### 투자자 니즈 분포

| 유형 | 비율 | InvestScan 관련성 |
|------|------|-----------------|
| "내일 뭐 오를까" (단기) | 45-50% | 없음 |
| "이 종목 괜찮은가" (확인형) | 30-35% | 거의 없음 |
| "시장 방향이 어디로" (방향성) | 12-15% | **핵심 타겟** |
| "자산배분 최적화" (체계적) | 3-5% | **핵심 타겟** |

**InvestScan의 자연 도달 시장 = 전체의 1-2%**

---

## Layer 접근법 평가

| Layer | 대상 | 도달 가능 | "월등" 주장? |
|-------|------|----------|------------|
| Layer 0: CLI | 개발자+퀀트 | 0.5-1% | 이 그룹 내 YES, 외부 검증 불가 |
| Layer 1: 주간 리포트 | 중급 자기주도 | 5-8% | 부분적 YES |
| **Layer 1+2: 리포트+웹 대시보드** | 관심있는 일반 | **15-20%** | **비로소 비교 가능** |
| Layer 3: 모바일/카카오톡 | 대중 | 30-40% | 토스/카카오와 정면 경쟁 |

**"월등히 뛰어난" 주장에 필요한 최소 레이어: Layer 1 + Layer 2**

## 진단

```
기술적 깊이     ████████████████████  InvestScan >>> AlphaSquare
접근성          ██                    InvestScan <<< AlphaSquare
즉시 활용       ███                   InvestScan <<< AlphaSquare
UX             █                     InvestScan <<< AlphaSquare
모바일          ░                     InvestScan <<< AlphaSquare
매매 연동       ░                     InvestScan <<< AlphaSquare
```

> **"InvestScan은 엔진은 우수하지만 차체가 없는 자동차다. 김민수는 엔진 성능이 아니라 '타고 갈 수 있는가'로 판단한다."**

### 메인스트림 최소 브릿지
1. 주간 한국어 리포트 자동 생성 (사람이 읽을 수 있는 형태)
2. "그래서 뭘 하라고?"에 대한 답 (구체적 액션: 비중 조절, 관심 섹터)
3. 접근 장벽 제거 (최소한 웹에서 결과 열람)
