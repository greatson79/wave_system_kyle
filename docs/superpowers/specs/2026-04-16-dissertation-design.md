## 잠정 연구 제목

> **AI 기반 소크라테스 대화·워크플로우 시스템을 통한 논리적 사고력 향상 연구**

---

## 연구 동기

박사과정 중 Claude Code 워크플로우를 직접 사용하며 느낀 경험:
- 아이디어를 논리적으로 확장하는 능력이 AI 활용의 핵심임을 체감
- 연속성 있는 질문과 설계 훈련이 사전에 있었다면 더 효과적이었을 것
- 하나의 아이디어에서 출발해 논리적 연관성을 가지며 확장하는 사고력 훈련의 필요성 인식

---

## 핵심 연구 방향

**방향 1(소크라테스 대화) + 방향 2(워크플로우) 통합**

```
[거시 구조 — 방향 2]
워크플로우 아키텍처: 아이디어 입력 → 확장 → 논리 구조화 → 검증

[미시 상호작용 — 방향 1]
각 단계마다 AI 소크라테스 질문으로 사용자 사고를 유도
```

- AI가 질문을 던져 사용자 스스로 사고를 확장하도록 유도 (소크라테스식) — **중심**
- 논리 구조를 시각화·정리하여 사용자 사고를 지원 — **보조**

---

## 시스템 개요

```
[입력] 사용자 아이디어 / 주제
       ↓
[Stage 1] 현재 생각 정리  → AI 소크라테스 질문
[Stage 2] 가정 도전       → AI 반론·심화 질문
[Stage 3] 논리 연결       → AI 관계성 질문
[Stage 4] 구조화          → 시각화 (논리 구조도)
       ↓
[출력] 논리적으로 확장된 사고 구조
```

## 이론적 배경 (6개 영역)

| 이론 | 역할 |
|------|------|
| 소크라테스 문답법 | 시스템 대화 설계의 철학적 근거 |
| 블룸의 개정 분류학 (Anderson & Krathwohl, 2001) | 사고력 수준 측정 기준 (기억→창조 6단계) |
| 비고츠키 ZPD·스캐폴딩 | AI가 학습자 사고를 지원하는 이론적 근거 |
| 인지부하이론 (Sweller, 1988) | 워크플로우가 인지부하를 줄이는 근거 |
| Human-AI Interaction | AI를 사고 파트너로 활용하는 최신 연구 |
| 독해력·사고력 연구 | 독해력 향상이 논리적 사고력과 연결되는 근거 |

## 연구방법

**설계기반연구 (DBR, Design-Based Research) + 혼합연구방법**

| 구성요소 | 방법 | 비중 |
|---------|------|------|
| 시스템 설계·구현 | 공학적 설계 (정성) | ★★★ 핵심 |
| 시스템 효과 검증 | 양적 (사전·사후 검사) | ★★ |
| 사용자 경험 | 질적 (설문·인터뷰) | ★ |

**연구 대상**: 범용 (초중고·대학생 포함) — 교수 상담 후 구체화 예정

---

## 실험 설계

| 항목 | 내용 |
|------|------|
| 참가자 | 20~30명 |
| 기간 | 4~6주 시스템 사용 |
| 사전검사 | 비판적 사고력 측정 도구 (한국형 또는 Watson-Glaser) |
| 사후검사 | 동일 도구 재측정 |
| 질적 데이터 | 사용자 설문 + 심층 인터뷰 |
| 통계분석 | 대응표본 t-검정 |

## 논문 구성 (챕터)

| 챕터 | 제목 | 핵심 내용 |
|------|------|---------|
| 1장 | 서론 | 연구 배경, 목적, 연구질문, 범위 |

| 5장 | 결과 | 시스템 구현 + 양적·질적 분석 |
| 6장 | 논의 | 결과 해석, 이론·실천적 함의 |
| 7장 | 결론 | 요약, 기여, 한계, 제언 |

## 전체 타임라인

```
Phase 1  문헌 조사 + 이론 정립          (2~3개월)
Phase 2  연구질문 확정 + 시스템 설계     (1~2개월)
Phase 3  프로토타입 개발                 (2~3개월)
Phase 4  파일럿 테스트 (5명 소규모)      (2~4주)
Phase 5  본 실험 + 데이터 수집           (4~6주)
Phase 6  데이터 분석                     (1개월)
Phase 7  논문 작성 + 수정                (3~4개월)
```

## 교수 상담 시 확인할 사항

1. **연구 대상 확정** — 범용 vs. 특정 학년/집단
2. **시스템 구현 범위** — 프로토타입 수준 vs. 완성도 기준
3. **측정 도구 승인** — 어떤 사고력 측정 도구를 쓸 것인지
4. **윤리 승인 필요 여부** — IRB(연구윤리심의) 필요한지
5. **논문 제출 일정** — 역산하여 Phase별 마감 설정
