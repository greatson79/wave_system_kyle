# 강의 설계 스펙 — 청소년을 위한 AI 활용 성경활동 앱 만들기

## 개요

- **대상**: 교회학교 교사
- **시간**: 1시간 30분
- **목표**: 교사들이 수련회 준비에 바로 활용할 수 있는 AI 앱을 이해하고, 완성된 앱을 가져가서 사용한다
- **제작 툴**: Codex (주), Claude Code (보조)

---

## 강의 타임라인

| 시간 | 섹션 | 내용 |
|------|------|------|
| 0:00–0:25 | AI 이해 (25분) | AI 이점 + 유의사항 (균형 톤) |
| 0:25–0:45 | Codex 라이브 시연 (20분) | 앱 제작 과정 시연 |
| 0:45–1:20 | 완성 앱 실습 (35분) | QR 접속 후 교사들이 직접 사용 |
| 1:20–1:30 | 마무리 (10분) | 링크 공유 + 기도 |

### 섹션 1 — AI 이해 (25분)

- AI란 무엇인가 — 교사 눈높이로 (5분)
- 교회·사역에서 AI 활용 이점 (8분)
  - 준비 시간 단축
  - 창의적 아이디어 보조
  - 맞춤형 콘텐츠 생성
- AI 사용 유의사항 — 실용적 + 신학적 균형 (8분)
  - AI가 성경 구절을 잘못 인용할 수 있다 → 검증 필수
  - AI는 성령의 감동을 대체할 수 없다 → 도구로만 사용
  - "잘 쓰면 축복의 도구"로 긍정 마무리
- Q&A (4분)

### 섹션 2 — Codex 라이브 시연 (20분)

- Codex 소개 및 사용법 (3분)
- 성향 검사 기능 라이브 제작 시연 (10분)
  - 프롬프트 예: "성경 캐릭터 유형 성향 검사 앱을 만들어줘"
- 수련회 프로그램 생성 기능 시연 (7분)
  - 프롬프트 예: "믿음 주제로 청소년 팀빌딩 활동 3개 생성해줘"

### 섹션 3 — 완성 앱 실습 (35분)

- QR코드로 앱 접속 (2분)
- 성향 검사 직접 해보기 (8분)
- 수련회 주제 선택 → 프로그램 생성 실습 (15분)
- 생성 결과 공유 및 피드백 (5분)
- 실제 수련회 적용 방법 안내 (5분)

### 섹션 4 — 마무리 (10분)

- 핵심 정리: AI는 도구, 교사가 중심 (3분)
- 앱 링크·GitHub 공유 (2분)
- 혼자서도 써볼 수 있는 것들 안내 (3분)
- 기도로 마침 (2분)

---

## 제작할 앱 스펙

### 앱 이름 (미정)
- 후보: "수련회 도우미" / "Youth Camp AI"

### 구조
탭 2개짜리 단일 페이지 웹앱 (HTML/CSS/JS 바닐라)

---

### 탭 1 — 수련회 프로그램 생성기

**입력**
- 수련회 주제 선택: 믿음 / 사랑 / 용기 / 소망 / 감사
- 인원수, 학년대(초등/중등/고등), 활동 가능 시간

**AI 출력 (주제별 활동 3~5개 제안 → 교사가 선택 조합)**
- 팀빌딩 게임: 진행 방법, 소요 시간, 준비물 포함
- 말씀·묵상: 성경 본문, 나눔 질문, 적용점
- 포스트 게임·마무리: 기도제목, 축복 선언문

**기능**
- 재생성 버튼 (다른 활동 제안)
- 결과 복사·공유

---

### 탭 2 — 성경 캐릭터 성향 검사

**형식**
- 상황형 질문 10개, 4지선다

**결과 유형 4가지**
| 유형 | 특성 | 성경 인물 |
|------|------|----------|
| 다윗형 | 리더십·용기 | 다윗 |
| 요셉형 | 인내·지혜 | 요셉 |
| 바나바형 | 섬김·격려 | 바나바 |
| 느헤미야형 | 계획·실행 | 느헤미야 |

**연동**
- 성향 검사 결과 → 수련회 프로그램 생성 시 자동 반영
- 예: 다윗형 多 → 리더십 팀빌딩 활동 우선 추천

---

## 기술 스택

| 항목 | 선택 |
|------|------|
| 프론트엔드 | HTML / CSS / JavaScript (바닐라) |
| AI API | Claude API 또는 OpenAI API |
| 배포 | GitHub Pages 또는 Vercel |
| 제작 도구 | Codex (주), Claude Code (보조) |
| 공유 방식 | QR코드 + 링크 |

---

## 강의 산출물 (교사들에게 제공)

1. **앱 URL** — QR코드로 공유, 즉시 사용 가능
2. **GitHub 저장소** — 코드 열람 및 자체 배포 가능
3. **강의 자료** — 슬라이드 PDF (AI 이해 섹션 포함)

---

## 미결 사항

- 앱 이름 확정
- API 키 관리 방법 (강의용 데모 키 vs 교사별 발급 안내)
- 슬라이드 제작 여부 및 도구 선택
