```
작성(작성팀) → 1차 검수 = 크리에이티브본부장 → 적대검수(agy + Codex) → 2차 검수 = 마스터(CEO) → 실게시
```

- 발행 게이트 = 마스터 위임(옵션 A): 마스터 2차검수 통과 = 즉시 게시 가능 상태(주인님 매번
  승인 불요). 이 단계까지는 4주차 대상 콘텐츠(교육9·10·11) 전부 완료됨.
- 실게시(카드 이미지·캡션을 실제 SNS 계정에 올리는 마지막 동작)만 아래 §2 집행 주체 규칙을 따른다.

## 3. ★현황 확인 — AI-Tech 자동집행 인프라 (코드베이스 전수 검색 결과)
- `output/WaveAI/AI-Tech본부` 전체 및 저장소 전수 검색(Facebook Graph API·카카오 API·자동 포스팅
  관련 키워드) 결과, **페이스북·카카오톡 자동 게시 인프라는 현재 미구축**임을 확인.
- 따라서 "그 외 채널 = 개발본부 집행"의 **현실적 초기 구현 형태는 자동화 API가 아니라 "AI-Tech
  담당자가 회사 계정에 직접 로그인해 수동 게시를 대행"**이다. 이는 즉시 실행 가능하나 **전제조건
  = AI-Tech에 회사 페북 페이지·카톡 오픈톡방 관리자 접근권한 공유**가 필요하다(§04 점검표
  주인님 액션 항목).
- **자동화(Graph API·카카오 비즈니스 API) 전환**은 별도 개발 과제다. 우선순위·착수 여부는
  CEO 결정 필요 — 마케팅은 이 상신에서 "구축 필요성 인지"까지만 보고하고 실제 구축은 AI-Tech
  본부장 소관으로 라우팅한다(크로스팀 요청, MASTER §5 준용).

## 4. "복붙 즉시 업로드" 패키징 기준 (인스타 — 주인님 수동 몫)
주인님이 판단·재구성 없이 순서대로 따라 하기만 하면 게시가 끝나도록 패키징한다.

1. **캡션**: 그대로 복사해서 붙여넣을 수 있는 완성 텍스트(코드블록 안에 원문 그대로 제공,
   플레이스홀더·수정 필요 문구 없음 — 있다면 상단에 "★게시 전 확인" 별도 표시로 눈에 띄게).
2. **이미지**: 파일 경로와 첨부 순서를 번호로 명시(카드01→카드10), 규격 확인 완료 표시.
3. **첫 댓글**: 캡션 게시 직후 붙일 문구를 별도 블록으로 분리 제공.
4. **게시 시각**: 권장 시간대 명시(오전 09:00~10:00대).
5. **전제조건 경고**: bio 링크 미세팅 등 게시 전 필수 선행 작업이 있으면 패키지 최상단에
   "★게시 전 필수 확인" 박스로 표시(교육10 채널패키지·회사채널 초기게시물 캡션의 기존 관례 계승).
