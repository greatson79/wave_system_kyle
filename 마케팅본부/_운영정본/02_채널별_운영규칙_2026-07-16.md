## 1. 인스타그램 (`@waveainetworks`)

| 항목 | 규칙 |
|---|---|
| **톤** | 공식·신뢰·잔잔 — 느낌표·과장 배제(agy 기존 검수 기준: "느낌표와 과장을 철저히 배제한 잔잔하고 신뢰감 있는 톤") |
| **캡션 구조** | 훅(1~2문장) → 본문(무엇을 다루는지, 불릿 또는 산문) → 미션/CTA → 시리즈명 표기("WAVE Academy · Claude 활용 시리즈 ○급 ○편") |
| **해시태그** | 15~20개 권장. 구조 = 브랜드(2) + 콘텐츠 특정(6) + 카테고리/타겟(5) + 발견성(4) ≈ 17개. 삽입 위치 = 캡션 본문 끝 또는 첫 댓글 |
| **첫 댓글** | 브랜드용 4태그(`#Claude고급 #⟨주제⟩ #⟨핵심키워드⟩ #WAVEAcademy`) + 시리즈 안내 1~2문장("이 시리즈는 비개발 파워유저를 위해 만들었습니다...") |
| **이미지 규격** | 1080×1350(세로형, 4:5) — 원본 그대로 사용, 리사이즈 불필요 |
| **카드 게시 순서** | 카드01→카드10 번호순 고정(캐러셀). 교육 콘텐츠는 순차 구조이므로 **순서 변경 금지** |
| **게시 시각** | 오전 09:00~10:00대 권장(기존 주간 발행 관례) |
| **링크** | 캡션 내 링크 직접 삽입 불가 관례 → "프로필 링크" 유도 문구 사용(예: "세미나 신청·문의는 프로필 링크로") |
| **하이라이트(고정)** | `WAVE Academy`(교육 소개) · `세미나`(일정·신청) · `AI 활용법`(카드뉴스 모음) · `전자책`(출간 후) |

## 5. 계정 보안·댓글 응대 (신규 — 회사 계정 접근권한 공유 전제 시 필수)
> ★4주차부터 "그 외 채널(페북·카톡) = 개발본부 집행"(§03) 전환에 따라 AI-Tech 담당자와
> 계정 접근권한을 공유하게 되므로, 아래 최소 보안·응대 규칙을 함께 확정한다.

| 항목 | 규칙 |
|---|---|
| **계정 보안** | 2단계 인증(2FA) 활성화(인스타·페북 모두) — 계정 접근권한 공유 전 주인님이 직접 설정. 비밀번호는 별도 채널(대면/보안메모)로만 전달, 문서·채팅 평문 기록 금지 |
| **접근권한 범위** | AI-Tech 담당자에게는 "게시·댓글 관리" 권한만 부여(가능하면 Meta Business Suite의 역할 기반 권한 — 소유자 권한은 주인님 단독 유지) |
| **댓글 응대** | 질문·문의성 댓글 = 마케팅이 답변 초안 작성 → 주인님/AI-Tech가 게시(정책 톤: 친절·간결, 논쟁적 댓글은 응대하지 않고 보고) |
| **민감·악성 댓글** | 즉시 삭제·숨김 처리하지 않고 스크린샷 보관 후 COO 보고(임의 삭제로 인한 오해 방지) |
| **게시 실패 대응** | 예약 실패·업로드 오류 시 카톡 세미나톡방에 우선 공지, 인스타/페북은 재시도 — AI-Tech가 실패 감지 시 마케팅에 즉시 통지 |

## 6. 공통 원칙

1. **1소스 다채널(OSMU)**: 동일 카드 이미지 자산을 인스타·페북·카톡에 재사용하되, 캡션·톤·CTA만
   채널별로 차별화. 신규 이미지 제작 반복 금지.
2. **개인↔회사 완전 동일 게시 지양**: 개인 채널(@greatson79 등)과 회사 채널은 톤이 다르므로
   캡션을 그대로 복붙하지 않는다(팔로우 유인 소멸·정체성 희석 방지 — 정본 원칙).
3. **사실성 완충 규칙**: 캡션에 특정 제품 조건(요금제·플랫폼 한정 등)을 서술할 때, 공식 문서와
   상충 가능한 세부는 "일부 기능은 제공 환경·요금제에 따라 다르니 공식 안내를 확인하세요" 형태로
   열어 둔다(교육10 완충 사례 준용 — 특정 조건을 단정하지도, 반대 조건을 단정하지도 않음).
4. **브랜드 표기 고정**: "WAVE Academy · Wave AI Networks" 계열 표기 통일. 시리즈물은
   "WAVE Academy · Claude 활용 시리즈 ○급 ○편" 형식 유지(카드10 하단 시리즈 넘버링과 정합).
5. **캡션 저작권**: SNS 문구(캡션·해시태그·첫댓글)는 **크리에이티브본부 소관 자산 재사용**이
   원칙 — 마케팅은 채널 규격 변환·패키징만 수행하고 신규 카피를 임의 창작하지 않는다.
