# 블로그 썸네일 프롬프트 생성 스킬

sshong.com(HONGS LAB) IT/AI 블로그 전용. 블로그 원고를 나노바나나 프로용 썸네일 프롬프트로 변환한다.

**핵심 흐름**: 원고 입력 → 주제·메시지·톤 추출 → 유형·캐릭터·색상·텍스트 배치 판단 → 프롬프트 출력

**참조 파일**:
- `references/style-templates.md` — 유형별 프롬프트 템플릿 + IT/AI 주제별 가이드
- `references/examples.md` — 실전 예시

## 나노바나나 프로 지시어 가이드

### 잘 작동하는 지시어 (적극 사용)
- 4색 팔레트 명시, 배경 큰 원형 블롭
- 미세 도트 패턴 (사선·격자 금지), 캐릭터 의상 색상+동작+표정
- 소아이콘 흩뿌리기, 반짝임+강조색, 분할 비교형 좌우 배경색 분리
- 환경 소품 1~2개, 말풍선, 텍스트 블록

### 무시되는 지시어 (사용 금지)
- 명암·입체감, 등신 수치, 둥근 모서리, 크기 비율 수치, 외곽선 색상·굵기

## 4색 팔레트 시스템

|------|------|
| 배경색 | 화면 전체 배경 + 블롭 장식 |
| 메인색 | 캐릭터 의상·오브젝트·아이콘 |
| 강조색 | 반짝임·하이라이트·포인트 (10~15%) |

| **파랑 (기본)** | #E8F0FE | #1A73E8 | #FBBC04 | #202124 | IT/AI 대부분의 글. 도구 소개, 시스템, 워크플로우, 기능 설명 |
| **회색 (비교·분석)** | #ECEFF1 | #455A64 | #1A73E8 | #263238 | 도구 비교, 객관적 분석, 중립적 톤. 강조색으로 파랑 포인트 |
| **노랑 (팁·발견)** | #FFFDE7 | #F9A825 | #1A73E8 | #F57F17 | 팁, 노하우, 발견, 꿀팁, 체크리스트. 강조색으로 파랑 포인트 |
| **빨강 (경고·실수)** | #FBE9E7 | #D32F2F | #FFA726 | #B71C1C | 실수 사례, 주의사항, 경고, 문제점 |

## 캐릭터 2유형

장면형(B)과 분할 비교형(D)에서 사용.

**① 크리에이터형** — sshong.com 기본 캐릭터
- 의상: 후드티/라운드넥, 편한 바지. 메인색 적용
- 소품: 노트북·노트·펜·커피
- 적합: 글쓰기, 이미지 생성, 경험담, 실용

**② 비즈니스형** — 전문성 강조
- 의상: 셔츠, 칼라·단추. 메인색 적용
- 소품: 모니터·문서·차트·화이트보드
- 적합: 도구 비교, 시스템 설계, 교육·강의

**공통**: "심플하고 친근한 일러스트 캐릭터" + 의상에 메인색 + 표정 구체 지시

## 텍스트 배치 방식 5가지

원고의 톤과 썸네일 유형에 따라 적합한 텍스트 배치 방식을 선택한다. **상단 배너 띠 고정이 아니라, 상황에 맞게 방식을 골라 적용한다.**

### T1. 일반 텍스트형
- 배경 위에 직접 큰 텍스트 배치. 배너·블록 없음
- 텍스트색 또는 메인색으로 굵게 표시
- 적합: 타이포 중심형(C), 메시지가 강한 글

### T2. 말풍선형
- 캐릭터 옆에 둥근 말풍선, 안에 짧은 텍스트
- 말풍선 배경 흰색, 테두리 텍스트색 또는 메인색
- 적합: 장면형(B), 캐릭터의 대사·반응·감정 표현

### T3. 블록 강조형
- 텍스트 뒤에 메인색 또는 텍스트색 사각 블록(배경 깔기)
- 블록 위에 #FFFFFF 흰색 텍스트
- 적합: 아이콘 중심형(A), 분할 비교형(D), 정보 전달

### T4. 레이블형
- 오브젝트·캐릭터 근처에 작은 태그·레이블로 텍스트 배치
- 화살표나 선으로 연결하기도 함
- 적합: 아이콘 중심형(A), 도구명·키워드 표시

### T5. 텍스트 없음
- 일러스트만으로 구성, 텍스트 완전 생략
- 적합: 일러스트 자체가 메시지인 경우, 이미지 중심 글

### 텍스트 배치 자동 선택 로직

| 썸네일 유형 | 1순위 | 2순위 |
|------------|------|------|
| A. 아이콘 중심형 | T3 블록 강조 | T1 일반 텍스트 |
| B. 장면형 | T2 말풍선 | T1 일반 텍스트 |
| C. 타이포 중심형 | T1 일반 텍스트 | T3 블록 강조 |
| D. 분할 비교형 | T3 블록 강조 | T4 레이블 |

| 원고 톤 | 추천 배치 |
|---------|----------|
| 캐릭터 대사·반응이 핵심 | **T2 말풍선** |
| 선언형 메시지·숫자 강조 | **T1 일반 텍스트** |
| 정보 전달·도구명 표시 | **T3 블록 강조** 또는 **T4 레이블** |
| 일러스트 자체가 메시지 | **T5 텍스트 없음** |
| 판단 어려운 경우 | 유형별 1순위 |

### 텍스트 공통 규칙

| 요소 | 기준 |
|------|------|
| 메인 텍스트 | 10자 이내, 크고 굵게 |
| 서브 텍스트 | 15자 이내, 선택 사항. 맥락 키워드 배치 공간 |
| 말풍선 텍스트 | 8자 이내, 대사체 |
| 레이블 | 8자 이내, 키워드 |

**맥락 키워드 필수 포함 규칙**:
원고에 등장하는 도구명·플랫폼명·핵심 대상(예: 클로드, ChatGPT, 나노바나나, 워드프레스 등)은 **메인 텍스트 또는 서브 텍스트에 반드시 1개 이상 포함**한다. 이미지만 봐도 "어떤 도구·플랫폼에 대한 글인지" 전달되어야 한다. 맥락 키워드가 메인 텍스트에 자연스럽게 들어가면 메인에, 그렇지 않으면 서브 텍스트에 배치한다.

| 원고 주제 | 나쁜 예 (맥락 누락) | 좋은 예 (맥락 포함) |
|-----------|-------------------|-------------------|
| 클로드 스킬로 책쓰기 | 메인 "어디서 실행할까" | 메인 "스킬로 책쓰기" + 서브 "클로드 프로젝트 vs 코워크" |
| ChatGPT 프롬프트 설계 | 메인 "프롬프트 5가지" | 메인 "ChatGPT 프롬프트" + 서브 "실전 설계 5가지" |
| 나노바나나 인포그래픽 | 메인 "이미지 프롬프트" | 메인 "나노바나나 프롬프트" + 서브 "인포그래픽 만들기" |

**텍스트 중복 방지**: 분할 비교형에서 메인 텍스트 ≠ 레이블.

## 시각 밀도 보강 (필수)

**레이어 구분**: 배경(색+미세 도트) → 중간(큰 블롭 1~2개) → 전면(오브젝트/캐릭터+텍스트)

**보조 장식 2개 이상**: 소아이콘 흩뿌리기 + 반짝임(강조색)

**오브젝트 디테일**: 핵심 2~3개만

**밀도 체크리스트** (4개 이상):
- [ ] 텍스트 배치 (T1~T4 중 선택, 또는 T5 없음)
- [ ] 배경 블롭 레이어
- [ ] 소아이콘 + 반짝임
- [ ] 오브젝트/캐릭터 핵심 디테일
- [ ] 미세 도트 배경
- [ ] 4색 팔레트 역할별 적용

## 좌우대칭 구도 가이드

필요 시 캐릭터+오브젝트를 좌우 대칭으로 배치하면 안정감과 전문성이 올라간다.

### 대칭이 효과적인 경우
- 분할 비교형(D): 좌우 같은 캐릭터의 다른 상태
- 장면형(B) 변형: 캐릭터 중앙 + 좌우에 오브젝트 대칭 배치
- 아이콘 중심형(A) 변형: 중앙 오브젝트 + 좌우에 보조 아이콘 대칭

### 대칭 프롬프트 지시어
```
구도: 좌우 대칭. 중앙에 [캐릭터/오브젝트], 좌측에 [요소A], 우측에 [요소B]를 대칭으로 배치.
```

### 대칭이 불필요한 경우
- 타이포 중심형(C): 텍스트 중심이므로 대칭보다 장식 배치가 효과적
- 단순 도구 소개: 오브젝트 1개 + 텍스트이면 대칭 없이 충분

## 프롬프트 생성 워크플로우

### 기본 동작: 한 번에 출력

### Step 1: 원고 수신

### Step 2: 핵심 추출
1. sshong.com 주제 분류 (4가지 중 택1)
2. 주제 키워드 1~2개
3. 맥락 키워드 — 원고에 등장하는 도구명·플랫폼명·핵심 대상 (예: 클로드, ChatGPT, 코워크, 나노바나나). 메인 또는 서브 텍스트에 반드시 포함할 대상
4. 핵심 메시지 1문장
5. 감정 톤
6. 팔레트 선택 (파랑 기본, 톤에 따라 회색/노랑/빨강/녹색)
7. 캐릭터 유형 (크리에이터/비즈니스)
8. 좌우대칭 필요 여부 판단
9. 텍스트 배치 방식 선택 (T1~T5)
10. 추천 텍스트 — 메인 10자 이내 + 서브 15자 이내. 맥락 키워드가 메인 또는 서브에 반드시 포함되었는지 확인

### Step 3: 프롬프트 작성 + 출력

**출력 형식**:
```
[추출 결과]
```

## 프롬프트 작성 원칙

1. 첫 문장: `블로그 썸네일 [유형] 일러스트 이미지를 생성해줘.`
2. 레이어 순서: 배경 → 메인 → 텍스트 → 보조 장식
3. 오브젝트 디테일 핵심 2~3개만
4. 캐릭터: "심플하고 친근한 일러스트 캐릭터" + 의상(메인색) + 동작 + 표정
5. 텍스트: 원고 톤에 맞는 배치 방식(T1~T5) 적용
6. 좌우대칭: 필요 시 "좌우 대칭 구도" 명시
7. 배경: 미세 도트만, 사선·격자 금지
8. 색상: 파랑 기본. 보라색 사용 금지

**일러스트 스타일 블록**:
```
일러스트 스타일:
- 라인+컬러 일러스트, 깔끔한 외곽선에 플랫 컬러 채색
- 4색 팔레트: 배경 [#], 메인 [#], 강조 [#], 텍스트 [#]
- 가로세로 비율: 16:9
```
