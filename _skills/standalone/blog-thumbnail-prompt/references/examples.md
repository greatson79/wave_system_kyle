# 블로그 썸네일 프롬프트 — 실전 예시

sshong.com 4주제별 예시. 색상은 파랑 기본, 보라 사용 안 함. 텍스트 배치 방식(T1~T5)을 다양하게 적용. 모든 예시에서 도구명·플랫폼명 등 맥락 키워드가 메인 또는 서브 텍스트에 포함되어 있다.

---

## 예시 1: AI 도구 소개 → 아이콘 중심형 / 파랑 팔레트 / T3 블록 강조형

```
블로그 썸네일 아이콘 중심형 일러스트 이미지를 생성해줘.

구도: 화면 상단~중앙에 큰 오브젝트, 하단에 텍스트.

배경: #E8F0FE 위에 미세한 도트 패턴. 오브젝트 뒤에 큰 원형 블롭을 #D2E3FC로 크게 배치.

오브젝트: 큰 모니터. 화면에 4개 카드가 2×2 격자로 배치, 각 카드에 작은 아이콘(연필, 차트, 슬라이드, 돋보기). 모니터 옆에 톱니바퀴. — 라인+컬러 일러스트, #1A73E8 파랑 채색, 크게 배치.

텍스트: "나만의 AI 시스템" — 매우 크고 굵은 한글 텍스트, #FFFFFF 흰색.
- 하단에 #202124 사각 블록, 그 위에 흰색 텍스트.
서브 텍스트: "클로드 스킬 워크플로우" — 중간 크기, #1A73E8.

보조 장식: 배경에 전구, 체크마크, 화살표, 별 4개 흩뿌리기 — #A8C7FA. 모니터 주변 반짝임 2개 — #FBBC04.

일러스트 스타일:
- 라인+컬러 일러스트, 깔끔한 외곽선에 플랫 컬러 채색
- 4색 팔레트: 배경 #E8F0FE, 메인 #1A73E8, 강조 #FBBC04, 텍스트 #202124
- 가로세로 비율: 16:9
```

## 예시 2: AI 글쓰기 실수 → 장면형 / 빨강 팔레트 / T2 말풍선형

```
블로그 썸네일 장면형 일러스트 이미지를 생성해줘.

구도: 중앙~하단에 캐릭터 장면, 캐릭터 옆에 말풍선.

배경: #FBE9E7 위에 부드러운 노이즈. 캐릭터 뒤에 큰 원형 블롭을 #F5C6B8로 배치.

캐릭터(크리에이터형): 심플하고 친근한 일러스트 캐릭터 1명.
- 의상: #D32F2F 빨강 라운드넥 티셔츠, 편한 바지
- 동작: 책상에 앉아 한 손으로 턱을 괴고 "뭘 해야 하지?" 자세
- 표정: 당혹, 눈썹 올라가고 입 삐쭉
- 소품: 열린 노트북(화면에 큰 물음표), 구겨진 메모지 2장
- 환경: 나무색 책상, 빈 커피 머그컵

말풍선: 캐릭터 우측 상단에 둥근 말풍선.
- 말풍선 배경 #FFFFFF 흰색, 테두리 #B71C1C.
- 말풍선 안에 "좋은 글 써줘?" — 굵은 한글 텍스트, #B71C1C.

보조 장식: 배경에 물음표 2개, 느낌표 1개 — #F5C6B8. 캐릭터 머리 위 소용돌이 — #FFA726.

일러스트 스타일:
- 라인+컬러 일러스트, 깔끔한 외곽선에 플랫 컬러 채색
- 4색 팔레트: 배경 #FBE9E7, 메인 #D32F2F, 강조 #FFA726, 텍스트 #B71C1C
- 가로세로 비율: 16:9
```

## 예시 4: AI 교육 → 장면형 / 녹색 팔레트 / T1 일반 텍스트형

```

## 예시 5: 도구 비교 → 분할 비교형 / 회색+파랑 / T3 블록 강조형

```

텍스트: "도구는 나눠 쓴다" — 매우 크고 굵은 한글 텍스트, #FFFFFF 흰색.

좌측 — "ChatGPT":
- 배경: #E8F0FE (연한 파랑) — 미세 도트.
- 일러스트: 모니터 화면에 채팅 UI(말풍선 3개 번갈아 배치). 모니터 위에 번개 아이콘. — #1A73E8 파랑 톤.

우측 — "Claude":
- 배경: #ECEFF1 (연한 회색) — 미세 도트.
- 일러스트: 모니터 화면에 문서 편집 UI(텍스트 줄과 톱니바퀴 패널). 모니터 위에 문서+톱니 아이콘. — #455A64 회색 톤.
