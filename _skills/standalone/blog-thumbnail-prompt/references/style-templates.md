## IT/AI 주제별 오브젝트·장면 가이드

### AI 도구 소개·리뷰
- 아이콘: 모니터+AI 채팅 UI(말풍선), 로봇 머리, 톱니바퀴
- 장면(비즈니스): 모니터 앞에서 AI 화면 가리키며 설명
- 분할: 도구A 화면 vs 도구B 화면

### AI 글쓰기·워크플로우
- 아이콘: 카드+화살표 흐름도, 문서+톱니바퀴
- 장면(크리에이터): 노트북 앞 타이핑 또는 노트에 메모
- 분할: 프롬프트 방식(종이더미) vs 워크플로우(연결된 카드)

### AI 이미지 생성
- 아이콘: 모니터+이미지+마법 지팡이, 붓+팔레트
- 장면(크리에이터): 모니터에서 이미지 결과물 보며 만족
- 분할: 텍스트 프롬프트 vs 생성된 이미지

### AI 교육·강의
- 아이콘: 칠판+AI 심볼, 책+모니터+전구
- 장면(비즈니스): 화이트보드 앞 발표 자세
- 분할: AI 없이 수동 vs AI 활용 교육

## 텍스트 배치 방식별 프롬프트 블록

각 유형 템플릿에서 `[텍스트 블록]`을 아래 중 하나로 교체하여 사용한다.

### T1. 일반 텍스트형
```
텍스트: "[10자 이내]" — 매우 크고 굵은 한글 텍스트, [텍스트색 또는 메인색].
- [위치]에 배경 위 직접 배치. 배너·블록 없음.
[선택] 서브 텍스트: "[15자 이내]" — 중간 크기, [텍스트색 연한 변형]. 맥락 키워드 포함.
```

### T2. 말풍선형
```
말풍선: 캐릭터 [방향]에 둥근 말풍선.
- 말풍선 배경 #FFFFFF 흰색, 테두리 [텍스트색 또는 메인색].
- 말풍선 안에 "[8자 이내]" — 굵은 한글 텍스트, [텍스트색].
```

### T3. 블록 강조형
```
텍스트: "[10자 이내]" — 매우 크고 굵은 한글 텍스트, #FFFFFF 흰색.
- [위치]에 [텍스트색 또는 메인색] 사각 블록, 그 위에 흰색 텍스트.
[선택] 서브 텍스트: "[15자 이내]" — 중간 크기, [메인색]. 맥락 키워드 포함.
```

### T4. 레이블형
```
레이블: 오브젝트 [위치]에 작은 태그.
- 태그 배경 [메인색], 텍스트 #FFFFFF 흰색.
- "[8자 이내]" — 굵은 한글 텍스트.
[선택] 화살표로 오브젝트와 연결.
```

### T5. 텍스트 없음
```
(텍스트 블록 생략 — 일러스트만으로 구성)
```

## A. 아이콘 중심형

### 구도: A-1(오브젝트 중앙+텍스트 하단), A-2(오브젝트 우+텍스트 좌), A-3(텍스트 상단+오브젝트 중앙), A-4(좌우대칭 — 중앙 오브젝트+좌우 보조 아이콘 대칭)

### 프롬프트 템플릿

```
블로그 썸네일 아이콘 중심형 일러스트 이미지를 생성해줘.

구도: [선택]
[좌우대칭 시] 좌우 대칭 구도. 중앙에 [메인 오브젝트], 좌측에 [보조A], 우측에 [보조B] 대칭 배치.

배경: [배경색] 위에 미세한 도트 패턴. 오브젝트 뒤에 큰 원형 블롭을 [배경색 한 톤 진한 색]으로 크게 배치.

오브젝트: [핵심 2~3개 디테일] — 라인+컬러 일러스트, [메인색] 채색, 크게 배치.

[텍스트 블록 — T1/T3/T4/T5 중 선택]

보조 장식: 소아이콘 [3~5개] 흩뿌리기 — [메인색 연한 톤]. 반짝임 2개 — [강조색].

일러스트 스타일:
- 라인+컬러 일러스트, 깔끔한 외곽선에 플랫 컬러 채색
- 4색 팔레트: 배경 [#], 메인 [#], 강조 [#], 텍스트 [#]
- 가로세로 비율: 16:9
```

### 캐릭터 × 장면 (IT/AI)

| 톤 | 캐릭터 | 장면 | 이펙트 |
|----|--------|------|--------|
| 도구 발견 | 비즈니스 | 모니터 가리키며 미소 | 반짝임, 전구 |
| 글쓰기 작업 | 크리에이터 | 노트북 타이핑, 커피 옆 | 집중선 |
| 프롬프트 실수 | 크리에이터 | 노트북 앞 고개 갸우뚱 | 물음표, 소용돌이 |
| 워크플로우 성공 | 비즈니스 | 모니터에 흐름도, 엄지 올림 | 체크마크, 반짝임 |
| 이미지 생성 | 크리에이터 | 모니터 보며 만족 | 반짝임, 별 |
| 강의 진행 | 비즈니스 | 화이트보드 앞 설명 | 전구, 화살표 |

좌측 — "[레이블]":
- 배경: [배경색 A] — 미세 도트.

우측 — "[레이블]":
- 배경: [배경색 B] — 미세 도트.
- 일러스트: [캐릭터/오브젝트 묘사]

- 이펙트: [반짝임/체크마크 등] — [강조색].

분할 장치: 중앙에 [화살표 / VS].

일러스트 스타일:

| 비교 | 좌측 | 우측 | 텍스트 예 | 레이블 예 |
