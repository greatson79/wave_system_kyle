## 기본 실행 순서

1. **SKILL.md 읽기** → 워크플로우 5단계 확인 + 장르 분기 판별
2. **장르 분기 확인 후 파일 로드** → 분기 ①만 02 필수 로드. 분기 ②는 건너뜀.
3. **입력 유형 분류** → 단발 프롬프트 / 모드 인스트럭션 / 범용 지침서
4. **01_진단_7축_체크리스트.md에서 7축 진단**
5. **약한 축 2~3개 선정** → 04_처방_패턴집.md에서 해당 스니펫만 로드
6. **Before/After 출력** → SKILL.md Phase 5 형식 준수

## 반드시 지켜야 할 강제 규칙

### ① 완성형 출력 필수
진단만 하고 끝내지 않는다. 반드시 다듬어진 최종 프롬프트를 제시한다.

### ② 사용자 톤 보존
기존 섹션 기호·말투를 AI 말투로 덮지 않는다.

### ③ 처방 근거 명시
"V축 보강 — 벡터 3종 세트 적용" 형식으로 반드시 축 이름을 밝힌다.

### ④ 재질문은 1회
판단이 애매해도 재질문은 1회. 이후에도 답 없으면 분기 ② 기본값으로 실행.

## 컨텍스트 절약 팁

- "간단히만 봐줘" → 01의 축별 점검 항목 중 최상위 1~2개만 사용
- "전체 분석해줘" → 01 전 축 + 05 사례 함께 첨부
- 동일 세션에서 여러 프롬프트 연속 다듬기 → 02 원칙을 메모리에 유지, 반복 로드 금지

## 에러·예외 상황 대응

| 상황 | 대응 |
|---|---|
| 프롬프트 없이 목적만 말함 | 초안 먼저 생성 → 그 초안을 7축으로 진단 |
| "점수 말고 결과만 줘" | 진단은 내부 수행, 출력은 After 프롬프트 + 간단한 수정 근거만 |
| "원칙은 내가 알아서 할게" | 품질 점검 간략 표기하되 삭제하지 않음 |
| 입력이 너무 길어 진단 어려움 | 모드·섹션 단위로 쪼개서 진단. "어느 부분부터 볼까요"로 재질문 가능 |
