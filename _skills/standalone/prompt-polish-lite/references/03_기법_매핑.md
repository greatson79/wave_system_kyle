## 축별 추천 기법 (우선순위 순)

### V 벡터 축 처방
- **3-Role 기법** — "[전문분야] 전문가 겸 [부가역할]"로 역할을 이중 지정해 의미 공간 좌표를 명확히 한다
- **청중 구체화 4요소** — 연령·경험수준·관심영역·현재 고민 상태를 함께 명시
- **톤 3종 지정** — 목소리(차분/열정/단호) + 문장 길이(짧게/중간/길게) + 감정 결

### L 손실함수 축 처방
- **반면교사 블록** — "이런 출력은 실패다" 예시 3가지
- **이상형 레퍼런스** — "이런 출력이 나오면 성공이다" 기준 1가지
- **도메인 금지어 세트** — 해당 분야에서 피해야 할 표현·결론 유형 명시

### M 행렬 분해 축 처방
- **컨텍스트 블록** — 조직명·대상·규모·상황 변수를 입력 슬롯으로 배치
- **대상 세그먼트 분기** — 집단별 출력 변형 설계
- **조건 분기** — 규모·상황 조건에 따른 출력 심도 조절

### C 분류 축 처방
- **자연어 트리거 복수화** — 명령어 + 자연어 표현 2~3개 병기
- **애매 시 선질문 규칙** — "~인가요, 아니면 ~인가요?" 1회 재질문 허용
- **예외 상황 감지 → 우선 처리** — 위험·긴급 키워드 감지 시 출력 최상단에 별도 블록 선행

### F 합성함수 축 처방
- **4단 구조** — 입력 해석 → 구조화 → 확장·예시 → 결론·적용
- **5단 구조** — 오프닝 → 현황 → 핵심 개념 → 실전 → 정리
- **단계 연결 명시어** — "~를 바탕으로", "~에서 도출된", "~와 연결되는"을 단계 간 다리로 삽입

### B CNN/베이지안 축 처방
- **사전정보 5대 블록** — 배경, 스타일, 선호 출처, 피해야 할 예시 유형, 최근 관심사
- **포커스 지시어** — "특히 ~에 주의하라", "~는 반드시 포함하라", "~는 다루지 말라"
- **출처 화이트리스트** — 신뢰할 출처 유형 명시, 미확인 정보 배제

### G 생성 축 처방
- **섹션 기호 세트** — 사용자 기존 기호 체계 유지 또는 신규 지정
- **분량 지정** — 항목 개수, 글자 수, 예상 분량을 구체적으로 명시
- **완성형 기준** — "바로 [사용/발송/게시] 가능한 수준"으로 완성도 기준 명시
