# 처방 패턴집
*약한 축별 바로 붙여 쓰는 스니펫 모음. 대괄호 [ ] 안은 상황 맞춰 치환.*

---

## V 벡터 3종 세트

```
**역할:** [전문분야] 전문가 겸 [부가역할]
**청중:** [연령·경험수준] / [관심영역] / [현재 고민]
**톤:** [목소리] + [문장 길이] + [감정 결]
```

예:
```
역할: 콘텐츠 전략가 겸 카피라이터
청중: 30~40대 직장인 / 생산성 관심 / 시간 부족 고민
톤: 간결함 + 짧은 문장 + 공감 + 실용적
```

## L 손실함수 블록

```
**이상적인 출력의 기준:**
- [기준 1]
- [기준 2]

**피해야 할 출력 3가지:**
- [반면교사 1]
- [반면교사 2]
- [반면교사 3]

**도메인 금지어:** [해당 분야에서 피해야 할 표현·결론 유형]
```

## M 컨텍스트 블록

```
**맥락 정보:**
- 조직명·업종·규모:
- 대상:
- 현재 상황:
- 올해 집중 과제:
- 현재 가장 힘든 과제:

**조건 분기:**
- 소규모 → [출력 간소화 규칙]
- 중규모 → [표준 규칙]
- 대규모 → [확장 규칙]
```

## C 분류·분기 블록

```
**트리거:** `/모드명` 또는 다음 자연어 중 하나
- "[자연어 1]"
- "[자연어 2]"

**판단이 애매할 때:** 다음 한 문장으로 재질문한다.
"[맥락 A]인가요, 아니면 [맥락 B]인가요?"

**예외 키워드 감지:** [위험·긴급 상황 키워드] 감지 시 출력 최상단에 별도 블록 선행
```

## F 합성함수 단계 분리

```
**처리 순서:**
1단계 — [입력 해석] → 산출물: [ ]
2단계 — [구조화] → 산출물: [ ], 1단계 결과를 바탕으로
3단계 — [확장·예시] → 산출물: [ ], 2단계에서 도출
4단계 — [결론·적용] → 산출물: [ ], 핵심 목적과 연결하여
5단계 — [검수] → 산출물: [ ], 이상적 기준과 대조
```

## B 사전정보 5대 블록

```
**사전정보 (반드시 고려):**

1. 배경: [업종·분야·조직 특성]
2. 스타일: [선호 톤·분량·주력 포맷]
3. 선호 출처·예시 유형: [데이터/사례/연구/경험담 등]
4. 피해야 할 예시 유형: [정치적 논쟁·특정 집단 비방·미확인 정보 등]
5. 최근 관심사: [현재 중점 프로젝트·이슈·캠페인]

**포커스 지시:**
- 특히 [핵심 디테일]에 주의한다
- 반드시 [필수 요소]를 포함한다
- [금지 영역]은 다루지 않는다
```

## G 완성형 출력 틀

```
**출력 형식 (반드시 이 구조로):**

[섹션 1] — [분량·개수 지정]
[섹션 2] — [분량·개수 지정]
[섹션 3] — [분량·개수 지정]
[마무리] — [완성형 기준]

**완성도 기준:** 바로 [사용/발송/게시/낭독] 가능한 수준
```

## 조합 템플릿 — 풀세트 (모드·인스트럭션 신설 시)

새 모드를 처음부터 설계할 때 아래 블록을 순서대로 채우면 7축이 동시에 충족된다.

```
## [모드명]

**트리거:** [명령어] 또는 자연어 [2~3개]

**역할:** (V)

**입력 양식:** (M + B)
- 맥락·상황 변수
- 사전정보 블록

**처리 순서:** (F)
- 1단계 …
- 2단계 …
- 3단계 …

**이상적 출력의 기준:** (L)
**피해야 할 출력:** (L)

**출력 형식:** (G)
- 섹션·분량·완성도 기준

**분류 분기:** (C)
- 애매 시 선질문
- 예외 키워드 감지
```
