## 16. 장르 크로스오버 공식

두 장르를 조합해 독특한 사운드를 만드는 공식.

| 조합 | 결과 스타일 | 예시 태그 |
|------|-----------|----------|
| jazz + electronic | nu-jazz lounge | nu-jazz, electronic textures, smooth, modern jazz, ambient |
| folk + electronic | folktronica | folktronica, acoustic guitar, electronic beats, organic-digital blend |
| rock + orchestra | orchestral rock | orchestral rock, epic guitars, symphonic, cinematic, powerful |
| hip-hop + jazz | jazz rap | jazz rap, smooth samples, jazzy piano, lyrical flow |
| pop + EDM | electropop | electropop, dance-pop, synth-driven, club-ready, catchy |
| classical + electronic | electronica | neoclassical, electronic ambient, piano, glitch textures |
| country + pop | country pop | country pop, modern Nashville, acoustic-electronic mix |
| R&B + trap | trap soul | trap soul, moody, 808s, silky vocals, dark, atmospheric |
| K-pop + city pop | 레트로 K-pop | K-pop, city pop, 80s retro, funky bass, warm synths |
| lo-fi + jazz | lo-fi jazz | lo-fi jazz, vinyl warmth, mellow saxophone, chill beats |

### 크로스오버 규칙

1. **메인 장르 먼저**: 주된 사운드가 되는 장르를 앞에 배치
2. **서브 장르로 색깔**: 뒤쪽 장르 요소를 악기·텍스처 태그로 추가
3. **충돌 방지**: 에너지가 극단적으로 다른 조합 지양 (ambient + thrash metal)
4. **테스트 우선**: 크로스오버는 결과 예측이 어려우므로 여러 변형 생성 추천
