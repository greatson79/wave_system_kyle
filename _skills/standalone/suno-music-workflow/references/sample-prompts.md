# 장르별 완성 프롬프트 예시 (Sample Prompts)

Suno Custom Mode에 바로 붙여넣을 수 있는 완성 프롬프트 세트 예시.
각 예시는 Style Prompt + Custom Lyrics 쌍으로 구성.

**주의: Custom Lyrics에 소괄호 `( )`를 사용하지 않는다. 모든 지시는 대괄호 `[ ]` 태그로만 한다.**

## 프롬프트 활용 팁

1. **그대로 복사**: 코드블록 내용을 각각 Style Prompt와 Custom Lyrics 필드에 붙여넣기
2. **부분 수정**: 가사 내용만 바꾸고 구조와 태그는 유지하면 안정적
3. **변형 테스트**: Style Prompt에서 태그 1~2개만 바꿔서 다른 느낌 테스트
4. **길이 조절**: 섹션을 추가/삭제해 길이 조절
5. **소괄호 절대 금지**: Custom Lyrics에 `( )` 넣으면 Suno가 가사로 부름
