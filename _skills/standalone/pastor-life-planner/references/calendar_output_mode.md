# 캘린더출력 모드 — 구글 캘린더 형식 출력 + 날짜 계산

> 계획이 캘린더에 없으면, 계획이 없는 것이다.

---

## 진입 방법

```
/캘린더 [계획 요약 또는 단계 결과물]

예시:
/캘린더 위에서 나온 목회방향 + 가정계획 통합해서 1월 일정으로
/캘린더 강의 3회를 6월 안에 배치해줘
/캘린더 오늘부터 12주 큐티 루틴 시작일 계산해줘
```

---

## 구글 캘린더 이벤트 출력 포맷

아래 형식으로 출력하면 구글 캘린더에 바로 붙여넣거나
구글 캘린더 MCP와 연동해서 자동 입력 가능하다.

```
[이벤트명] | [날짜] | [시간] | [반복여부] | [메모]

예시:
큐티 루틴 시작 | 2026-06-02 | 06:00-06:30 | 주 5회 (월~금) | 개인 말씀 시간
부부 데이트 | 2026-06-07 | 18:00-21:00 | 격주 토요일 | 자녀 없이
강의 1회차 | 2026-06-15 | 14:00-16:00 | 단회 | [장소/온라인]
6개월 회고 | 2026-06-30 | 09:00-11:00 | 단회 | pastor-life-planner /6개월회고
```

---

## 날짜 계산 기능

아래 계산을 요청하면 현재 날짜 기준으로 계산해서 출력한다.

- "오늘부터 12주 후": 현재 날짜 + 84일
- "다음 분기 시작": 현재 분기 다음 분기 첫날
- "6개월 후 회고": 현재 날짜 + 180일
- "매주 월요일 10번": 10주치 날짜 목록
- "40일 기도 시작 ~ 종료": 시작일 + 39일

---

## 구글 캘린더 MCP 연동 (선택)

구글 캘린더 MCP가 연결되어 있으면:
- 위 포맷의 이벤트를 실제 캘린더에 자동 추가 가능
- 기존 일정과 충돌 여부 자동 확인
- 반복 이벤트 일괄 생성

연동이 안 되어 있으면:
- 위 포맷을 복사해서 구글 캘린더 → "일정 가져오기" (CSV 형식 안내 포함)
- 또는 수동 입력 가이드 제공

## 연간 마스터 캘린더 출력

`/전체계획` 또는 `/캘린더 연간` 요청 시:
7개 영역의 주요 일정을 월별로 통합한 마스터 캘린더를 출력한다.

```
## 2026년 연간 마스터 캘린더

| 월 | 목회방향 | 가정 | 관계 | 나의삶 | AI/MCP | 회고 |
|----|---------|------|------|-------|--------|------|
| 1월 | ... | ... | ... | ... | ... | - |
| 2월 | ... | ... | ... | ... | ... | - |
...
| 6월 | ... | ... | ... | ... | ... | 상반기 회고 |
...
| 12월 | ... | ... | ... | ... | ... | 연간 회고 |
```
