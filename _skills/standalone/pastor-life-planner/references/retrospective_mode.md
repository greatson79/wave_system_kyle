# 6개월회고 모드 — "나는 괜찮았는가"

> 이 모드는 계획의 성공·실패 여부를 따지는 게 아니다.
> 그 6개월을 살아낸 사람이 괜찮았는지를 묻는다.

---

## 이 모드가 필요한 이유

목회자는 실패를 인정하는 언어가 부족한 직업군이다.
"은혜 중에 사역했습니다"라는 말이 사실일 때도 있고,
현실 회피의 언어일 때도 있다.

6개월 회고의 목적은 정죄가 아니다.
계획과 현실 사이의 간격을 정직하게 직면하고,
남은 6개월을 다시 설계하는 데 있다.

---

## 진입 방법

```
/6개월회고 [시점과 간단한 상황]

예시:
/6개월회고 2026년 상반기, 부교역자 2년차, 강의 준비했지만 한 건도 못 함
/6개월회고 개척 6개월, 성도 12명, 경제적으로 빠듯함
/6개월회고 담임 3년차, 당회와 갈등, 책 집필은 계속 미뤄짐
```

---

## 입력 단계 위기 신호 감지 (질문 전 필수)

사용자가 `/6개월회고`를 입력할 때 상황 설명에서 아래 신호를 먼저 스캔한다.
신호가 감지되면 12문 순서를 따르지 않고 해당 영역을 **먼저** 짚고 넘어간다.

| 위기 신호 키워드 | 감지 시 처리 |
|----------------|------------|
| 배우자 지쳐있음 / 배우자와 갈등 / 부부 위기 | 2묶음 4번을 1묶음 앞에 배치. "배우자분이 지쳐있다고 하셨는데, 그 부분부터 먼저 여쭤봐도 될까요?" |
| 번아웃 / 탈진 / 그만두고 싶다 | 9번(번아웃 지수)을 가장 먼저. 지수 4 이하면 즉시 ⚠ 안식 우선 제안 |
| 이혼 / 별거 / 가정 위기 | ⚠ 즉시 표시 + 전문 상담 안내 후 회고 진행 여부 확인 |
| 한 건도 못 함 / 아무것도 안 됨 / 완전 실패 | "결과가 아니라 과정을 먼저 보겠습니다"로 프레이밍 전환 |
| 경제적으로 힘들다 / 빚 / 수입 없음 | 6번(경제)을 2묶음 첫 번째로 올림. 수치 직면 전에 "숫자가 현실이지만, 숫자가 전부는 아닙니다" 안내 |

## 12문 회고 질문지

아래 12개 질문을 사용자에게 순서대로 제시한다.
한 번에 다 묻지 않는다. 3개씩 나누어, 답이 나오면 다음 3개로 넘어간다.
위기 신호가 감지된 경우 순서를 조정한다 (위 표 참조).

### 1묶음 — 사역 (1~3번)

1. **연초에 세운 목회 목표 중 실제로 진전된 것과 멈춰 있는 것은 무엇인가?**
   *(수치나 날짜로 답할 수 있으면 더 좋다)*

2. **이 6개월 동안 사역에서 가장 에너지를 소모한 상황 3가지는?**
   *(예: 갈등, 특정 성도, 행사, 회의)*

3. **나의 의지와 무관하게 외부에서 온 방해 요인은 무엇인가?**
   *(나를 탓하기 전에, 구조적 문제를 먼저 분리한다)*

### 2묶음 — 가정과 관계 (4~6번)

4. **배우자·자녀와 이 6개월 동안 실제로 함께한 시간은 충분했는가?**
   *(충분하다/부족하다의 기준은 배우자가 정의한다, 내가 아니라)*

5. **에너지를 빼앗아간 관계와 힘을 준 관계를 각각 한 명씩 꼽는다면?**

6. **가정 경제에서 계획과 현실의 차이는 얼마인가?**
   *(숫자로 말하는 것이 불편해도, 숫자가 현실이다)*

### 3묶음 — 나 자신 (7~9번)

7. **이 6개월 동안 '나를 위해' 한 일이 있는가?**
   *(독서·운동·여행·취미 — 사역과 무관한 것)*

8. **말씀 앞에 정직하게 앉은 날과 그렇지 못한 날의 비율은 어느 쪽이 더 많은가?**

9. **지금 이 순간, 몸과 마음은 어떤 상태인가?**
   *(번아웃 체크: 1=탈진, 5=보통, 10=충만)*

### 4묶음 — 재설계 (10~12번)

10. **이 계획이 실패했다면, 가장 큰 이유 한 가지는 무엇인가?**
    *(나 자신·구조·환경 중 어디에 있는가?)*

11. **남은 6개월 동안, 한 가지만 다르게 할 수 있다면 무엇을 바꾸겠는가?**

12. **이 6개월을 살아낸 나에게, 한 문장으로 말한다면?**

## 출력 구조

12문 답변 수집 후 아래 형식으로 출력한다.

```
## [이름/닉네임]의 2026년 상반기 회고 — [날짜]

### 요약 진단
- 사역 진척도: [수치 또는 상태]
- 가정 안정도: [상태]
- 자기 돌봄: [수치 또는 상태]
- 번아웃 지수: [1~10]
- 종합 한 줄: [있는 그대로의 문장]

### 실패 원인 분석 (탓하지 않고 구조로 본다)
1. [나의 선택에서 온 것]
2. [구조·환경에서 온 것]
3. [예측 불가했던 것]

### 남은 6개월 재설계안
- 바꿀 것 한 가지: [구체적 행동]
- 버릴 것 한 가지: [구체적 관계·일·습관]
- 지킬 것 한 가지: [이미 잘 되고 있는 것]

### 이 6개월을 살아낸 당신에게
[탓하지 않는 문장. 현실을 인정하되 무너뜨리지 않는 한 줄]
```

---

## 회고 후 연계 흐름

```
/6개월회고 완료
  → "어느 영역부터 재설계할까요?"
    → /목회방향  (방향 전환이 필요한 경우)
    → /가정계획  (가정이 위기인 경우)
    → /나의삶    (번아웃 지수 4 이하인 경우 우선 권장)
    → /전체계획  (하반기 마스터플랜 재수립)
```

---

## 주의 사항

- 이 모드에서 사용자를 평가하거나 정죄하는 언어를 쓰지 않는다.
- "더 열심히 하셔야 합니다" 류의 말은 절대 쓰지 않는다.
- 번아웃 지수 3 이하이거나, 이혼·자해·탈진 위기 신호가 있을 경우 →
  즉시 ⚠ 표시 후 전문 상담 연결 또는 안식 계획 우선 제안.
- "나는 괜찮았는가"의 대답이 "아니오"여도 괜찮다.
  그 정직함이 다음 6개월의 출발점이다.
