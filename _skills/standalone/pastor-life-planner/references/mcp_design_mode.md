# MCP설계 모드 — AI 도구를 사역과 생산성에 통합하는 로드맵

> 목회자에게 AI는 대체제가 아니라 보조 도구다.
> 올바르게 설계하면 시간을 절약하고, 잘못 설계하면 또 다른 소음이 된다.

---

## 현재 수준별 진입 경로

| 수준 | 특징 | 시작점 |
|------|------|--------|
| 0단계 | ChatGPT/Claude 간단히 써봄 | AI 활용 루틴 설계부터 |
| 1단계 | 시스템 인스트럭션(MD)을 써봄 | 커스텀 MD 고도화 |
| 2단계 | 여러 AI 도구 연결해서 씀 | MCP 서버 연결 설계 |
| 3단계 | Claude Code 또는 Cowork 진입 | 자동화·스킬 제작 |

---

## 단계별 설계 로드맵

### 0→1단계: 루틴 AI 사용자

**목표:** AI가 일상 사역에 자연스럽게 녹아드는 루틴 설계

- 설교 준비에 AI 활용 (본문 분석·예화 검색·개요 생성)
- 행정 문서 자동화 (보고서·안내문·이메일)
- 상담 전 정보 정리

**추천 도구:** Claude.ai Pro 또는 Gemini Advanced

---

### 1→2단계: MD 사용자 → MCP 연결

**목표:** 여러 도구를 하나의 흐름으로 연결

연결 가능한 MCP 서버 예시:
- **Google Calendar MCP** → 사역 일정 자동 입력
- **Google Drive MCP** → 설교 원고·회의록 자동 저장
- **Gmail MCP** → 성도 이메일 분류·답장 초안

`/캘린더` 명령어는 이 단계에서 구글 캘린더 MCP와 연동된다.

---

### 2→3단계: Claude Code 진입

**목표:** 반복 작업을 코드로 자동화 / 커스텀 스킬 제작

- Claude Code 설치 (터미널 기반)
- 기존 스킬(pastor-ai-system·yeyepapa-sermon-studio)을 코드로 확장
- 교회별 맞춤 AI 시스템 납품 자동화

**진입 요건:** 터미널 기본 사용 능력 / Node.js 환경

---

