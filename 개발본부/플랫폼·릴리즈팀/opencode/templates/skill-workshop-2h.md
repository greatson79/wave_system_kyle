# 스킬(Skills) 만들기 입문 강의

> GPT Codex로 나만의 스킬을 만드는 법

**대상**: 코딩 초보자  
**시간**: 2시간 (120분)  
**형식**: 이론 + 실습 (1:1 비율)

---

## 강의 개요

| 항목 | 내용 |
|------|------|
| **목표** | 스킬의 개념 이해 + 나만의 첫 스킬 만들기 |
| **선수 지식** | 코딩 기초 (변수, 함수 개념) |
| **준비물** | VS Code, GPT Codex 접근 가능 환경 |

---

## 학습 목표

1. **이해**: 스킬이 무엇인지 설명할 수 있다
2. **분석**: 기존 스킬의 구조를 읽고 이해할 수 있다
3. **응용**: 간단한 스킬을 직접 만들 수 있다
4. **확장**: 만든 스킬을 자신의 작업에 적용할 수 있다

#### 🎯 핵심 개념: 스킬이란?

**비유로 이해하기:**
- 스킬 = **레시피북**
- GPT Codex = **요리사**
- 스킬 = 요리사에게 "이렇게 만들어줘"라고 주는 **지시서**

**日常生活 예시:**
```
💬 "Korean BBQ 만들어줘" (일반 요청)
   ↓ 명확한 스킬이 없으면 매번 설명해야 함

💬 "/recipe korean-bbq" (스킬 사용)
   ↓ 레시피북을 주면 정확하게 만들어줌
```

#### 📂 스킬 파일 구조

```
.skills/                    ← 스킬 폴더
└── my-first-skill/        ← 스킬 이름 (폴더)
    ├── SKILL.md           ← ⭐ 핵심 파일
    └── settings.json      ← 선택 (설정)
```

#### 🔍 실습 1: 기존 스킬 분석

**실습 목표**: 주어진 스킬 파일을 읽고 구조 파악

```markdown
<!-- my-first-skill/SKILL.md -->

---
name: my-first-skill
description: 이 스킬이 무엇을 하는지 한 줄 설명
---

## Overview
이 스킬의 목적 설명

## When to use me
- 상황 1
- 상황 2

## What I do
1. 첫 번째 할 일
2. 두 번째 할 일
```

**분석 체크포인트:**
- [ ] `---` 로 감싸진 부분의 이름은?
- [ ] `description`은 어디에 쓰이나?
- [ ] `## When to use me`는 언제 필요한가?

#### 🎯 실습 과제: "나의 daily planner 스킬" 만들기

**과제 요구사항:**
```
테마: 하루 일정을 계획하는 스킬
대상: 자기 자신을 위한 개인 스킬
기능:
1. 오늘의 목표 설정
2. 시간별 계획 짜기
3. 체크리스트 만들기
```

#### 📝 단계별 가이드

**Step 1: 폴더 만들기**
```
.skills/
└── daily-planner/
```

**Step 2: SKILL.md 파일 만들기**

```markdown
---
name: daily-planner
description: 오늘의 일정을 계획하고 추적하는 스킬
---

## Overview
매일 아침 10분, 하루를 효율적으로 계획하는 스킬입니다.

## When to use me
- 아침에 하루를 계획하고 싶을 때
- 주간 목표를 세우고 싶을 때
- 일정을 정리하고 싶을 때

## What I do
1. 오늘의 가장 중요한 3가지를 질문
2. 시간대별 일정 제안
3. 체크리스트 형식으로 정리

## Output Format
다음 형식으로 결과를 제공합니다:

# 📅 오늘의 계획 - [날짜]

## 🎯 오늘의 핵심 목표
1. [가장 중요한 일]
2. [두 번째]
3. [세 번째]

## ⏰ 시간별 계획
| 시간 | 활동 | 메모 |
|------|------|------|
| 9:00 | | |
```

**Step 3: 스킬 테스트 (GPT Codex에서)**

```
GPT Codex에서:
/skill daily-planner
오늘 하루 계획해줘
```

## Q&A 예상 질문

**Q: 스킬과 일반 프롬프트의 차이는?**
A: 스킬은 저장해서 재사용 가능, 프롬프트는 매번 입력해야 함

**Q: 여러 개의 스킬을 만들 수 있나요?**
A: 네, 원하는 만큼 만들 수 있습니다

**Q: 다른 사람에게 스킬을 공유할 수 있나요?**
A: 네, 스킬 폴더를 공유하면 됩니다

**Q: 스킬이 작동하지 않으면怎么办?**
A: 파일 경로, 이름, frontmatter 형식을 확인하세요
