## Overview

이 스킬은 모든 주제에 대해 체계적인 강의 커리큘럼을 설계합니다. 온라인/오프라인 하이브리드授课를 고려하여 설계합니다.

## When to use me

- 새 강의를 개설할 때
- 기존 강의 커리큘럼을 재설계할 때
- 특정 주제를 깊이 있게 다루는 강의를 만들고 싶을 때
- 학습 경로를 설계할 때

## What I do

1. **주제 분석**: 대상 청중, 수준, 목표 파악
2. **커리큘럼 설계**: 학습 목표 → 모듈 → 수업 → 세부 토픽
3. **수업 설계**: 각 수업별 목표, 내용, 활동, 평가 방법
4. **산출물 생성**: 마크다운 형태의 강의 계획서

## How to use

```bash
/skill course-design
```

다음 정보를 제공하면 더 정확한 커리큘럼을 설계합니다:
- 강의 주제
- 대상 수준 (초급/중급/고급)
- 총 강의 시간
- 선호하는授课 방식

## Output Format

설계된 커리큘럼은 다음 구조로 제공됩니다:

```markdown
# [강의명]

## 강의 개요
- 대상: ...
- 기간: ...
- 목표: ...

## 학습 목표
1. ...
2. ...

## 커리큘럼

### Module 1: [제목]
#### Session 1: [제목]
- 목표: ...
- 내용: ...
- 활동: ...
- 평가: ...

## 수업 계획서
[세부 수업 계획]
```

## Principles

- **역량 중심**: 단순 지식 전달이 아닌 역량 개발 지향
- **점진적 난이도**: 기초 → 심화 → 응용 순서
- **실습 포함**: 이론만 아닌 Hands-on 활동 포함
- **평가 설계**: formative + summative 평가 모두 포함
