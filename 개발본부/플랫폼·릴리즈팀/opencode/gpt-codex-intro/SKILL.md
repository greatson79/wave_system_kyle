## Overview

GPT Codex 입문자를 위한 실습 중심 학습 스킬입니다. AI를 활용한 코딩의 기본 개념부터 실제 프로젝트까지 단계별로 안내합니다.

## When to use me

- 코딩을 처음 시작하는 경우
- AI 도구를 코딩에 활용하고 싶은 경우
- GPT Codex의 기능을 배우고 싶은 경우
- 실습을 통해 확실히 배우고 싶은 경우

## Learning Path

### Level 1: 기본 개념 (1-2일차)
- AI 어시스턴트란?
- GPT Codex 소개와 특징
- 코딩 환경 설정
- 첫 번째 질문하기

### Level 2: 기초 실습 (3-5일차)
- 간단한 질문으로 코드 생성
- 코드 설명 받기
- 버그 찾기와 수정 요청
- 주석 추가 및 코드 정리

### Level 3: 실전 적용 (1주차)
- 함수 작성 요청하기
- 데이터 처리 코드 만들기
- 간단한 프로젝트 시작
- 코드 리팩토링

### Level 4: 심화 학습 (2주차)
- 프로젝트 기반 학습
- 디버깅 전략
- 코드 최적화
- 테스트 코드 작성

## How to use

1. **순서대로 학습**: Level 1부터 시작하여 순차적으로 진행
2. **실습 위주**: 각 단계에서 직접 코드를 작성하고 실행
3. **질문하기**: 궁금한 점은 즉시 질문
4. **복습하기**: 완료한 내용을 복습하고 응용

## 실습 예시

### 예시 1: 코드 생성 요청
```
"Python으로 숫자 맞추기 게임 만들어줘"
```

### 예시 2: 코드 설명 요청
```
"이 코드가 어떻게 작동하는지 설명해줘"
```

### 예시 3: 버그 수정 요청
```
"이 코드에 에러가 나는데 어디가 문제야?"
```

### 예시 4: 코드 개선 요청
```
"이 코드를 더 효율적으로 만들어줘"
```

## 핵심 원칙

1. **명확한 요청**: 무엇을 원하는지 구체적으로 표현
2. **점진적 발전**: 작은 것부터 시작하여 점차 복잡하게
3. **실행 후 확인**: 생성된 코드는 반드시 직접 실행하고 확인
4. **이해 후 응용**: 복사粘贴ではなく 이해하고 나만의 것으로 만들기

## Common Mistakes to Avoid

- 너무 복잡한 요청을 한 번에 하기
- 생성된 코드를 확인하지 않고 사용하기
- 모르는 용어를 그냥 넘기기
- 혼자 시도하지 않고 바로 답만 받기

학습 진행 상황에 따라 다음을 제공합니다:

```markdown

- [목표 1]
- [목표 2]

```[언어]
[코드]
```

### 복습 체크리스트
- [ ] 개념 이해
- [ ] 실습 완료
- [ ] 응용 가능
```
