# AgenticWorkflow 부모 프레임워크 템플릿

이 폴더는 새로운 AgenticWorkflow 자식 프로젝트를 만들 때 사용하는 **부모 프레임워크 템플릿**입니다.

## 사용법

1. 이 폴더 전체를 새 프로젝트 폴더로 복사합니다
2. `CLAUDE.md`를 새 프로젝트에 맞게 수정합니다 (프로젝트명, 목표, 구조 등)
3. `AGENTS.md`를 새 프로젝트의 에이전트 구성에 맞게 수정합니다
4. 프로젝트별 문서를 추가합니다 (예: `NEWPROJECT-README.md`, `NEWPROJECT-USER-MANUAL.md`)
5. `DECISION-LOG.md`는 새 프로젝트에서 새로 시작하거나, 부모 로그를 유지할 수 있습니다

## 포함된 파일

| 파일 | 역할 | 수정 필요 여부 |
|------|------|--------------|
| `soul.md` | 프레임워크의 핵심 철학/신념 | 보통 그대로 유지 |
| `CLAUDE.md` | AI 에이전트 지시서 (헌법) | **반드시 프로젝트에 맞게 수정** |
| `AGENTS.md` | 에이전트 설계 문서 | **반드시 프로젝트에 맞게 수정** |
| `AGENTICWORKFLOW-ARCHITECTURE-AND-PHILOSOPHY.md` | 설계 철학/아키텍처 | 보통 그대로 유지 |
| `AGENTICWORKFLOW-USER-MANUAL.md` | 프레임워크 사용법 | 보통 그대로 유지 |
| `DECISION-LOG.md` | 설계 결정 로그 | 새 프로젝트에 맞게 초기화 또는 유지 |
| `COPYRIGHT.md` | 저작권 | 보통 그대로 유지 |
