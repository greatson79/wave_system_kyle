# 청소년 소그룹 나눔지 작성 규칙

## 톤

- 친근하고 솔직한 문체 (존댓말 + 친근체 혼합)
- "~해요" / "~인 거 같아" 수준의 자연스러운 말투
- 쉬운성경 인용 (개역개정 아님)
- 이모지 적절히 사용 가능

## 제목 변환

설교 제목을 10대가 공감할 수 있는 언어로 재구성한다.
- 원본: "고난받는 종의 섬김" → 변환: "아무도 몰라주는데 왜 섬겨야 해?"
- 원본: "섬김의 리더십" → 변환: "진짜 리더는 뭐가 다를까?"

## 한 줄 핵심

CMT를 10대 눈높이로 1-2문장으로 변환한다.
- 신학 용어 사용 금지
- "이번 주 핵심은 이거야:" 로 시작

## 질문 설계 원칙

### 공감 질문 (1개)
- 학교, 친구, SNS, 가족 등 10대 일상과 연결
- "학교에서 ~ 한 적 있어?" / "SNS에서 ~ 보면 어떤 생각 들어?"
- 본문 주제를 간접적으로 환기

### 본문 연결 (1-2개)
- 본문의 상황과 10대의 상황을 이어주는 질문
- "이 말씀이 ~ 상황이랑 어떻게 연결될까?"
- "예수님이라면 ~ 할 때 어떻게 하셨을까?"
- 너무 무겁지 않게, 생각을 여는 수준

### 실천 질문 (1개)
- "이번 주에 뭘 다르게 해볼 수 있을까?"
- 구체적이고 작은 것
- 친구에게 말할 수 있는 수준

## 이번 주 챌린지

- 1가지만, 아주 구체적
- SNS에 공유할 수 있는 형태면 더 좋음
- 예: "이번 주 하루, 먼저 '고마워'라고 말해보기"
- 예: "인스타 스토리에 오늘 감사한 것 1개 올리기"

## 기도

빈칸 채우기 양식:
```
하나님, 이번 주 제가 ________________ 할 수 있게 도와주세요.
제 마음에 ________________ 을/를 채워주세요.
예수님의 이름으로 기도합니다. 아멘.
```

## 금지 사항

- 어른 말투로 훈계하지 않는다
- "너희는 ~해야 해" 식의 명령형 사용 금지
- 죄책감을 주는 질문 금지
- 너무 긴 텍스트 금지 (A4 1장 이내)
