# Mode C — 원포인트 설교 구조 (One-Point Sermon)

하나의 본문에서 하나의 핵심 메시지(HP)를 도출하고, Movement 1-5를 통해 논리적으로 전개하는 아웃라인 전용 구조.

Mode C는 장르에 의해 자동 선택되지 않는다. 사용자가 "원포인트"를 명시하거나, 짧은 설교(15-20분) 또는 특정 상황(수련회, 새벽기도, 특별집회 등)에서 사용자가 요청할 때 선택한다.

---

## 핵심 원칙

| 원칙 | 설명 |
|---|---|
| **One Point** | 설교 전체가 하나의 HP를 향해 수렴한다 |
| **아웃라인 전용** | 원고로 확장하지 않는다. 구조와 논리만 제공한다 |
| **FCF → CMT → HP 진행** | 인간 조건 → 하나님의 구속 행위 → 그리스도 중심 성취 → 성령의 적용 |
| **반도덕주의** | 적용이 도덕주의로 퇴행하지 않는다. HP는 은혜 기반 변화를 반영한다 |
| **원어 풍성화** | 각 무브먼트에서 핵심 원어를 통해 본문의 의미를 깊이 있게 전달한다. → 상세: `rules/original_language.md` |
| **예화 전략** | 서론에 인문학적 예화를 포함하고, 각 무브먼트에서 필요 시 예화를 삽입한다. → 상세: `rules/illustration.md` |

---

## 복음 프레임워크 (내부 논리)

```
Human Condition (FCF)
  → Redemptive Action of God
    → Christ-centered Fulfillment
      → Spirit-empowered Application (HP)
```

---

## Movement 1-5 아키텍처

```
서론
  - 문화적/인문학적 접속 (청중의 세계에서 시작)
  - 문제 제기
  - 본문과의 긴장 형성

Movement 1 (M1) — 배경과 심화
  - 역사적·문맥적 배경
  - 신학적 문제 심화

Movement 2 (M2) — FCF 직면
  - FCF 명시적 선언
  - 청중 공감 연결

Movement 3 (M3) — CMT 도출
  - 본문의 중심 메시지 (CMT) 선언
  - 하나님의 구속적 메시지

Bridge — Cross Impact 연관성 분석
  - CMT × FCF → 4영역 교차 분석
  - 연관성 검증 (3항목)
  → 상세: rules/cross_impact.md

Movement 4 (M4) — 현대 적용
  - Bridge에서 도출된 영역별 구체적 적용
  - 구체적 사례

Movement 5 (M5) — 통합
  - M1-M4의 논리 통합
  - 결론 준비 — HP를 향한 수렴

결론

H.P. (Homiletical Point)
  1. 종교적 언어 포함 버전
  2. 종교적 언어 제외 버전
```

---

## Movement 검증 프로토콜

아웃라인 출력 전 내부적으로 검증한다:

| Movement | 검증 항목 |
|---|---|
| M1 | 문맥적·신학적 배경이 충분한가? |
| M2 | FCF가 명시적으로 선언되었는가? |
| M3 | CMT가 본문에서 명확히 도출되었는가? |
| Bridge | Cross Impact 연관성이 본문 근거로 도출되었는가? 선택 영역이 자연스러운가? |
| M4 | Bridge에서 도출된 영역별 적용이 구체적이고 현대적 맥락에 맞는가? |
| M5 | M1-M4가 논리적으로 통합되어 HP를 향해 수렴하는가? |
| HP | CMT와 FCF 모두를 반영하는가? |

---

## 스코프 규칙

- 아웃라인 형식만 출력한다. 설교 원고로 확장하지 않는다
- 외부 신학 체계를 삽입하지 않는다
- 출처를 확인할 수 없는 인용구나 일화를 만들어내지 않는다
- 청중이 명시되지 않은 경우 가정하지 않는다
- 불확실한 정보는 포함하지 않고 생략한다

## Mode C 체크리스트

- [ ] 설교 전체가 하나의 HP를 향해 수렴하는가?
- [ ] FCF → CMT → HP 진행이 논리적인가?
- [ ] M1-M5 각 무브먼트가 고유 역할을 수행하는가?
- [ ] 적용이 도덕주의로 퇴행하지 않는가?
- [ ] HP가 CMT와 FCF 모두를 반영하는가?
- [ ] HP 두 버전(종교적/비종교적)이 모두 제공되었는가?
- [ ] 아웃라인 형식을 유지했는가? (원고 확장 없음)
- [ ] 각 무브먼트에 핵심 원어가 포함되어 본문 설명이 풍성한가?
- [ ] Bridge에서 Cross Impact 4영역 교차 분석이 수행되었는가?
- [ ] Bridge의 연관성이 3항목 검증(논리적/본문근거/비인위적)을 통과하는가?
- [ ] M4의 적용이 Bridge에서 선택된 영역을 기반으로 구체화되었는가?
- [ ] 서론에 온세대 인문학적 예화가 포함되었는가?
- [ ] Bridge가 M3(고대)과 M4(현대) 사이를 자연스럽게 연결하는가?
- [ ] 예화가 필요한 곳에만 선별적으로 삽입되었는가?
