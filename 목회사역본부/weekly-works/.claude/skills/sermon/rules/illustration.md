# 예화 규칙 — SermonStory Companion 기반

모든 설교 모드(A/B/C)에서 예화를 다룰 때 적용한다.

---

## 예화의 본질

예화는 **다리**다. 본문과 청중을 연결하는 것이 예화의 존재 이유이며, 예화 자체가 메시지가 되어서는 안 된다.

---

## 예화 소스 우선순위 — 인문학 최우선 ★2026-07-18 (주인님 확정)

예화의 재료(소스)는 아래 우선순위로 고른다. **인문학 스토리를 최우선**으로 한다.

| 순위 | 소스 | 설명 |
|---|---|---|
| **1 (최우선)** | **인문학 스토리** | 문학(소설·시·희곡)·고전·역사적 사건과 인물·위인 전기·철학적 일화·예술(그림·음악)·영화·연극 등 인류가 오래 축적한 이야기. 시대를 초월한 보편성과 깊이로 본문의 진리를 인간 경험으로 번역한다 |
| **2** | 일상·보편 경험 장면 | 인문학 스토리로 진입이 어렵거나 즉각적 공감이 필요할 때 |
| **3 (최소·보조)** | 검증된 통계·시사 | 논증 보강용으로만. 감정 조작·선정·분열 이슈 금지 |

**작성 절차**: 예화가 필요한 파트마다 **①인문학 스토리를 먼저 탐색**하고, 적합한 것이 없거나 즉각 공감이 더 중요할 때만 2·3으로 내려간다.

**인문학 예화 가드**(최우선이라도 반드시 준수):
- **출처 확인**: 실존 작품·사건·인물이어야 하며 날조·왜곡 금지(아래 "확인 불가" 경계 준수). 줄거리·사실을 압축·각색해도 원전의 핵심을 왜곡하지 않는다.
- **온세대 풀어쓰기**: 고전·문학이라도 어린이~어르신이 이해하도록 배경을 한두 문장으로 풀어 설명한다. 전공자·특정 세대만 아는 난해한 레퍼런스는 지양하거나 쉽게 번역한다.
- **본문 우선**: 인문학 이야기가 본문·복음을 앞서거나 대체하지 않는다(예화=다리).
- **신학 정박**: 성공 신화·인간 중심 교훈으로 흐르지 않게 CMT·FCF에 정박한다(아래 "성공 신화" 경계 준수).

## 위치별 깊이 조절

| 위치 | 깊이 | 설명 |
|---|---|---|
| **서론** | 짧고 직관적 | 인문학적 예화(문학, 영화, 일상 스토리 등)로 청중의 세계에서 본문으로 진입. 온세대가 공감할 수 있는 보편적 이야기. **서론 예화는 필수** |
| **본론 (M1-M4)** | 구조적 | 메시지 해석을 돕는 예화. 추상적 개념을 구체화하거나 청중 공감을 끌어올릴 때 삽입. **선택적 — 필요할 때만** |
| **결론/M5** | 이미지 중심 | 기억에 남는 짧은 이미지. 논리 통합 단계이므로 예화 추가 시 산만해질 수 있어 **대부분 불필요** |

## 출력 구조

예화 삽입 시 이야기만 던지지 않는다. 다음 3요소를 포함한다:

1. **예화 제목** (한 줄)
2. **이야기 본문** (일상 언어, 전문용어 최소화)
3. **설교 연결 포인트** — "이 예화가 왜 이 본문/이 무브먼트에 필요한지" 명시

선택적으로 **청중 변형 제안**(청소년/청년/장년별 조정 포인트)을 추가할 수 있다.

## 신학적·내용적 경계

| 구분 | 내용 |
|---|---|
| **신학 기준** | 개혁주의·복음주의 신학과 명백히 충돌하는 내용 배제. 은혜·회개·소명·공동체 개념을 왜곡하지 않는다 |
| **제외: 성공 신화** | 인간 중심 성공 이야기, "열심히 하면 복 받는다"식 예화 배제 |
| **제외: 확인 불가** | 출처 불명의 인용구, 날조된 일화, 과장된 간증, 검증 불가능한 통계 배제 |
| **제외: 감정 조작** | 불필요하게 감정만 자극하고 본문을 소외시키는 예화 배제 |
| **제외: 사회 이슈** | 선정적·분열적 사회 이슈 배제 |
| **온세대 고려** | 어린이~어르신 모두가 공감할 수 있는 스토리를 우선한다. 특정 세대만 아는 레퍼런스는 피한다 |

## Self-Check (출력 전 점검)

모든 예화에 대해 출력 전 4가지를 확인한다:

```
□ 소스 우선순위 — 인문학 스토리를 먼저 검토했는가? (인문학 → 일상경험 → (최소)시사) ★필수
□ 이 예화는 본문보다 앞서지 않는가?
□ 교리적으로 오해될 여지는 없는가?
□ 청중이 현실에서 공감 가능한가? (인문학이면 온세대 풀어쓰기 되었는가)
□ 인문학 예화의 출처(작품·사건·인물)가 실존·확인 가능한가? 날조·왜곡 아닌가?
□ 불필요하게 감정만 자극하지 않는가?
□ (나선 구조 한정) 누적 대지(클라이맥스 이전)의 예화가 복음 해소(은혜로의 반전·구원의 위로)를 미리 누설하지 않는가?
```

위 항목 중 하나라도 통과하지 못하면 해당 예화를 수정하거나 제거한다. **소스 우선순위(인문학 최우선)와 출처 확인은 필수 통과**다.
