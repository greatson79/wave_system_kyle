# Mode A — 비서사 텍스트 설교 구조

서신서, 잠언, 교훈 시편, 예언서 등 비서사 텍스트에 적용한다.

> **전개 방식 — 선형 / 나선(누적지연형)**
> Mode A는 두 전개 방식을 가진다. **선형·나선은 설교 흐름의 논리적 전개 방식이며, 본문 구조와 무관하게 설교자가 선택한다.**
> **2-4단계에서 선형 아웃라인과 나선 아웃라인을 모두 작성하여 목사에게 제시한다.** 목사 판단으로 최종 방식을 확정한다.

---

## 13단계 흐름

> 1~4단계는 5단계 프로세스의 2단계(본문 분석)에서 수행된다.

1. 본문 선택 및 범위 확정
2. 원어 분석 — 파싱, 구조, 번역 비교 ← [2-1]
3. 역사·사회·문화 배경 분석 ← [2-2]
4. 문화 내러티브 · 우상 분석 ← [2-3]
5. CMT (Central Message of the Text) 도출 ← [2-4]
6. 도덕적 명제 — 본문의 도덕적 요구 → 인간의 시도 (요구·시도 두 박자)
7. 인간의 노력과 실패
8. 무능력 (Inability)
9. FCF — 타락한 조건 직면 ← [2-4]
10. 그리스도 연결
11. 복음 선포
12. HP — 해석학적 적용 (복음 동기) ← [2-4]
13. 삶의 열매 · 공동체 회복

---

## 설교 아웃라인 (5부 구조 — 선형)

```
서론 — 본문으로의 진입
1부 — Text: 본문이 말하는 것
2부 — Principle: 원칙과 명제
3부 — Inability: 인간의 무능력과 FCF
4부 — Christ: 그리스도 안에서의 해답
5부 — HP (Homiletical Point): 복음 동기 적용
결론 — 초청, 강압 없는 마무리
```

|---|---|

## 나선 전개 (누적지연형 / Cumulative-Delayed Spiral)

> Mode A 선형의 변형. 여러 대지에서 FCF를 각기 다른 각도로 **누적**하고, 그리스도·복음은 의도적으로 **지연**했다가 클라이맥스에서 단 1회 **폭발**시켜 누적된 모든 FCF를 동시에 해소한다.
> 5대 핵심 원리(본문중심·FCF중심·그리스도중심·세계관전환·복음동기)는 선형과 동일하다 — `sermon_SKILL.md`의 "설교 철학" 참조. 특히 **FCF(원리 2)**와 **복음 동기(원리 5)**가 강화된다.

### 두 방식의 특성

| 항목 | 선형 | 나선 |
|------|------|------|
| 흐름 | FCF → 복음 → HP를 한 줄기로 1회 통과 | FCF를 여러 각도로 누적 → 복음 지연 → 클라이맥스 1회 폭발 |
| 긴장 구조 | 비교적 이른 시점에 복음 제시 | 복음을 끝까지 미루어 긴장·기대 극대화 |
| 적합 상황 | 복음을 일찍 근거로 깔고 실천으로 전진하는 본문 흐름 | 회중이 자신의 무능을 충분히 인식한 후 복음이 터져야 효과적인 주제 |
| CMT 형식 | 단일 CMT | 우산 CMT (모든 FCF 누적을 한 문장으로 종속) |

> **초안 시점 = 2-4단계(종합 통찰).** 두 아웃라인을 모두 작성하여 목사에게 제시한다. **공식 확정 시점 = 4-2단계(전개방식 확정)** — 2-4 마커를 그대로 승격해 게이트로 만들며 새 판단을 하지 않는다. 이후 4-3(예화설계) → 4-4(아웃라인 작성)로 진행한다.

### 작동 메커니즘

```
대지1 ─ FCF(각도 A) ┐
대지2 ─ FCF(각도 B) ├─ 복음 "보류"(긴장 증대) ─→ 클라이맥스: 그리스도·복음 1회 폭발
대지3 ─ FCF(각도 C) ┘                              (누적 FCF 전부 동시 해소)
```

- **각도 변주**: 같은 죄/주제를 대지마다 다른 면으로 비춘다 (반복 아닌 점층).
- **복음 지연**: 누적 대지에서는 복음을 터뜨리지 않고 "아직 답이 없다"는 긴장을 유지한다.
- **단일 폭발**: 그리스도·복음은 클라이맥스에서 단 1회 full로 폭발하며 앞의 모든 FCF를 동시 해소한다.
- **점층**: 뒤 대지의 FCF가 앞보다 더 깊고 절망적이어야 한다.

### 13단계의 나선 재배치 (기존 번호 유지)

나선은 새 번호가 아니라 **위 13단계의 배치 변형**이다:

| 구간 | 단계 | 동작 |
|------|------|------|
| 준비 | 1~5 | 본문·원어·배경·우상 → **우산 CMT 확정(5단계, 2-4)** |
| 누적 (대지 N회) | 6→7→8→9 ×N | 각 대지마다 요구·시도 → 노력·실패 → 무능 → 미니 FCF. **10·11(복음) 보류** |
| 폭발 (클라이맥스) | 10→11 | 누적 FCF 전체 환기 → 그리스도 연결 → 복음 선포 (1회) |
| 적용 | 12 | 각 대지 FCF에 각각 대응하는 복음 동기 적용 |
| 결론 | 13 | 삶의 열매 + 공동체·세상 회복 |

> 선형은 6~11을 한 줄기로 1회 통과한다. 나선은 6~9를 대지 수만큼 반복하되 10·11은 끝까지 미뤘다 1회 폭발시킨다.
> **5부 아웃라인 대체**: 나선 선택 시 위 "5부 구조"와 13단계 step 11(단일 중간 복음 선포)을 사용하지 않고, 아래 나선 아웃라인을 사용한다. (한 설교 안에 두 복음 타이밍이 공존하지 않는다.)

### 나선 설교 아웃라인 (5부 대체)

```
서론       — 우산 CMT를 암시(직접 진술 X), 청중을 본문의 긴장으로 끌어들임
대지 1~N   — [본문 관찰 → 도덕적 요구 → 시도·무능 → 미니 FCF(각도 변주) → 복음 보류 신호]
클라이맥스 — 누적 FCF 환기 → 그리스도 인격·사역(본문에서 직접 도출) → 복음 full 선포(동시 해소)
적용       — 마음 변화(정체성·동기) → 각 대지 FCF에 각각 대응하는 삶의 열매
결론       — 공동체·세상 회복 + 복음 선언(종교 언어) + 실존적 적용(비종교 언어)
```

### 우산 CMT 강제 규칙

다대지는 흩어지기 쉽다. 5단계(2-4)에서 **우산 명제(Umbrella CMT)**를 한 문장으로 확정하고 모든 대지를 그 하위에 종속시킨다.

- 형식: `[본문의 핵심 진리]는 [인간의 누적된 무능]을 [그리스도]를 통해 [복음의 해방]으로 바꾼다.`
- **복음 완결성**: 우산 CMT는 정의상 그리스도·복음을 포함한다. 다운스트림(소그룹·카드뉴스·캡션)의 핵심 메시지는 반드시 **이 우산 CMT에서 추출**한다 (개별 누적 대지 금지 — 복음 누수 방지).
- 검증: 각 대지가 이 한 문장의 하위 논거로 환원되지 않으면 대지에서 제외한다.

### 안전장치 체크리스트 (발행 전 필수)

- [ ] **각도 변주**: 대지마다 FCF가 다른 면인가? (단순 반복이면 실패)
- [ ] **점층**: 뒤 대지의 FCF가 앞보다 더 깊은가?
- [ ] **지연 유지**: 누적 단계에서 복음을 미리 터뜨리지 않았는가?
- [ ] **단일 폭발**: 그리스도 full 선포가 클라이맥스 1회로 집중되었는가?
- [ ] **동시 해소**: 클라이맥스 복음이 앞의 모든 FCF를 건드리는가? (하나라도 미해소 시 구조 실패)
- [ ] **본문 정합성**: 폭발 지점 그리스도가 외부 삽입이 아니라 본문에서 직접 도출되었는가?
- [ ] **우산 CMT 종속**: 모든 대지가 단일 우산 CMT 하위에 종속되는가?
- [ ] **피로 관리**: 대지가 4개를 넘어 긴장이 늘어지지 않는가? (권장 2~3개)

### 실증 예시

**① 켈러 「가인의 도시」(창 4장) — 구약 내러티브**
- 우산 CMT: "죄는 개인과 도시를 죽음의 문화로 타락시키지만, 하나님은 은혜의 도시를 세우신다"
- 대지1 FCF: 회개 불능 — 가인은 죄가 아닌 죄의 결과만 슬퍼함 (각도 A: 개인)
- 대지2 FCF: 죽음의 문화 — 라멕의 폭력·자기 이름 높임 (각도 B: 사회)
- 폭발: 라멕 77배 복수 ↔ 예수 일흔번씩 일곱번 용서 / 가인의 형벌(14절)이 예수께 떨어짐 → **저주는 그리스도께, 축복은 우리에게** (대속·갈 3:13·고후 5:21)
- 적용: "내 이름을 높일 필요 없음" → 일·돈·성·권력 사용이 달라짐
> 대속(Great Exchange) 신학으로 건전. 단, 창 4장의 직접 주해가 아니라 **예표론적 궤적** 적용임에 유의.

**② 엡 4:11-16 「머리이신 그리스도께로 자라는 몸」 — 서신서**
- 우산 CMT: "교회는 스스로 성숙할 수 없으나, 머리이신 그리스도께 연결될 때 사랑 안에서 그분의 장성한 분량까지 자란다"
- 대지1 FCF: 직분의 권력화 (각도 A) / 대지2 FCF: 미성숙과 요동(14절, 각도 B) / 대지3 FCF: 머리에서 끊긴 단절된 지체 (각도 C)
- 폭발: "그는 머리니 곧 그리스도라"(15절) — 은사를 주신 분·자라갈 목표(13절)·자라게 하는 근원(16절). 세 FCF 동시 해소.
> **성화론 균형절(필수)**: "성숙은 머리이신 그리스도로부터 흘러나오는 **선물**이되, 그 선물은 몸의 각 지체가 사랑 안에서 **능동적으로 역사하는 수단**을 통해 자란다(16절) — 수동적 수령이 아니라 은혜로 힘입은 참여다(빌 2:12-13)." 선물을 수동성으로 평탄화하지 않는다.
> 서신서이므로 원칙상 선형이 기본값이나, 복음이 15-16절에 배치되어 나선이 본문 흐름과 합치한다.

### 그리스도 연결 방식

클라이맥스 폭발의 그리스도 연결은 본 파일 상단 "그리스도 연결 방법" 표(장르별)를 그대로 적용한다 — 별도 규칙을 두지 않는다.
