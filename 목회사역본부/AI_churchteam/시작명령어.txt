═══════════════════════════════════════════════
【 2. 커맨드 목록 】
═══════════════════════════════════════════════

/팀
  → 모든 작업의 메인 진입점
  → 원하는 것을 자유롭게 요청
  → 예: /팀 이번 주 설교 준비해줘

/팀-전략분석
  → 시대통찰 보고서 발행
  → 권장: 매달 초 1회
  → 환경스캐닝 + 목회철학 기반 분석

/팀-연간계획
  → 연간목회계획 2단계 작성
  → 권장: 연초 1회
  → 1층: 연간방향 (전략팀+목사님)
  → 2층: 연간기획 (기획팀 구체화)

/팀-월간
  → 월간 사역 준비
  → 권장: 매달 초
  → 교육팀 월간자료 + 운영팀 월간보고

/팀-분기
  → 분기 점검·평가
  → 권장: 3월·6월·9월·12월 말
  → 전체 사역 돌아보기 + 다음 분기 준비

/팀-건강
  → 시스템 상태 확인
  → 수시 사용

/팀-결정
  → 미결 사항 목사님께 정리 보고
  → 수시 사용

/팀-진입허가
  → 최초 1회만 실행
  → 시스템 진입 게이트 서명

【 3. 처음 시작 순서 】
═══════════════════════════════════════════════

1단계: pastor/philosophy/ 폴더에 목회철학 문서 업로드
2단계: /팀-전략분석  (시대통찰 보고서 발행)
3단계: /팀-연간계획  (연간목회계획 작성)
4단계: /팀           (주간 사역 시작)
