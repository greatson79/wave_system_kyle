# /팀-분기 — 분기 사역 점검

분기마다 (3월·6월·9월·12월 말) 실행합니다.
전체 사역을 돌아보고 다음 분기를 준비합니다.

## 실행 팀

**미래목회전략팀**
- 이번 분기 시대 변화와 목회 방향 재점검
- 다음 분기 전략 조정 의견 제시

**사역기획팀**
- 이번 분기 기획 실적 vs 계획 비교
- 다음 분기 기획 초안

**교육팀**
- 분기 교육 커리큘럼 점검
- 영적 성장 분기 보고

**운영팀**
- 분기 결산 보고
- 다음 분기 행사 기획

## 실행 순서

```
1. 전략팀 분기 점검 (시대통찰 최신화 포함)
2. 기획팀 분기 실적 보고
3. 교육팀·운영팀 병렬 분기 점검
4. 총괄팀장이 종합 분기 보고서 작성
5. 담임목사님께 보고 + 다음 분기 방향 확인
```

## 산출물

```
reports/strategy/YYYY-QN-분기통찰.md       ← 전략팀 (QN = Q1~Q4)
output/YYYY-QN/전체/분기종합보고서.md
output/YYYY-QN/교육팀/분기성장점검.md
output/YYYY-QN/운영팀/분기결산.md
```
