# /팀-전략분석 — 시대통찰 보고서 발행

미래목회전략팀이 환경스캐닝 데이터와 목회철학을 바탕으로 시대통찰 보고서를 작성합니다.
**요청 시 언제든 발행 가능합니다. 권장 주기는 월 1회입니다.**

## 실행 순서

1. **Culture & Generation Analyst**
   → 환경스캐닝 output 읽기 + 시대·문화·사회 신호 추출

2. **AI & Ministry Innovation**
   → 기술·혁신 접목 포인트 도출

3. **Scenario Planner**
   → 3가지 미래 시나리오 구성

4. **Theology Alignment**
   → 분석 결과 신학 정합성 검증

5. **Kingdom Vision**
   → 연간방향(`pastor/annual-plans/YYYY-연간방향.md`)과 정렬 확인

6. **Strategy Synthesizer (팀장)**
   → Adversarial Review + 최종 시대통찰 보고서 통합

## 사전 확인

실행 전 아래 항목을 자동 확인합니다:
- `pastor/philosophy/` 파일 존재 여부
- `pastor/annual-plans/YYYY-연간방향.md` 존재 여부
- 환경스캐닝 output 최신 파일 날짜
- 이번 달 보고서 기존 발행 여부 (재발행 시 갱신)

## 산출물

```
reports/strategy/YYYY-MM-시대통찰보고서.md
예: reports/strategy/2026-05-시대통찰보고서.md
```

- 같은 달 재실행 시 기존 파일을 갱신합니다
- 사역기획팀이 이 파일을 자동으로 읽어 기획에 반영합니다
