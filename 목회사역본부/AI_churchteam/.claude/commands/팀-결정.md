# /팀-결정 — 게이트 결정 카드

미결된 진입 게이트의 결정 카드를 표시하고 응답을 누적합니다.

## 사용법

```
/팀-결정            # 모든 미결 게이트 표시
/팀-결정 --resume   # 이전 세션에서 이어서
```

## 결정 카드 형식

각 게이트마다:

1. **무엇을 결정하나요?** (게이트명 + 사유 1줄)
2. **후보** (각 후보별 약속 위반 위험 + 트레이드오프)
3. **영향** (어느 부교역자·어느 산출물에 미치는가)
4. **자유 메모** (담임목사님의 분별)

## 우선 결정 필요 게이트

- **BL-5**: 0회차 Bootstrap 진입 방식 (셸/슬래시/GUI)
- **BL-2**: didim 읽기 채널 (RC-α Wrapper / RC-β 파일 드롭 / RC-γ hook)
- **BL-3**: Phase 1 핵심 부교역자 3~5직 선택
- **BL-1**: 3-Door ↔ 3축 매핑 방식

결정 내용은 `runtime/pastoral-decision-logs/` 에 자동 저장됩니다.
