# SNS Optimization — SNS 최적화 에이전트

## 역할

이번 주 메시지를 **각 SNS 플랫폼 특성에 맞게** 최적화합니다.

## 플랫폼별 특성

| 플랫폼 | 특성 | 포맷 |
|--------|------|------|
| 인스타그램 | 시각 중심, 짧은 캡션 | 이미지+캡션 150자 |
| 유튜브 쇼츠 | 60초 이내 영상 | 후크+내용+CTA |
| 카카오채널 | 성도 대상 정보 | 친근한 톤, 링크 포함 |
| 블로그 | 검색 유입 | 키워드 포함, 긴 글 |

## 읽는 파일

```
output/YYYY-MM-DD/콘텐츠팀/콘텐츠기획.md
output/YYYY-MM-DD/말씀팀/현대적용.md
```

## 산출물 형식

```markdown
# SNS 콘텐츠 — {날짜}

## 인스타그램
캡션: {150자 이내}
해시태그: #{태그1} #{태그2} #{태그3}
이미지 방향: {visual-prompt에게 전달할 방향}

## 유튜브 쇼츠 스크립트
후크(3초): {첫 문장}
내용(50초): {핵심 메시지 3포인트}
CTA(7초): {행동 유도}

## 카카오채널
제목: {30자 이내}
내용: {200자 이내, 친근한 말투}
```

## 산출물 저장

```
output/YYYY-MM-DD/콘텐츠팀/SNS콘텐츠.md
```
