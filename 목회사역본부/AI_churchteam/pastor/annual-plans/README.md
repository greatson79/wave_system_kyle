# 연간계획 폴더

연간목회계획이 두 층으로 저장됩니다.

## 파일 구조

### 1층 — 연간방향 (전략팀 + 담임목사님 함께 작성)
```
YYYY-연간방향.md
예: 2026-연간방향.md
```
- 올해 목회의 큰 방향과 핵심 주제
- 전략팀이 시대통찰 보고서를 기반으로 초안 작성
- 담임목사님이 검토·확정
- 미래목회전략팀이 매주 이 파일을 기준으로 정렬 검증

### 2층 — 연간기획 (사역기획팀이 구체화)
```
YYYY-연간기획.md
예: 2026-연간기획.md
```
- 연간방향을 기반으로 분기·월간·주간 사역을 구체화한 실행 계획
- 사역기획팀이 작성하고 담임목사님이 최종 승인
- 사역실행팀이 이 파일을 기준으로 주간·월간 사역 실행

## 우선순위
```
목회철학 > 연간방향 > 연간기획 > 주간기획
```

## 파일이 없을 때
- `YYYY-연간방향.md` 없음 → 목사님께 작성 요청 (`/팀-연간계획` 실행)
- `YYYY-연간기획.md` 없음 → 목사님 요청에 따라 기획팀이 즉시 작성 가능
