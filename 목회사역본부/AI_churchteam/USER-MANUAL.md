---

## 시작하기 전에

```bash
cd ~/Desktop/Ai_works/Vibe-Practice/AI_churchteam/Claude_skills/AI_churchteam
claude
```

### 2단계: 목회철학 문서 업로드 (최초 1회)

`pastor/philosophy/` 폴더에 목회철학 문서를 넣어주세요.
파일 형식: `.md` `.pdf` `.docx` `.txt` 모두 가능

```
pastor/
├── philosophy/         ← 목회철학 여기
│   └── 목회철학.md
├── annual-plans/       ← 연간계획 (AI와 함께 작성)
└── reference/          ← 참고자료 여기
```

## 커맨드 사용법

### `/팀` — 메인 진입점

모든 작업의 시작점입니다. 무엇이든 요청할 수 있습니다.

```
/팀
/팀 이번 주 설교 준비해줘
/팀 청소년 교육 자료 만들어줘
/팀 이번 주 SNS 콘텐츠 준비해줘
```

실행하면 Lead Orchestrator가 요청을 분석하고
필요한 팀들을 자동으로 소환합니다.

---

### `/팀-전략분석` — 시대통찰 보고서

환경스캐닝 데이터를 분석해 목회전략 인사이트를 제공합니다.
**권장: 매달 초 1회 실행**

```
/팀-전략분석
```

결과물: `reports/strategy/2026-05-시대통찰보고서.md`

> 같은 달에 다시 실행하면 기존 보고서가 갱신됩니다.
> 언제든 필요할 때 실행할 수 있습니다.

---

### `/팀-연간계획` — 연간목회계획 작성

AI 팀과 함께 연간목회계획을 2단계로 작성합니다.
**권장: 연초 1회**

```
/팀-연간계획
```

**작성 순서:**
1. `/팀-전략분석` 먼저 실행 (시대통찰 보고서 준비)
2. `/팀-연간계획` 실행
3. 전략팀이 연간방향 초안 작성 → 목사님 검토·확정
4. 기획팀이 연간기획 구체화 → 목사님 최종 승인

결과물:
```
pastor/annual-plans/2026-연간방향.md   ← 큰 방향
pastor/annual-plans/2026-연간기획.md   ← 구체적 계획
```

---

### `/팀-월간` — 월간 사역 실행

**권장: 매달 초 실행**

```
/팀-월간
```

교육팀·운영팀이 월간 자료를 준비합니다.
- 이번 달 교육 커리큘럼
- 월간 보고서
- 다음 달 준비

---

### `/팀-분기` — 분기 점검

**권장: 3월·6월·9월·12월 말 실행**

```
/팀-분기
```

전체 사역을 돌아보고 다음 분기를 준비합니다.
- 전략팀 분기 점검
- 교육팀 커리큘럼 점검
- 운영팀 분기 결산
- 목사님 방향 확인

---

### `/팀-건강` — 시스템 상태 확인

```
/팀-건강
```

시스템 6개 신호를 점검합니다.
- DNA 상속 / SOT 무결성 / 신학 필터
- 외부 인증 / 자기 진화 이력 / 시스템 도달성

---

### `/팀-결정` — 미결 사항 결정

AI 팀이 판단하기 어려운 사항을 목사님께 정리해서 보여줍니다.

```
/팀-결정
```

최초 1회, 9개 진입 게이트를 확인하고 서명합니다.


## 주간 루틴 예시

### 월요일 (주간 시작)
```
/팀 이번 주 사역 준비해줘
```
→ Lead Orchestrator가 전략팀·기획팀·실행팀 순서로 자동 실행

### 원하는 것만 할 때
```
/팀 설교 구조만 잡아줘
/팀 이번 주 SNS 카드뉴스만 만들어줘
/팀 소그룹 나눔지 작성해줘
```

---

## 월간 루틴 예시

```
1일:  /팀-전략분석  (시대통찰 보고서 갱신)
2일:  /팀-월간      (월간 교육·운영 준비)
매주: /팀           (주간 사역 실행)
말일: 다음 달 준비 확인
```

---

## 연간 루틴 예시

```
1월초: /팀-전략분석 → /팀-연간계획
3월말: /팀-분기 (1분기 점검)
6월말: /팀-분기 (2분기 점검)
9월말: /팀-분기 (3분기 점검)
12월말: /팀-분기 (연간 결산)
```
