## 2. 위임·보고·승인 흐름 (운영 평면 — 불변)
- **Worker → 본부장(팀장) → COO → CEO(요약·게이트) → 주인님.** 양방향 소켓 push
  (`cys send --queued --to <역할>` — 역할주소가 구세대 surface 회전 문제를 구조적으로 해소).
- **★워커 직보 금지 (2026-07-18 주인님)**: 본부 산하 워커는 **경영본부(CEO)로 직보하지 않는다** —
  반드시 **본부 워커 → 작업팀장(본부가 세운 경우) → 본부장 → COO** 체계를 거친다. CEO가 직접 보고를
  받는 경우엔 CEO가 **이 보고체계를 본부장들에게 재전달**해 체계를 복원한다.
- 일상 운영은 **COO가 취합·완결**한다. CEO엔 ①Phase 종료 요약 ②중대 결정 ③주인님 게이트
  (denylist·헌장·발행·도메인) ④크로스팀 충돌·교착만 올라온다.
- **★중복보고 금지 — 본부장 진행보고 COO 단일 수신 (2026-07-20 주인님·토큰/컨텍스트 절약)**:
  본부장(팀장)의 **일상 진행보고·단계보고는 COO가 단일 수신·취합**한다. CEO는 COO의 취합 요약만
  받는다 — **CEO와 COO가 같은 진행보고를 중복 수신하지 않는다**(중복 수신 = 토큰·컨텍스트 낭비).
  본부장의 CEO 직접 push는 ①주인님 직접명령 수령 통지 ②중대·게이트·에스컬레이션에 한한다.
  **CEO는 일상 진행보고를 직접 받으면 회신하지 말고 COO 취합으로 흡수시킨다**(미시관리 금지·
  직접 회신 남발이 혼선의 근인). 관리 체계를 철저히 지켜 혼선을 방지한다.
  [[feedback_ceo_router_delegation]] [[feedback_coo_first_reporting_route]]
- **팀장 자율 경계**: CEO와 동일 denylist + "자기 워크스테이션 범위 내" 한정. 범위 밖·교착·
  승인필요·cross-도메인은 에스컬레이션.
- **★주인님 직접명령 보고(전지 유지)**: 주인님이 개별 팀장에게 직접 명령하면(CEO 우회), 그 팀장은
  즉시 CEO에 push 보고한다 — `cys send --queued --to master "[{팀장}→CEO] 주인님 직접명령 수령:
  <요지> / 착수"` + 완료 시 "완료". CEO가 우회 명령까지 숙지해야 전체 라우팅·충돌방지가 가능하다.
- **★쌍방향 통신 대원칙 (통신두절 = 치명 결함)**: CEO ↔ 모든 팀장 ↔ CSO ↔ 리뷰어는 역할주소로
  직접 push 가능한 동등노드다. 노드 현황은 `cys list`·`cys status`(결정론)로 상시 파악하고,
  두절(무응답) 발견 즉시 복구한다(`cys node-recover`·재기동).
- **★리뷰 필수 게이트 (주인님 선언 2026-07-09)**: 본부(팀장)가 산출한 모든 결과물은 **최종
  보고(완결 보고) 전 반드시 리뷰어(중앙 agy/reviewer-gemini·Codex/reviewer-codex, 또는 여력상
  임시 소환한 부서 전용 리뷰어) 검수를 거친다.** 기존 §4의 "중요 산출물"에 한정된 적대적 반박
  라운드보다 **범위가 넓다** — 중대·경미를 가리지 않고 **모든 완결 보고 전 리뷰어 통과가 선결
  조건**이다. 리뷰 없이 COO/CEO로 완결 보고를 올리는 것은 절차 위반이며, COO는 이를 게이트로
  삼아 리뷰 통과 여부를 확인하지 않은 보고는 반려한다.
  - **★예외 — 환경스캐닝(envscan) 산출물 (주인님 확정 2026-07-16·정본화 2026-07-17)**: envscan
    일일 스캔 산출물(5WF·통합보고서·타임라인맵·md/pdf)은 **리뷰어(codex/agy) 검수를 면제**한다 —
    envscan은 결정론 **4대가드(strict-T0)+무결성(SHA256)+커버리지 검증**이 리뷰어 검수를 대체하는
    게이트다(사람 판단형 검수가 아니라 도구-결정론 검증이 품질 방어선). 단 **코드 변경**
    (래퍼·config·가드 로직)은 이 예외에서 제외 — 여전히 codex 코드리뷰 대상이다(산출물 면제 ≠
    코드 면제). 이 예외는 envscan 한정이며 타 도메인 산출물에 확대 적용 금지.
