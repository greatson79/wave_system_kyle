# 산출물 저장구조 규약 (전 본부 공통)

> 제정: 주인님 직접지시 2026-07-28 · 관리: CEO(총괄) · 적용: `output/WaveAI/` 전체
> 배치: `.claude/org/` (git 추적 조직 확장층 — 팩 업데이트로 소실되지 않는다)

## 1. 왜

지금까지는 본부 폴더 아래에 `프로젝트명_날짜/`와 낱개 md 파일이 뒤섞여 쌓였다. 종류가 다른
산출물이 한 층에 평평하게 놓이니 **무엇이 어느 갈래의 몇 번째 결과물인지** 폴더만 봐서는
알 수 없다. 카테고리로 묶고 날짜로 정렬한다.

## 2. 표준 경로

```
output/WaveAI/{본부}/{카테고리}/{MMDD}_{제목}/{산출물}
```

**예시**

```
output/WaveAI/크리에이티브본부/
├── AI트렌드실전팁/
│   ├── 0728_에이전트에게_일을_맡기는_법/
│   │   ├── 기획안.md
│   │   ├── 원고_v2.md
│   │   ├── verdict_agy.md
│   │   ├── verdict_codex.md
│   │   └── assets/          ← 이미지·첨부가 3개 이상일 때만 만든다
│   └── 0805_.../
├── 카드뉴스/
│   └── 0727_수강후기_7장/
└── 교육아티클/
    └── 0727_codex_sites_완전정복/
```

### 각 층의 규칙

| 층 | 규칙 |
|---|---|
| **{본부}** | 기존 8본부 이름 그대로 |
| **{카테고리}** | 산출물의 **갈래**. 요일 발행물은 코너명을 그대로 쓴다(AI트렌드실전팁·AI트렌드기술동향·주간시대통찰·미니스트리아티클·카드뉴스·교육아티클). 그 외는 업무 갈래(환경스캐닝·설교·수련회·SNS운영·검색엔진·홈페이지) |
| **{MMDD}** | 4자리 숫자. **연도는 붙이지 않는다**(폴더가 이미 그 해 안에 있고, 짧아야 눈에 들어온다). 해가 바뀌면 카테고리 아래 `2027/`을 한 겹 넣는다 |
| **{제목}** | 그 산출물을 **한눈에 식별하는 말**. 공백은 `_`. 길면 핵심어만 |
| **{산출물}** | 파일을 바로 놓는다. 단계 폴더(01_기획/02_원고)는 **만들지 않는다** — 한 건의 산출물 수가 대개 10개 미만이라 층만 늘어난다 |

### 예외 — 그대로 두는 폴더

- `_round/` — 본부 작업기억·핸드오프·상태파일. 날짜별로 안 나눈다.
- `_archive/` — 종료된 것.
- `deliverables/` · `projects/` — 기존 용도 유지.

## 3. 지켜야 할 것

1. **한 건 = 한 폴더.** 같은 산출물의 기획·원고·검수·에셋은 흩지 않는다. verdict를 상위나
   다른 폴더에 두면 나중에 짝을 못 찾는다(실제로 오늘 A아티클 verdict가 두 곳에 흩어져 있었다).
2. **낱개 md를 본부 루트에 두지 않는다.** 한 장짜리라도 카테고리/날짜 폴더 안에 넣는다.
3. **폴더명에 날짜를 두 번 쓰지 않는다.** `0728_제목/` 안의 파일명에 다시 `_2026-07-28`을
   붙이지 않는다.
4. **경로를 옮길 때는 참조를 함께 고친다.** verdict·핸드오프·상태파일이 **절대경로로 서로를
   인용**한다. 폴더만 옮기면 그 인용이 전부 죽는다 — 이동과 치환은 한 묶음으로 한다.

## 4. 신규 폴더 만들 때

```bash
bash .claude/bin/newout.sh <본부> <카테고리> <제목>
# 예: bash .claude/bin/newout.sh 크리에이티브본부 AI트렌드실전팁 에이전트에게_일을_맡기는_법
# → output/WaveAI/크리에이티브본부/AI트렌드실전팁/0728_에이전트에게_일을_맡기는_법/ 생성 후 경로 출력
```

날짜는 스크립트가 실행 시각으로 자동으로 넣는다(수기 입력 금지 — 날짜 오기재 방지).

## 4-b. ★본부 소환해제 전에 일일보고를 남긴다 (2026-07-28 신설)

**해제 순서**: 본부장 완료보고 → ★**일일보고·핸드오프 저장** → CEO가 CSO에 ws 전달 →
CSO idle 실측 → 해제.

**왜**: 2026-07-28 Edu본부가 과업 종료 즉시 해제됐는데, 그 결과 **일일보고를 남길 주체가 함께
사라졌다.** 그날 저녁 전 본부 보고를 취합할 때 Edu만 기록이 없어 CEO가 대행 작성해야 했다
(`output/WaveAI/Edu본부/일일보고/0728_CEO대행_작성/`). 토큰 위생을 위한 즉시 해제는 옳지만,
**해제는 기록을 남긴 뒤에 한다.**

일일보고 형식은 4항목이면 충분하다 — ①오늘 완결(산출물·검수통과·절대경로) ②진행 중과 현재 단계
③다음 재개 시 첫 작업 ④**주인님 결정 필요 항목**. 경로는 `{본부}/일일보고/{MMDD}_{제목}/`.

## 5. 기존 자산 이관

**신규 산출물부터 즉시 적용**한다. 기존 폴더는 §3-4의 참조 문제 때문에 **한꺼번에 옮기지
않는다.** 본부별로 ①이동 ②문서 내 절대경로 일괄 치환 ③치환 후 링크 실재 검증을 한 묶음으로
처리하고, 본부별 완료를 COO가 확인한다. 진행 중인 트랙의 폴더는 그 트랙이 끝난 뒤 옮긴다.
