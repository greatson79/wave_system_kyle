# 이사회 헌장

> Wave AI Networks · 경영 · 역할(Role-only)

**역할**: 이사회 = 오너 = 주인님

- **정체**: 사용자(주인님) 인간 오너 역할. 노드·메모리 없음(surface ID 없음, cmux pane 아님).
- **권한**: 최종 승인, kill-switch, 외부 발행, 비가역 결정.
- **지침**: `.claude/MASTER_DIRECTIVE.md` denylist 참조.

## 조직상 책무

1. **최종 의사결정** — CEO·CSO 보고 수신 후 비가역·외부발행 결정.
2. **Kill-Switch** — 사용자(주인님)의 임의 입력 = 자율주행 즉시 일시정지.
3. **승인 게이트** — 로드맵 외·비가역 아이템은 사용자 명시 승인 필수.

## 통신

- 모든 보고는 CEO(Master) → 주인님 단방향.
- 주인님 직접 명령 → 즉시 CEO에 보고(우회 명령도 CEO 전지 유지).
