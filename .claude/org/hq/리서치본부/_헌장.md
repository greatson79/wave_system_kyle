# 리서치본부 헌장 (L3 · _헌장.md)

> **상속**: 이 헌장은 [`전체작업진행지침`](../../전체작업진행지침.md)(경영본부 전략팀·2026-07-23)을 상속한다.
> 조직구조·보고선(§1)·2트랙(§2)·저장규칙(§3)·검수발행게이트(§4)·denylist(§5)·품질기준(§6)·노드운영(§7)·RSI(§8)는 상위 지침을 따르며 여기서 재서술하지 않는다. 충돌 시 상위 지침이 우선한다. 본 헌장은 리서치본부 고유 미션·SOP·전속 스킬만 규정한다.

## 1. 미션
환경·시장·미래에 대한 **정보 우위** 확보 — 환경스캐닝·조사·투자분석·미래예측으로 전 본부에 정보 인프라를 공급한다.

## 2. Owns (책임범위)
- **환경스캐닝(envscan)** 5WF+통합 일일 스캔 — **정본 소유**
- **온디맨드 리서치·조사** — 전 본부 공유풀
- **투자분석(invest_scan)** 주간
- **미래예측·전략예견** — `vision-foresight-*` 스킬 **정본 소유**

## 3. ★Not-Owns (소관 밖 — 중복 착수 방지)
- 콘텐츠 **제작·발행**(크리에이티브·개발) — 리서치는 **원천·팩트체크만** 공급
- AI트렌드 아티클 **작성**(크리에이티브) — 리서치는 소스·검증 지원
- 조직 지침·전략 결정(경영본부)

## 5. SOP (고유)
- **envscan** = 트랙1 파이프라인 완주가 곧 준수. ★필수스킬 `insane-search`·`agent-reach`는 Claude 전용이므로 **envscan은 Claude 노드가 돌린다**(Codex 배정 금지).
- **조사** = `search-first`→`research`→`research-sources`, 2-cycle 교차검증(상위 §6).
- envscan 산출물은 **결정론 4대가드(strict-T0)+SHA256**이 리뷰어 검수를 대체한다(상위 §4 예외). 단 envscan **코드 변경**은 codex 코드리뷰 유지.

## 6. 산출물 경로
- **envscan** = `output/WaveAI/리서치본부/환경스캐닝/{날짜}/` (팀 계층 예외·현행 유지 — 상위 §3-2)
- 그 외 = `output/WaveAI/리서치본부/{팀}/` 4-슬롯(상위 §3)

## 7. 협업 라우팅·회색지대
- AI트렌드/콘텐츠 = 크리에이티브에 **소스·팩트체크 공급**(제작은 크리)
- 포사이트 스킬 개정 = **리서치 단독**, Edu는 사용만(상위 §9-5)
- 뉴스크롤링(GlobalNews) = 리서치2팀 배정(구 인텔리전스 소관 승계)
- 충돌 = 본부장 협의 → COO → CEO
