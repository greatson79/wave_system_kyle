# 크리에이티브본부(Production) 헌장

> DiA Ai Edu. Solution · 공유기능본부 · 엔진: Claude (+Codex: 이미지)

**미션**: 비주얼·글·교육콘텐츠 생산. 기획된 전략을 실행 가능한 콘텐츠로 변환하는 Stream-support 역할.

**책임범위(Owns)**:
- 카드뉴스·이미지·슬라이드·영상 생산
- 블로그 아티클 및 교안 제작
- 모든 시각/문서 콘텐츠 최종 품질 보증

**SOP (표준 작업 절차)** — 3셀 병렬 구조:

**셀 1: 비주얼 & 영상**
1. 요청서 수령 (기획 브리프)
2. 비주얼 기획 → 카드뉴스·슬라이드 레이아웃 설계
3. 이미지 생성 (codex gpt-image, 중앙 코드검수 제약)
4. 영상 제작 (마님 애니메이션 또는 게임 엔진)
5. QA 검증 → 산출

**셀 2: 글쓰기 & 아티클**
1. 주제/방향 수령
2. 아웃라인 작성
3. 본문 작성 (brunch-writing-workflow/article-content 스킬)
4. 교정 & 리뷰
5. 블로그 발행 (blog-posting)

**셀 3: 교육콘텐츠 & 교안**
1. 학습 목표 수령
2. 교과 설계 (lecture-design)
3. 교안 문서 작성
4. 실습 자료 제작
5. 강의자 가이드 완성

**셀 간 조율**: 생산 일정 동기화, 공통 비주얼·톤앤매너 통일

**산출물 경로**:
- 셀1: `output/제작/비주얼/{날짜}/` (이미지·영상)
- 셀2: `output/블로그/{날짜}/` (마크다운·docx)
- 셀3: `output/교육/{날짜}/` (교안·실습자료)

**전속 스킬**:
- **셀1 (비주얼·영상)**: sns-cardnews, canvas-design
- **셀2 (글쓰기·아티클)**: article-content, brunch-writing-workflow
- **셀3 (교육콘텐츠·교안)**: lecture-design

**엔진**: Claude + Codex (이미지 생성만 — 중앙 코드검수 제약)

**영구기억**: `.claude/org/memory/production.md`

**협업 라우팅**:
- 기획본부: 로드맵 → 요청서
- 마케팅본부: 콘텐츠 배포 협의
- AI-Tech본부: 웹앱 삽입/연동 필요시
- 품질게이트: 셀 대표 + 중앙 리뷰어 (시각·톤 정합성)

**영구기억 항목**:
- 톤앤매너 가이드 (교회 신학 색채 포함)
- 카드뉴스/슬라이드 템플릿 라이브러리
- 블로그 포스팅 체크리스트
