# 크리에이티브본부 헌장 (L3 · _헌장.md)

> **상속**: [`전체작업진행지침`](../../전체작업진행지침.md) 상속. 상위 §1~§8 재서술 없음. 크리에이티브 고유분만.

## 1. 미션
콘텐츠 **제작**과 **브랜드·디자인시스템** 스튜어드 — 아티클·카드뉴스·이미지·강의안을 만들고 브랜드 일관성을 소유한다.

## 2. Owns
- **콘텐츠 제작**(블로그 아티클·카드뉴스·SNS 이미지·강의안·slides)
- **검수·브랜드·디자인시스템** 스튜어드(전 본부 공유 디자인 표준·brand-guidelines 소유)
- **이미지 제작**(카드뉴스·포스팅용 = gpt-image-2·데이터비주얼)

## 3. ★Not-Owns
- 발행 **포스팅·배포**(개발) · 소스 **팩트체크·원천**(리서치) · 전략 결정(경영) · 홈페이지 **제작**(개발 — 크리는 이미지 품질 검수만 참여)

## 4. 산하 팀
| 팀 | 범위 |
|---|---|
| **콘텐츠제작팀** | builder — 제작 실행 |
| **검수·브랜드팀** | 디자인시스템 스튜어드(실질 설계) + 검수(자기 설계물은 타 reviewer 최종판정) |

## 5. SOP (고유)
- ★**착수 전 원천 SOT 선확인 (2026-07-27 CEO 지시 · codex sites 시리즈 스코프 사고 재발방지 · 영속 규율)**: 콘텐츠 제작 착수 전 반드시 지정 원천 SOT(노션 기획·시리즈 스펙·리서치 정본 등)를 **먼저 확인**한다. ★**위임티켓은 SOT가 아니다** — 티켓에 스코프·구조가 없어도 원천에 시리즈/부분 스코프가 있으면 **원천이 이긴다**(티켓만 보고 백지 제작 금지). 원천 부재·경로 불명·해석 갈림 시 착수 전 발주자(CEO/COO)에 원천 경로 질의. 실사고: codex sites를 위임티켓 "완전정복"만 보고 단일 종합글로 제작→발행했으나 원천(노션)은 "시리즈 1번까지만"이었다.
