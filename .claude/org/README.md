## 매트릭스 작동 원리

### 1. 사업부 = 결과 책임자
CEO가 목표 위임 → 사업부장이 마감·품질·산출물 소유.

### 2. 공유기능본부 = 전문가 센터
각 본부가 능력의 표준·SOP·템플릿·스킬·품질바를 소유·관리.

### 3. 실행 흐름 (Virtual Matrix)
기존 커맨드는 **사업부장 노드가 단독 실행**(100% 보존). 매트릭스는 무거운 inter-pane 소켓 위임이 아니라 **SOP 결합**으로 구현 — sub-agent 스폰 시 대상 본부 헌장·SOP를 시스템 프롬프트에 결합. 진짜 무거운/크로스-사업부 작업만 본부 노드에 정식 의뢰.

### 4. 충돌 조율
두 사업부가 같은 본부 자원 경합 → CEO(Master) 중앙 중재.

### 5. 이원화 검증 게이트
모든 산출물 → ① **리서치·검증본부 = Fact Validation**(사실·출처·환각) → ② **품질감사실 = Value & Logic Validation**(전략·신학·문체) → CEO → 회장 보고. 두 게이트 격리.

## 운영·전략 두 평면 + 본부장 전략회의 (★2026-06-30 · 2026-07-23 B안 재설계 — 사업부문장→본부장)

> **설계 원리**: 계층을 *더하지* 않고, 위로 올라가는 것을 *줄인다*. 조직을 두 평면으로 분리하되, **본부장은 운영 라인(COO 경유)과 별개로 전략평면(본부장 전략회의)에 전략 hat으로만 참여**하며 이것이 운영 보고 hop을 늘리지 않는다(계층 추가로 인한 latency·병목 방지).

### 평면 분리
| | 운영 평면 (빠름·평면, **불변**) | 전략 평면 (작음·숙고) |
|---|---|---|
| 흐름 | 팀 → 본부장 → COO → CEO → 주인님 | **본부장 전략회의** |
| 상설 | 본부장·워커·COO | **CEO + COO** |
| 참여 | — | **안건 관련 본부장**(8본부 대상·전원 상시 아님) |

### ★본부장 임명 = 2엔진 선발 (2026-07-18 주인님 명령)
본부 소환 시 본부장은 **Codex·Claude 후보를 모두 소환→적합도 판단→승자 임명**한다(전원 Claude 방지·엔진
분산·Anthropic 한도 분산). 소환 4요소·엔진 선발(적합표·성과대장·bake-off·부하분산 tie-breaker·비용가드)·
각성 브리핑·스킬베이스·리뷰게이트의 **집행 정본 = [`본부장_임명지침.md`](본부장_임명지침.md)**. 헌장 상위 =
MASTER §7·WORKER §1. 선례: 아래 목회사역 사업부 내부(기획팀장=Codex·실행팀장=agy)는 이미 멀티엔진 임명.

### ~~사업부문장 = 본부장 겸직~~ — 폐기 (2026-07-23 · 사업부 폐지)
전략평면 주역은 이제 **본부장**이다(사업부문장 개념 소멸·겸직 hat 없음). 각 본부장이 자기 도메인의 전략·우선순위를 대표해 본부장 전략회의에 참여한다. 운영 지휘는 COO 라인 그대로.

### 본부장 전략회의 (전략 평면의 유일 의식 — ★매주 월요일 오전 · 2026-07-23 B안)
- **구성**: **CEO + COO 상설 + 안건 관련 본부장**(8본부 대상·전원 상시 아님·자원 위생). CSO=자원안건 시 / agy·Codex=적대검증 시 소환.
- **안건**: 전략·주간 방향 · **cross-도메인(본부 간) 우선순위** · 공유 자원배분 중재 · denylist급 결정. ★일상 운영 제외(COO·본부장 소관).
- **주기**: **매주 월요일 오전** (개시 = 주인님 호출 시 · CEO 안건 사전준비) + 이벤트(cross-도메인 충돌·중대결정). 작고 드물게.
- **산출**: 결정·우선순위 → COO가 운영 평면 언어로 번역·집행.

### 자원 배분 원칙
본부는 다(多)도메인 봉사(공유 역량). **COO = 일상 서플라이 배분 중재** / **본부장 전략회의 = 전략 우선순위**. 본부 자원충돌 → COO 1차 중재 → 안 풀리면 본부장 전략회의 상정.
