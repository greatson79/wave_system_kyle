# /대시보드 — 회사 전체 Mission Control

DiA Ai Edu. Solution 회사 상태를 **한 화면**으로 보는 정적 대시보드를 생성하고 브라우저에서 연다.

## 동작 (정적 생성 · 서버 0)

기본(1회 생성 후 열기):

```bash
node output/DiA/AI-Tech본부/대시보드팀/대시보드/build_dashboard.mjs && open output/DiA/AI-Tech본부/대시보드팀/대시보드/dashboard.html
```

실시간 갱신(작업 진행 중에만 — bounded 루프, idle 시 자가종료):

```bash
node output/DiA/AI-Tech본부/대시보드팀/대시보드/build_dashboard.mjs --watch   # 활성(L0≥1)이면 8s마다 재생성, 전 노드 idle이면 1회 쓰고 종료
```

## 실시간 반영 / 대기모드 (상시 서버 0)

- **활성 판정** = L0(RUN) 노드 ≥ 1 (작업 진행 중). → HTML에 `<meta refresh 8s>` + "🟢 실시간 갱신" 배지. `--watch`는 8s마다 재생성.
- **대기모드** = 전 노드 L1/L2 (L0=0). → meta-refresh 제거(브라우저 폴링 0) + "⏸ 대기모드" 배지 + 마지막 갱신시각 + 수동 새로고침 버튼. `--watch`는 idle 감지 즉시 대기 HTML 1회 쓰고 **자가종료**.
- **메커니즘**: 상시 listening 서버 없음. `--watch`는 활성 중에만 도는 **bounded 재생성 루프**(안전캡 30분). 브라우저는 meta-refresh로 다음 로드 시 대기 HTML(무refresh)을 받아 폴링을 자동 중단. CSO가 재생성 프로세스 생명주기 감시.
- **반응형**: 320/768/1024/1440 전부 가로 오버플로 0. 좁은 화면 = 1컬럼 스택, 넓은 화면 = 2컬럼 대등.

생성기(`build_dashboard.mjs`)는 아래 SOT를 **직접 읽어** 추측 없이 `dashboard.html`을 만든다:

| 섹션 | 데이터 소스 (직접 읽기) |
|------|------------------------|
| ① 조직 13노드 | `SESSION_STATE.md` 노드 레지스트리 테이블 + `cmux tree --all` 라이브 교차 |
| ② 전사 작업 보드 | `SESSION_STATE.md` `##` 섹션(본문 종결표식으로 완료 재분류) |
| ③ 산출물 현황 | `output/README.md` 허브 테이블(심링크/정본) |
| ④ 자원·서버위생 | `uptime`·`sysctl`·`vm_stat`·`lsof`(헤더 제외) |
| ⑤ 타임라인 | `SESSION_STATE.md` 이벤트 로그 |
| ⑥ 라이브 노드 | `cmux tree --all` |

## 규칙 (불가침)

- **서버 0**: 정적 HTML만 생성. 별도 웹서버를 띄우지 않는다.
- **headless 사용 시 즉시 kill**: 시각 검증용 headless 렌더(playwright 등)를 쓰면 작업 후 강제 종료(누적 금지).
- **graceful 결측**: 소스가 비면 해당 섹션을 빈 상태로 처리(전체 깨짐 방지). 생성 로그 마지막 줄에 결측 목록 보고.
- **추측 0**: 13노드/작업보드/산출물은 SOT 직접 파싱 결과만 표시.
- **주소 재회전 흡수**: SESSION_STATE 기록 주소 ≠ 라이브 cmux면 라이브 우선 + "주소 재회전" 배지.
