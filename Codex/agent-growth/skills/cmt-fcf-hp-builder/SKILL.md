# CMT FCF HP Builder

## Procedure

1. Confirm the passage and whether the user wants CMT only, FCF only, HP only, or all three.
2. Derive Subject from the passage boundary.
3. Write one or two concrete Complement statements.
4. Write exactly one CMT Sentence.
5. Write FCF as one or two sentences revealing gospel need, not mere moral failure.
6. Write HP as one sentence that answers the FCF through the CMT.
7. Add a neutral HP only when requested.
8. Mark uncertain claims as `확인 필요`.

## Output

Use the CMT / FCF / HP format from `output-formats.md`.
