## Procedure

1. Start from the passage, CMT, and FCF. If any is missing, state the gap and create only what the user requested.
2. State the Moral Principle honestly derived from the passage.
3. Show Human Effort Failure without shaming or moralizing.
4. Present Christ's person and work as the gospel answer, centered on representative obedience and the cross.
5. Draw Hermeneutical Points connecting CMT and FCF to contemporary life.
6. Write gospel application for personal and communal life.
7. Mark uncertain claims as `확인 필요`.
