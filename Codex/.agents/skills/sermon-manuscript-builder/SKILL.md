## Procedure

1. Confirm whether the user wants an outline, full manuscript, introduction, conclusion, application, or questions.
2. Use existing passage research, CMT, FCF, HP, or sermon arc when provided.
3. Do not invent historical background, original-language claims, or theologian quotations.
4. Keep the sermon movement Christ-centered: text, FCF, human inability, Christ's fulfillment, gospel application.
5. Write for the requested audience and length.
6. Run the quality checklist before final output.
7. Mark uncertain claims as `확인 필요`.

## Output

Use the Sermon Manuscript format from `output-formats.md` unless the user asks for another format.
