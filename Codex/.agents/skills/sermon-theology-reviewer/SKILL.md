## Procedure

1. Identify the artifact type: research note, CMT/FCF/HP, sermon arc, outline, manuscript, or application.
2. Check whether the artifact stays inside the passage.
3. Check whether CMT -> FCF -> HP is logically connected when present.
4. Check whether Christ's representative work is explicit.
5. Flag moralism, self-salvation logic, unsupported original-language claims, invented quotations, and prohibited-source influence.
6. Separate required fixes from optional improvements.
7. Mark unverifiable claims as `확인 필요`.
