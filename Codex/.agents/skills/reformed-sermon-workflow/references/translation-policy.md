# Translation Policy

## Primary Bible Versions

Prioritize:

- 개역개정
- NIV
- ESV

## Rules

- Use the passage and translation supplied by the user when provided.
- If the user does not provide text, avoid long direct quotation and mark exact wording as `확인 필요`.
- Use Hebrew, Aramaic, or Greek only when the relevant original-language basis is known.
- Do not expand etymology or assign speculative meaning.
- Mark uncertain textual, historical, or linguistic claims as `확인 필요`.
