AI 에이전트 작업 방식 이해

            

              

                
질문하는 AI

                
대화창 안에서 답변, 요약, 아이디어를 제공하는 조언자에 가깝다.

                
    
                  
  • 사용자가 직접 파일을 만들고 옮긴다.
    • 
                  
  • 답변의 품질은 좋지만 실행은 사람 몫이다.
    • 
                  
  • 결과물 검증과 배포를 따로 챙겨야 한다.
    • 
                

              

              

                
파일을 고치고 배포까지 하는 AI 에이전트

                
작업 폴더를 읽고, 파일을 수정하고, 검증 명령을 실행하고, 배포 결과까지 확인한다.

                
    
                  
  • 요구사항을 작업 계획과 파일 변경으로 바꾼다.
    • 
                  
  • HTML, CSS, 이미지, 배포 설정을 실제 산출물로 만든다.
    • 
                  
  • 검증 실패를 보고 다시 고치는 반복을 수행한다.
    • 
                

              

            

          


          

            
Codex Desktop UI 설명

            

              

                
작업 폴더

                
Codex가 읽고 고칠 실제 프로젝트 공간이다. 수업에서는 폴더를 먼저 정하고 그 안에서만 작업한다.

              

              

                
대화창

                
요청, 승인, 피드백을 주고받는 지휘석이다. “무엇을 만들지”보다 “완료 기준”을 함께 적는다.

              

              

                
파일 변경

                
Codex가 어떤 파일을 바꿨는지 확인하는 영역이다. 의도와 다른 변경은 여기서 바로 잡는다.

              

              

                
터미널

                
설치 확인, 미리보기 실행, 검증 스크립트, 배포 명령이 실행되는 곳이다.

              

              

                
브라우저 미리보기

                
로컬 페이지를 열어 CTA, 레이아웃, 모바일 흐름, 공유 이미지를 확인한다.

              

              

                
배포 결과

                
Vercel URL과 카카오톡 공유용 URL을 확인하고, 필요한 경우 캐시 우회 경로를 만든다.

              

            

          

        


        

          

            
오늘 다룰 수업 내용

            

              

                1
                
브리프 작성

                
대상, 메시지, CTA, 이미지, 링크를 한 장으로 정리한다.

              

              

                2
                
구조 설계

                
Codex가 섹션, 파일, 검증 기준을 먼저 제안하게 한다.

              

              

                3
                
MVP 제작

                
첫 화면, CTA, 정보 섹션을 빠르게 구현하고 바로 미리본다.

              

              

                4
                
검증 고정

                
필수 문구, CTA, OG 이미지, footer 조건을 스크립트로 확인한다.

              

              

                5
                
배포 자동화

                
Vercel 배포 후 실제 URL과 공유 미리보기를 점검한다.

              

            

          


          

            
운영 보드

            

              

                강사 핵심 멘트
                좋은 프롬프트는 일을 시키는 문장이 아니라 완료 기준까지 포함한 작업 계약서입니다.
              

              

                주의 지점
                카카오톡 미리보기는 OG 이미지를 캐시한다. 같은 URL이 계속 QR로 보이면 새 공유 경로를 만든다.
              

              

                성공 기준
                수강생이 자기 페이지를 열고 CTA와 공유 이미지를 설명할 수 있으면 성공이다.
