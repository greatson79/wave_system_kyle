# Agent Checklist

Use this checklist at the start and end of each engineering task.

## Start

- [ ] I read `AGENTS.md`.
- [ ] I read `.codex/harness/safe-development-protocol.md`.
- [ ] I checked repository status.
- [ ] I identified existing test/build commands.
- [ ] I classified the change.
- [ ] I noted any high-risk areas.
- [ ] I made a short plan for non-trivial work.

## During

- [ ] I avoided unrelated refactors.
- [ ] I preserved user changes.
- [ ] I used established project patterns.
- [ ] I added or identified tests/checks where practical.
- [ ] I updated the plan when facts changed.

## Finish

- [ ] I ran relevant verification.
- [ ] I recorded commands and outcomes.
- [ ] I listed changed files.
- [ ] I documented anything not verified.
- [ ] I recommended the next safe step.
